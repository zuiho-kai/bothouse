- Commands (bash-guard): no `pkill -f` (it kills the shell running it); use `kill $(pgrep -f '[x]yz')` or a pid file. Background commands need a timeout (`timeout <s> <cmd>`; on macOS `perl -e 'alarm shift; exec @ARGV' <s> <cmd>`) and no `| tail`/`| head`; end a long-running service with `# long-running-ok`. With HOOK_PROXY set, downloads go through the proxy; add `# direct-ok` when a direct download is really needed.
- Reject foreground gh watch, sleep >=60 seconds and sleep polling loops. DSH also rejects any foreground sleep, repeated polls/read-only commands and a fourth sequential single read-only step. Batched reads, child sessions and outing turns have scoped exemptions. DSH network installs/fetches require a timed background task. Missing session history never fabricates counts.
- A Claude Code subagent's foreground command with a timeout over 290 seconds gets it cut to 290 seconds (a subagent's prompt cache lasts 5 minutes); what does not finish moves to the background by itself. Do not poll it then: deliver with the log path and the next step. Dispatch work that waits 5–60 minutes to a long-task subagent (1-hour cache, not capped). A while … sleep loop inside perl/python counts as polling too.

- Other CLIs do not inherit the Claude long-task cache policy. Start work expected to exceed five minutes in the native background, report its log/task ID, and end the turn: DSH run_in_background (timeoutMs can promote to background), Grok block_until_ms=0, Gemini is_background, or the session ID returned by Codex exec_command. Do not poll with wait/sleep. DSH child timeouts above 290000 ms are denied with capped retry arguments; Grok child block_until_ms is capped at 290000.
