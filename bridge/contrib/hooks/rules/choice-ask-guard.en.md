- Decide or ask (choice-ask-guard): when a reply puts a decision to the user, a small model checks it against the product intent card and the user's recent messages. If the user's earlier words settle it, the reply is sent back with the answer: decide and act on it. If the question or plan conflicts with something the user already decided, it is sent back naming that decision: follow the decision. Ask only about a direction the user has not chosen, spending the user's money, or something only the user can do or look at.
