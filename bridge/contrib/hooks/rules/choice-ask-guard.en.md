- Answer before you ask (choice-ask-guard, checks Chinese replies): before a reply puts a choice or decision question to the user (要不要, 你定, 选哪个, 方案一/二, A 还是 B？), work it out from what the user decided before, what the product is for, and common sense; if that settles it, decide and do it without asking. A change that overturns or alters something the user already decided is never a common-sense call, even when it looks like one: ask first, do not change it yourself. Ask only about direction (a route the user has not chosen), changing what the user decided, or spending over budget, and put three items before the question: 「我的答案：…」「依据：…」「为何不能自己定：方向/改用户定过的/花钱」.
