- Numbers need a source (param-source-guard): every new `name = number` in code (limits, thresholds, windows, …) gets a comment on the same or previous line saying where it comes from — the user's words, data or a measurement, a SPEC, or an existing setting it follows (the words 来源/source/实测/数据/用户/SPEC/沿用 mark it). No source means you made it up: leave the parameter out or ask the user. 0, 1, -1, timeouts, ports and test files are not checked.
