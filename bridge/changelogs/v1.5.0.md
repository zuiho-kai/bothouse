## v1.5.0 — 2026-08-16

First stable release of the v1.5.0 series since v1.4.1. Stabilizes the
v1.5.0-beta.1 → v1.5.0-beta.5 line (~93 commits, 5 rolling betas) with
production-validated P1 stability fixes ([#1693](https://github.com/chenhg5/cc-connect/pull/1693) fixing [#1686](https://github.com/chenhg5/cc-connect/issues/1686)).

If you have been running any `1.5.0-beta.*` in production, **upgrading to v1.5.0 is
recommended** — same runtime as beta.5 (`3fa54174`) with stable versioning and npm `@latest`.

---

### Highlights

- **New platforms** — Tencent Yuanbao Bot API (#1445); **cloud_web** self-hosted IM gateway (#1282); **Google Chat** (#1424); **WPS Agentspace** (#1439); **Tuitui** (#849).
- **New agent** — **Reasonix** HTTP serve API adapter (#1281).
- **Feishu hardening** — topic workspace isolation (#1551); quoted file on-demand download (#1588); first thread mention bootstrap (#1627); cross-type image batch flush (#1693).
- **Agent ecosystem** — Kimi Code CLI native dialect (#1564); Pi v0.84.0 toolcall_end + willRetry (#1674, #1597); codex `/model` gpt-5.x visibility (#1546); Claude Code session title fallback (#1549).
- **Core stability** — restart-notify panic recovery; idle close race fixes; attachment filename collision prevention; code fence split integrity (#1693, #1630, #1557).
- **Pi & permissions** — RPC mode (#1440); permission mode env injection (#1637); `agent_session_idle_timeout_mins` (#1338).

---

### ⚠️ Notable fixes (production-reported)

1. **#1686 P1-A** — `/restart` no longer crashes daemon when platform adapter panics during post-restart notification (#1693).
2. **#1686 P1-B** — Rapid image + text within `image_batch_window_ms` no longer drops the buffered image (#1693).
3. **#1686 P1-C** — Long background turns no longer killed by stale idle-close timer (#1693).
4. **Weixin send budget** — `sendmessage ret=-2` fails fast per-account (#1643).

---

### Known non-blocking items (post-release)

- `/restart` success notification may drop if platform takes >10s to reach ready (P3 UX).
- Google Chat / WPS Agentspace / Tuitui adapters not manually QA'd on dedicated test accounts (CI + production observation).

---

### Breaking Changes

None. All new config options are optional with safe defaults. v1.4.1 configs upgrade as-is.
