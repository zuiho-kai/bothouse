## v1.5.0-beta.5 — 2026-08-16

Rolling beta with **1 commit** on top of [v1.5.0-beta.4](https://github.com/chenhg5/cc-connect/releases/tag/v1.5.0-beta.4). P1 stability fixes from beta.3 QA feedback (#1686).

---

## Fixed

- **P1-A: restart-notify goroutine panic recovery** (#1693 fixing #1686)

  `runPendingRestartNotify` now has `defer recover()` so a platform adapter panic during
  post-restart notification cannot crash the entire daemon.

- **P1-B: cross-type image batch flush** (#1693)

  When `image_batch_window_ms` is active, a text message arriving within the batch window
  could cause the buffered image to be dropped as stale. Non-image dispatches now call
  `flushImageBatchForSession` synchronously before advancing the watermark.

- **P1-C: idle close race fixes** (#1693)

  - **P1-1**: unsolicited/background turns now re-arm the per-session idle close timer
  - **P1-2**: idle close timer is armed *before* `drainPendingMessages` so racing user
    messages can cancel it correctly
