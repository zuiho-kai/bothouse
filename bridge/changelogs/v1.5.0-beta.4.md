## v1.5.0-beta.4 — 2026-08-16

Rolling beta with **6 commits** merged from `main` since [v1.5.0-beta.3](https://github.com/chenhg5/cc-connect/releases/tag/v1.5.0-beta.3) (2026-08-14). Owner merged new PRs today — ship beta.4 for QA before stable.

---

## Features

- **Kimi Code CLI native dialect** (#1564 fixing #1561)

  Full support for the Node.js `kimi-code` CLI: probe-gated `--quiet`, modern `-r <id>` resume,
  JSON meta `session.resume_hint` parsing, dual content-shape stream parser, and
  `~/.kimi-code/sessions` listing for `/list` and `/delete`. Legacy `kimi-cli` unchanged.

## Fixed

- **Kimi `--work-dir` flag gating** (#1483 fixing #1476)

  Probe `kimi --help` and only emit `--work-dir` when the installed CLI advertises it.
  Fixes `error: unknown option --work-dir` on modern Kimi Code CLI builds.

- **Pi willRetry turn continuity** (#1597)

  Keep the agent turn open while Pi auto-retries transient errors (`willRetry`), so users
  see progress instead of a premature turn end + duplicate reply.

- **Pi v0.84.0 toolcall_end** (#1674)

  Support `toolcall_end` events without a cumulative message field — fixes broken tool
  progress on Pi CLI v0.84.0+.

- **WeCom quoted message context** (#1669)

  Preserve quoted/replied messages as agent context on enterprise WeChat.

- **Web admin work_dir validation** (#1572)

  Validate project `work_dir` in the Web admin UI before save.
