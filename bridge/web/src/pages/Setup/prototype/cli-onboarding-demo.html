这份 Demo 和真实实现的边界

页面只使用内存中的模拟状态。真实版本需要本机后台执行各 CLI 的官方安装与授权流程，并逐个验证调用。账号授权由对应服务完成；一个 CLI 的授权不能替代其他 CLI 的授权。这里的示例 API 连接不接收真实 Key，示例聊天不调用模型、不产生费用。手机接入、断线恢复和权限授权未在本 Demo 验证。
