# 常见卡点

按你看到的现象找。

## 装不上

**下载很慢或失败** — GitHub 在国内不稳定，先开代理再跑安装命令。

**提示 `typing 'bothouse' runs another copy first`** — 电脑上还有一个旧的 bothouse。照它打出的命令把新路径放前面，或用它打出的完整路径运行。详见[装 bothouse](./guide/install)。

**Mac 上双击安装包被拦** — 安装包没有签名。右键 → 打开。

## 安装页面打不开

**敲了 `bothouse` 浏览器没反应** — 把终端里打出的 `http://localhost:…/login?token=…` 链接复制到浏览器。别把这条链接发给别人。

**刷新后前面填的都没了** — 刷新会清空填过的内容。所以开始前先把 AI 工具登录好，中途别刷新。

## 不回话

**Discord：机器人在线，@ 它不回** — 没开「允许机器人读消息」的开关（Message Content Intent）。去开发者后台 → Bot 打开，保存，再到管理面板点「重启生效」。见 [Discord 第 1 步](./guide/discord#step-1)。

**不 @ 它就不说话** — 正常。默认只在被点名时回复。

**DSH：频道里没有队员** — 桌面版没重新打开。在安装页面点「在桌面版里打开」，或者完全退出桌面版再打开。见 [DSH 第 5 步](./guide/dsh#step-5)。

**@ 了，别人能指挥、我不能**（或者反过来）— 看「谁能指挥它」填的是谁。见[谁能指挥它](./advanced/who-can-command)。

**同一个机器人在两台电脑上都开着** — 一个机器人只能在一处在线，关掉另一台的 bothouse。

## 回得很慢

**一直「正在输入」，好几分钟** — 多半是 AI 工具背后的模型太忙，工具自己在等着重试。等一等；急的话对它说「换成 xx 模型」。见[换模型](./advanced/model)。

**DSH：点「安装插件」后几分钟没动** — 正常，要 3 到 4 分钟。

## 找不到东西

**Discord：选服务器的下拉框是空的** — 机器人还没进你的服务器。点安装页面上的「邀请链接」把它拉进来。见 [Discord 第 2 步](./guide/discord#step-2)。

**DSH：安装页面没写「已找到桌面版」** — 桌面版没装，或装了没打开过。装好、打开一次，再刷新安装页面。

## 冒出看不懂的东西

**出现红色的 curl 报错（DSH 派活时）** — 不用管，活一般照样派出去了。去任务板看一眼确认。

**冒出「工作区 1、2…」这样的新频道** — 正常。队长接到大活会自己开新频道去做，做完把结果发回主频道。

**没人叫它，它自己冒出一句话** — 装完默认每小时问它一次要不要说话。嫌吵就[关掉](./advanced/hourly-chat)。

**两个队员来回说「收到」「不客气」** — 派完活偶尔会客气几轮，几十秒后自己停。

**QQ 安装页面写着「QQ 官方机器人」** — 不用去申请官方机器人。不过 QQ 路线现在还没走通，见[路线 C](./guide/qq)。
