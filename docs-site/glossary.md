# 名词对照

安装页面和聊天里有些叫法是内部说法。左边是你在屏幕上会看到的字，右边是它的意思。

| 屏幕上写的 | 意思 |
|---|---|
| 主角色、主 bot | **队长**：接你的话、分活、检查交回的结果 |
| sub、队员、角色 | **AI 队员** |
| 一主多 sub | 一个队长带几个队员 |
| 人设 | 队员的名字和性格 |
| CLI、本机 CLI | 你电脑上的 AI 工具，比如 Codex、Claude Code、Gemini CLI |
| token（Discord、QQ） | 机器人的密码，别外传 |
| Message Content Intent | Discord 后台里「允许机器人读消息」的开关 |
| 安装向导 | 安装页面 |
| gate、闸门、智能判断 | 让一个小模型自动判断一句没点名的话该谁回。新手不用开 |
| 仅被点名时回复 | 群里 @ 谁，谁才回 |
| 工作区（Discord 等聊天软件里） | 队长干大活时自己开的临时频道 |
| 工作区（DSH 桌面版左栏） | DSH 自己放文件夹的地方，和 bothouse 无关 |
| 派活 / 交回 / 验收 | 把事交给队员 / 做完报给队长 / 队长检查 |
| 进度卡 | 它正在做哪一步的小卡片 |
| 任务板 | 记着这个频道里每件活做到哪了 |
| allow_from、谁能指挥 | 谁能让机器人干活；`*` 表示所有人 |
| 想不想说 | 每小时问一次要不要主动说话的定时任务 |
| daemon | 后台服务，关了窗口也一直在线 |
| wiki、记忆 | 队员共用的笔记本，你电脑上的一个文件夹 |
| DSH | DeepSeek Harness，DeepSeek 官方的 AI 桌面应用 |
| NapCat | 让 bothouse 用普通 QQ 号收发消息的工具 |

安装页面上还可能看到 hook、YOLO、jev、ACP 这些词，都是进阶设置，新手不用管。
