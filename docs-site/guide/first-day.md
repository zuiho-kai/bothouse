# 装好之后：第一天能干什么

下面每段都能直接复制，@ 你的队长发出去。没专门选过队长，就 @ 任意一个队员。［方括号］里换成你自己的内容。

## 先定规矩 {#rules}

AI 能在你电脑上跑命令。第一件事，先把底线说清楚：

```
以后的规矩：
查资料、整理内容、写草稿、只查看不修改的操作，可以直接做。
公开发布、花钱、删文件、把代码传到网上之前，把要做什么、改哪里先发给我，等我确认。
交结果时带依据（命令输出或截图）。缺材料、没权限，或者同一个问题连错两次，就停下来告诉我，不要编造完成。
```

## 让它帮你查东西

```
帮我查一下［你关心的事，比如：最近一周 AI 编程工具有什么新消息］，挑最重要的五条，每条一句话，附上来源链接。
```

## 让它整理你电脑上的文件

```
看一下［某个文件夹，比如 ~/项目/会议记录］里的文件，帮我写一份一页的总结，存成 总结.md 放在同一个文件夹里。先别删任何东西。
```

## 让队长分活

有两个以上队员时，试试让队长拆活：

```
我要［一件稍大的事，比如：给我的小网站做一个登录页，再写一份上线说明］。你拆一下，代码交给［队员 A］，说明交给［队员 B］，做完你检查一遍再交给我。
```

队长会在频道里 @ 队员把活分出去。活比较大时，它可能会自己开「工作区 1」这样的新频道去做，做完把结果发回来。

## 让它记住你的习惯

```
记住：我喜欢回答先说结论，再说原因；不要用表格。
```

它会把这条记进共用笔记本，以后的对话都会照做。见[团队记忆](../advanced/memory)。
