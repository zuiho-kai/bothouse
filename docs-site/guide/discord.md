# 路线 B：Discord

**做完长什么样**：在你自己的 Discord 服务器里，你 @ 机器人说一句，它先发一张小卡片说正在做哪一步，再正式回你。手机上的 Discord 也能用。

![做完的样子：你问机器人是谁，它回答](/img/discord/06-first-reply.png)

::: danger 先记住一件事
装到最后一页，一定要把「谁能指挥这些机器人」改成只有你自己（第 5 步会教）。不改的话，你服务器里**任何人**都能让机器人在你电脑上跑命令。
:::

## 要准备什么

在打开安装页面**之前**把这几样弄好，中途去弄会很麻烦：

1. **一个你能管理的 Discord 服务器**。自己新建一个最省事：Discord 左边栏点「+」→ 创建服务器。
2. **一个已登录的 AI 工具**：终端里敲 `codex` 或 `claude` 能正常聊天。**一定先登录好**——装到一半回去登录、再刷新安装页面，前面填的东西会被清空。
3. **已经装好 bothouse，并打开了安装页面**。还没装：[开始前：装 bothouse](./install)。还没有 AI 工具：[还没有 AI 工具？](./choose#no-ai)。

## 1. 去 Discord 后台建两个机器人 {#step-1}

在 Discord 里，**一个机器人 = 一个 AI 队员**。建两个：一个当队长，一个当队员，第 7 步派活要用。这一步在 Discord 的开发者后台做，页面是英文的。下面 1 到 3 小步做两遍。

1. 打开 [discord.com/developers/applications](https://discord.com/developers/applications)，点右上角 **New Application**，起个名字（这就是它在群里的名字），点 Create。
2. 左边点 **Bot**，再点 **Reset Token**，然后点 **Copy** 复制。这串字就是**机器人的密码**（页面上叫 token），只显示一次，先存到记事本。
3. 还在 Bot 这一页，往下翻到 **Privileged Gateway Intents**，打开 **Message Content Intent**（「允许机器人读消息」的开关），点 **Save Changes**。

::: warning 第 3 步最容易忘
不开这个开关，机器人会显示在线，但读不到你说的话，@ 它也不回。
:::

::: danger 机器人的密码别外传
别发到群里，别截图给别人。谁拿到它，谁就能冒充你的机器人。
:::

## 2. 安装页面第 2 页「机器人」：贴密码，选服务器 {#step-2}

回到安装页面，第一页点 **Discord**，点「下一步」。

1. 把第一个机器人的密码贴进「机器人 token」，点 **校验**。你会看到：密码框下面出现绿色的机器人名字和一串编号。
2. **把机器人拉进你的服务器**：新建的机器人还不在任何服务器里，校验后会出现黄字「这个机器人还没进所选服务器」，后面跟着「邀请链接」。点这个链接，在弹出的 Discord 页面里选你的服务器，点授权。这个链接已经带齐了机器人要的权限，不要自己去后台拼链接。
3. 点「再加一个机器人」，贴第二个机器人的密码，同样点「校验」，同样用它的「邀请链接」拉进服务器。
4. 「装在哪个服务器」选你的服务器，「默认聊天频道」选一个频道（比如 #常规）。
5. 点「下一步」。

![贴好机器人密码，校验通过](/img/discord/02-token.png)

::: details 没看到？
- **出现黄字说 Message Content Intent 没开**：回第 1 步第 3 小步打开，保存，再点一次「校验」。
- **服务器下拉框是空的**：机器人还没进任何服务器，点下拉框下面的「邀请链接」拉它进去。
- 邀请链接这一步我们实测时用的是已经在服务器里的机器人，没有从零点过。
:::

## 3. 第 3、4 页：选 AI 工具，起名字

第 3 页「本机 CLI」列出你电脑上装了的 AI 工具，给每个队员选一个显示「已登录」的（两个选同一个也行），点「下一步」。

![选一个已登录的 AI 工具](/img/discord/03-cli.png)

第 4 页「人设」是名字和性格。**这一页可以留空直接下一步**，以后随时能改。想给它性格，复制这段改一改：

```
你叫小橙，是这个群的队长。说话简短，先说结论。
接到活先拆成几步，能派给队友的就派出去，自己负责检查。
公开发布、花钱、删文件之前，先把要做什么发给我确认。
```

## 4. 第 5 页「主角色」：选队长，选「仅被点名时回复」

- **群聊参与方式**：选「仅被点名时回复（推荐，不用装模型）」。群里 @ 谁谁回。
- **主角色**：就是队长。选你想让它带队的那个机器人。

![选队长和回复方式](/img/discord/04-lead.png)

## 5. 第 6 页「完成」：改成只有你能指挥，保存，重启

1. 找到「谁能指挥这些机器人」这个框。**它默认是 `*`，意思是服务器里任何人都能让机器人在你电脑上跑命令。** 把 `*` 换成你自己的 Discord 用户 ID（一串数字）。拿 ID 的办法：
   - Discord 左下角你头像旁边的齿轮（用户设置）→「高级」→ 打开「开发者模式」。
   - 回到任意频道，在右边成员列表里（或聊天记录里）右键你自己的名字 →「复制用户 ID」，粘贴进这个框。
2. 其他勾选框都不用动。
3. 点 **保存配置**，等出现「保存好了」，再点 **重启生效**。这里重启的是 bothouse 这个程序，不是你的电脑，几秒钟就好。

![完成页：「谁能指挥这些机器人」那一栏](/img/discord/05-finish.png)

你会看到：Discord 里机器人的头像变成在线（绿点）。

::: tip 保存后出来一长串清单
保存后页面会列一长串它做了什么，不用看，只找最上面的「保存好了」和最下面的「重启生效」按钮。
:::

## 6. 在频道里说第一句

去你选的那个频道，**一定要 @ 它**（没 @ 它不会理你）：

```
@［机器人名字］ 你好，你是谁？用一句话介绍一下你自己。
```

你会看到：它先发一张「Codex · 已完成」这样的小卡片，告诉你它在做哪一步；然后正式回你一句话。

![第一句对话](/img/discord/06-first-reply.png)

::: details 一直显示「正在输入」好几分钟？
多半是 AI 工具背后的模型那边太忙。实测时 OpenAI 回了「模型满载」，Codex 自己等了 5 分钟才重试，频道里只能看到「正在输入」。等一等；急的话问它「你能换成哪些模型？」，挑一个让它换。
:::

::: details @ 了也不回？
- 第 1 步第 3 小步的「允许机器人读消息」开关没开。
- 「谁能指挥」填的 ID 不是你自己的。
- 同一个机器人在另一台电脑上也开着 bothouse：一个机器人只能在一处在线，关掉另一台。
:::

## 7. 让队长派一次活

在频道里发（［方括号］换成你两个机器人的名字）：

```
@［队长名字］ 派个小活给［队员名字］：让她查一下现在几点，把结果发回这个频道。
```

你会看到：队长在频道里 @ 队员把活交出去，几分钟内队员把时间发回来，再 @ 回队长。
