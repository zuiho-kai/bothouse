# 路线 A：DSH 桌面版

**做完长什么样**：在 DeepSeek 桌面应用的 #general 频道里，你 @ 一个 AI 队员，它 20 秒左右回你；你让它把活派给另一个队员，另一个队员做完交回。

![做完的样子：你问小橙是谁，小橙回答](/img/dsh/07-reply.png)

## 要准备什么

- **DSH 桌面版**（DeepSeek 官方出的 AI 桌面应用，全名 DeepSeek Harness）。Mac 下载后拖进「应用程序」；Windows 双击下载的安装程序装好。然后**打开一次**，看到它的主界面就可以关掉：
  - Mac（M 系列芯片）：[下载](https://download.deepseek.com/desktop/dsh-latest-macos-arm64.dmg)
  - Mac（Intel 芯片）：[下载](https://download.deepseek.com/desktop/dsh-latest-macos-x64.dmg)
  - Windows：[下载](https://download.deepseek.com/desktop/dsh-latest-windows-x64.exe)
  - 安装包两百多 MB。GitHub 上没有这个安装包，别去那找。
- **一个 AI**：一把 DeepSeek 的 API Key（最省事），或者一个已登录的 Codex、Claude Code。都没有？看[还没有 AI 工具？](./choose#no-ai)。
- **已经装好 bothouse**，并打开了安装页面。还没装：[开始前：装 bothouse](./install)。

**要多久**：约 15 分钟，其中 4 分钟是等安装。

不用注册机器人，也不用复制任何密码。

## 1. 在安装页面选 DSH，再选「DSH 桌面版」

安装页面第一页点 **DSH**，点「下一步」。然后在「角色住在哪」里选 **DSH 桌面版（推荐）**，点「下一步」。

你会看到：卡片下面写着「已找到桌面版。」

![选择 DSH 桌面版](/img/dsh/01-choose.png)

::: details 没看到「已找到桌面版」？
DSH 桌面版还没装，或者装了没打开过。照上面「要准备什么」装好、打开一次，再刷新一下浏览器里的安装页面（这时还没填任何东西，刷新不会丢内容）。
:::

## 2. 点「安装插件」，等 4 分钟

点 **安装插件**。

**页面 3 到 4 分钟没有变化是正常的**，它在后台装东西。装的时候 DSH 桌面版会被自动打开一次，不用管它。

你会看到：上面的进度条走到「3. 角色和模型」。

![安装插件这一页](/img/dsh/02-install.png)

::: details 等了很久还是没动？
超过 10 分钟没动，关掉安装页面，重新打开 bothouse，再走一遍这一步。
:::

## 3. 建两个队员，起好名字

这一页决定谁住进频道。**建两个**，第 7 步派活要用到第二个。

1. 「用什么回话」：有 DeepSeek API Key 就选 **DSH 原生模型**，在下面贴上 Key；有已登录的 Codex 就选 **Codex · 已登录**。
2. 点开「可选：自定义名字…」，在「名字（@ 时用）」里起个名字，比如 `小橙`。**不起名字的话，两个队员会叫 Codex 和 Codex-2，很难分。**
3. 点「再加一个角色」，同样选工具、起名字：`小蓝`。
4. 点 **保存，下一步**。

下面那排卡片（橘、龙娘……）是现成的性格，想用就点「用这个」，不用也行。

![选「用什么回话」，在名字框里起名字](/img/dsh/03-roles.png)

截图里名字框还是默认的「Codex」，你把它改成 `小橙`。往下翻能看到「再加一个角色」和「保存，下一步」：

![再加一个角色、保存下一步两个按钮](/img/dsh/03b-add-save.png)

## 4. 点「在桌面版里打开」

点 **在桌面版里打开**。

已经开着的 DSH 桌面版会先自动关掉再打开，这样它才能认出新来的队员。

![一切就绪，点在桌面版里打开](/img/dsh/04-open.png)

## 5. 在桌面版里找到 #general 频道 {#step-5}

DSH 桌面版左边点 **频道**，再点 **# general**。

你会看到：右上角有你刚才建的队员头像，写着「3 位成员」（你和两个队员）。

![DSH 桌面版的 #general 频道](/img/dsh/05-channel.png)

::: details 频道里没有队员？
桌面版没重新打开，还没认出队员。回安装页面再点一次「在桌面版里打开」，或者自己把桌面版完全退出再打开。
:::

::: tip 左边那个「工作区」不是 bothouse 的
DSH 桌面版左栏自带一个「工作区」，那是 DSH 自己放文件夹的地方，和 bothouse 没关系，不用点。
:::

## 6. 说第一句

在输入框里敲 `@`，会弹出队员列表，选 `小橙`，接着输入下面这句，回车。

```
@小橙 你好，你是谁？用一句话介绍一下你自己。
```

![敲 @ 弹出队员列表](/img/dsh/06-mention.png)

你会看到：20 秒左右，小橙回你一句话。

![小橙回话](/img/dsh/07-reply.png)

::: details 一直没回？
- 一定要用 `@` 选人，光打名字它不知道你在叫它。
- 你选的 AI 工具可能没登录好。打开终端敲一下 `codex`（或 `claude`），确认能正常聊天。
:::

## 7. 让它派一次活

把下面这段复制进输入框，回车。［小蓝］换成你第二个队员的名字。

```
@小橙 派个小活给［小蓝］：让她查一下现在几点，把结果发回这个频道。
```

你会看到：小橙在频道里 @ 小蓝把活交出去，小蓝报回现在的时间，最后出现一行「验收完成（小橙）」。频道顶上「本频道进展」和右上角「任务板」里能看到这件活。

![小橙把活派给小蓝，小蓝交回时间](/img/dsh/08-dispatch.png)

::: details 出现一条红色的 curl 报错？
红字类似「派给 @小蓝 的任务暂时没发出去：curl … Failed to connect」。**不用管，活已经交出去了**，等一会儿小蓝就会回。
:::

::: details 两个队员来回说「收到」「不客气」？
派完活两个人可能客气几轮，几十秒后自己停下，任务板上会多记一两件。不影响使用。
:::

## 你成功了

到这一步，你已经有了一支两个人的小队。

接下来：

- 看看[第一天能干什么](./first-day)，里面有几段可以直接复制的用法。
- 不用专门选队长：你 @ 谁，谁就接活。
