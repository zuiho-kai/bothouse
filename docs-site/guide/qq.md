## 它是怎么接 QQ 的

bothouse 接 QQ 靠一个叫 **NapCat** 的工具：你在电脑上用一个普通 QQ 号（建议用小号）登录 NapCat，bothouse 通过它收发这个号的消息。

安装页面这一页的标题写着「QQ 官方机器人」，但**不用去 q.qq.com 申请官方机器人**，用的就是普通 QQ 小号。

## 要准备什么

- 一个给机器人用的 QQ 小号，和一部能扫码登录它的手机。
- 你自己的 QQ 号（大号），用来指挥机器人。
- 一个只有你和机器人小号的测试群。
- 已经装好 bothouse：[开始前：装 bothouse](./install)。

## 1. 安装页面选 QQ，填四样东西 <span class="badge-ok">已验证</span>

安装页面第一页点 **QQ**，点「下一步」。这一页要填：

- **NapCat WebSocket 地址**：默认 `ws://127.0.0.1:3001`，NapCat 装在同一台电脑上就不用改。
- **NapCat 访问令牌**：你在 NapCat 里自己设的一串密码（第 3 步设）。
- **你的 QQ 号**：填你自己的**大号**，不是机器人小号。只有这里填的号能指挥机器人。
- NapCat HTTP 地址：发文件用，可以空着。

![QQ 安装页面](/img/qq/01-qq-page.png)

::: details 「测试连接」按钮是灰的，点不动？
令牌和你的 QQ 号两个都填上，按钮才能点。
:::

1. 照安装页面底部的「NapCat 安装」链接装 NapCat。
2. 打开 NapCat 的网页后台，用手机 QQ 扫码登录小号。
3. 在 NapCat「网络配置」里**新建一个 WebSocket 服务器**，端口 3001，设一个访问令牌。不做这一步，bothouse 连不上它。
4. 把令牌填回安装页面，点「测试连接」。
