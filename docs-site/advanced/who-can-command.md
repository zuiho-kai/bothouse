# 谁能指挥它

AI 队员能在你的电脑上跑命令，所以要管好**谁能让它干活**。

## Discord

装完默认是 `*`：**你选的那个服务器里，任何人都能让机器人在你电脑上跑命令。** 私信和管理命令仍然只认你。

只想自己用：

- 装的时候，在安装页面最后一页「谁能指挥这些机器人」里，把 `*` 换成你自己的 Discord 用户 ID。
- 已经装好了：打开配置文件（Mac/Linux 是 `~/.bothouse/config.toml`，Windows 是 `%USERPROFILE%\.bothouse\config.toml`），把 `allow_from = "*"` 改成 `allow_from = "你的用户ID"`，再点「重启生效」。

多个人用逗号隔开。

**怎么拿到用户 ID**：Discord 设置 → 高级 → 打开「开发者模式」，然后右键自己的头像 →「复制用户 ID」。

## QQ

安装页面里「你的 QQ 号」那一栏就是能指挥机器人的人，填你自己的大号，多个用逗号隔开。填 `*` 表示所有人都能指挥，不推荐。

## DSH 桌面版

DSH 的频道只在你自己的电脑上，别人进不来，不用设置。
