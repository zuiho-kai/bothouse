# 关掉窗口也一直在线

用 `bothouse` 命令打开时，关掉终端窗口，队员就下线了。想让它在后台一直跑：

```sh
bothouse daemon install
```

装成后台服务，并马上启动。之后关掉终端，队员也在线。

- **开机自动启动**默认是关的。要打开：`bothouse daemon autostart on`，或者在管理面板「设置」里改。
- **以后想再打开管理面板**：终端里敲 `bothouse web`。

::: tip 电脑睡着了也会下线
bothouse 跑在你的电脑上。电脑关机或睡眠，队员就不在线。要一直在线，得让这台电脑一直开着。
:::
