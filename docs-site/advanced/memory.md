# 团队记忆

队员们共用一本**笔记本**：就是你电脑上的一个文件夹（默认在 `~/wiki`），里面是普通的文本文件（.md），你能直接打开看、打开改。

- **聊完会自动整理进去**：做过的事、你说过的习惯，会被记下来。每半小时、每天晚上各整理一次。
- **下次会带上**：聊到相关的事，队员会先翻笔记本里相关的那几页。
- **你说了算**：觉得哪条记错了，直接打开文件改掉或删掉。
- **可以备份**：会用 Git 的话，可以把这个文件夹备份到你自己的 GitHub 私有仓库。不会也不影响使用。

想手动配置记忆，或者想知道它怎么挑出相关的那几页，见仓库里的[记忆配置说明](https://github.com/zuiho-kai/bothouse/blob/main/docs/ccm-and-wiki.md)。
