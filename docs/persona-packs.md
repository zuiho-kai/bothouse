# 角色库：人设、头像和包

bothouse 自带一个角色库。人设和头像都放在库里，建角色时从库里挑一张卡片就行。库按「包」组织：自带一个默认包，你自己做的东西进「我的」包，别人做好的包也能一键装上。

## 在哪用

- **安装向导第 3 步（人设）**：每个角色一排人设卡片。点「用这个」，人设全文填进下方文本框，头像跟着人设走。文本框里还能接着改。
- **网页后台「角色库」页**：三个标签页，人设、头像、包。

## 人设和头像

- 新建、编辑、复制、删除都在卡片上。删除后底部会出提示，点「撤销」就回来。
- 默认包和装上的包里的东西不会真删，只会隐藏；勾「显示已隐藏的」可以再显示。
- 改了默认包或装上的包里的人设，会在「我的」里存一份副本，原件不动；点「恢复默认」删掉副本。
- 改完人设，正在用它的角色会一起更新（只替换向导写的那一段，你手写的部分不动），提示里会列出更新了哪些角色。
- 头像可以拖进来或点选上传，自动居中裁成正方形，圆形预览。没有头像的人设显示名字首字圆标。
- 向导里选了带头像的人设：Discord 机器人会换上这张头像（只试一次，没设上会提示你去 Discord 开发者后台手动换）；自建平台和 DSH 频道里成员也显示这张头像。

## 包

一个包就是一个 zip：

```
manifest.json          {"id":"my-pack","name":"我的包","version":"1.0.0","license":"CC-BY-4.0","author":"...","description":"..."}
personas/<slug>.md     一个人设
avatars/<slug>.png     一张头像（png、jpg、jpeg、webp、gif）
```

人设文件开头可以带一段属性，后面是人设全文：

```
---
name: 女仆长
intro: 可靠的女仆长，管日程、记提醒、催进度。
avatar: orange
---
（人设全文）
```

`avatar` 写头像的 slug，可以是包里 `avatars/` 下的图，也可以是库里已有的头像。slug 只能用小写字母、数字、`-`、`_`，最长 32 个字符。

在「包」标签页：

- **安装**：上传 zip 或填一个 https 链接，先看预览（有哪些人设和头像、会替换哪个已装版本、和哪些包同名），确认后才装。
- **启用 / 停用 / 卸载**：停用后包里的东西暂时不出现；默认包和「我的」不能卸载。
- **导出**：把「我的」里挑中的人设和头像打成一个包，填名称、版本和许可证（必填）后下载，发给别人就能装。

同一个 slug 出现在多个包里时，按这个顺序取：我的 > 装上的包（按包 id 排）> 默认包。

## 存在哪

```
<数据目录>/library/
  packs/<包 id>/       装上的包
  packs/mine/          我的包
  state.json           停用的包、隐藏的条目
  trash/               每个 slug 最后删掉的一份，用来撤销
```

默认包编在程序里，只读。接口说明见 `bridge/core/library_api.go` 文件头。
