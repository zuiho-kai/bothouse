## CLI 目录错误验证

main 的 CLI 使用实例目录，尚未支持 #398 的每频道目录。新增回归通过 Hub 收到 `@CC`，进入 DshMembers 调度，再调用真实 CliMember 和 Node 子进程 spawn；cwd 为临时目录下一个从未创建的路径。没有调用真实模型或网络，操作系统因 cwd 不存在而拒绝创建进程。

验证结果：频道错误状态和系统消息包含频道名、实际 cwd、原始 ENOENT；ACP sessions/saved 为空，绑定保持 cli 占位值，原生会话创建数为零。旧实现测试失败于缺少频道名，错误仅为「本机 CLI 未能正常运行或已退出，请检查安装和登录状态。」；补丁后该回归通过。中文路径全目录运行 231 项，229 通过、2 失败；失败是 main 上已知的提醒命令与 G24 工作区命令 URL.pathname 问题，由 #405 单独处理，本分支不修。这里覆盖本地派发至进程启动错误的链路，不宣称覆盖已登录 CLI 的模型回合、浏览器展示或每频道目录。

## 真机验收清单（尚未执行）

使用单独测试 profile、临时数据库和测试目录，不使用生产数据库或现有真实 bot。记录实际构建 SHA、main 基线、Node/CLI 版本、系统 locale、配置、每步结果与错误。记录不包含 token、完整对话或个人路径。若独立测试 profile 无法隔离真实帐号/频道，先停止并取得明确授权。

### 1. 升级后可见范围

1. 在旧版测试库创建聊天频道 A、B；添加从未发言的 UI 成员 U，以及一个配置成员 C。保存测试库副本。
2. 升级到包含频道归属迁移的构建并启动。检查 U 在 A、B 可见，成员记录归属为升级时已有聊天频道。
3. 重启再检查归属不变；编辑 U 名字/模型后归属不变。
4. 明确核对全局例外：配置成员省略 rooms 或显式全局成员仍全局可见，不误记成迁移失败。

预期：迁移只执行一次；从未发言成员不丢失；已有显式归属不被改写；空频道快照延迟迁移。

### 2. 新建频道为空

1. 在隔离实例使用仅 UI 成员、无显式全局成员和无无归属 bot 的配置。
2. 升级后新建 C。检查成员列表、提及候选、主角色选择和任务分配候选。
3. 在 C 新增成员 V，再看 A/B；在 C 的子工作区检查 V。
4. 单独用全局配置成员重做一次，记录全局例外行为。

预期：无例外时 C 仅 owner，没有 agent；V 只在 C 及其占用工作区可见。旧 /collab 与原生页面一致。全局例外按文档出现。

### 3. 两频道目录

1. A、B 分别配置独立绝对路径，目录名覆盖中文、空格和百分号。用测试成员新建会话，各写一个带不同内容的标记文件。
2. 检查标记只出现在各自目录；将共享工作区先交给 A，完成释放，再交给 B 并新建会话，重复检查。
3. 修改目录配置：确认旧原生会话继续使用原 cwd，按文档 /new 后新会话使用新 cwd；CLI 不复用另一目录的进程。
4. 将 CLI 的目标设为不存在的目录，触发一轮；检查频道名、实际路径、底层错误均可见，目标和回退目录都没有生成标记/新 ACP 会话。

预期：工作区继承当前占用聊天频道；空目录配置使用实例默认；无效目录不静默回退。模型文件写入和 CLI 目录行为均须独立记录，自动测试不能代替此项。

### 4. 双 bot

1. 使用两套隔离测试 bot 连接，分别归属 A 和 B（使用不同 bot id，可用相同显示名）。
2. 在 A/B 各发送普通消息、显式点名和回复，分别观察两个连接实际收到的帧。
3. 检查普通回复、按钮正文、任务卡创建/编辑的提及显示；创建任务提醒并检查 nudge 目标。
4. 断开一个 bot 并重连；检查离线成员退出候选、历史保留，且另一个 bot 不受影响。

预期：各 bot 只收到所属频道和当前归属工作区的消息；名字不造成跨频道误路由。reply/buttons/body 的剩余审查项未修复前，不能将该完整条目标为通过。

### 5. 退出不崩与恢复

1. 在隔离实例启动原生成员、CLI 成员和 bot；制造正在流式输出的草稿，然后正常关闭应用。
2. 检查进程退出，无关库后的数据库访问异常、重复清理异常或残留后台 CLI。
3. 再打开测试 profile，触发旧会话恢复，检查工具集实际可用；检查成员归属与目录仍正确。
4. 分别覆盖正常完成后退出、流式中退出和连续关闭清理。

预期：close 幂等，晚到草稿清理安全；恢复工具集不丢失。保留时间戳和必要错误片段，不将自动模拟的 shutdown 冒充桌面实跑。
