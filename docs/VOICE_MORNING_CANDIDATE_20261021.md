## 可重复的识别诊断

用已有 MLX 环境执行，模型和合成 WAV 都必须是本地文件：

```sh
python companion/tools/profile_asr.py --model /absolute/local/model \
  --synthetic-wav /absolute/synthetic.wav --prewarm --repeats 2
```

工具仅在独立进程临时包裹 MLX 解码器，退出/异常后恢复方法；不接麦克风、HTTP、桥接、TTS 或扬声器。无线上配置更改，输出仅数值、计数和错误类型。编码采用 `eval` 同步归因，会改变流水时序；结果适合定位阶段，不能代替原路径性能验收。请勿把工具导入服务或并发运行。多次 decode 不一定是回退，也可能是多段音频，须一起看各次 temperature。
