# 用中继连另一台电脑（不在同一个 Tailscale 时）

两台电脑只要都能上网，不需要装 Tailscale、不需要公网 IP、也不用改路由器端口，填上同一个自托管或社区中继地址，就能在 DSH「其他电脑」里互相打开频道、工作台和面板。

## 什么时候用 Tailscale，什么时候用中继

- **已经在用同一个 Tailscale**：直接用页面上方的「生成数字」（6 位码）最简单，走内网直连、没有单次请求大小上限，也支持手机浏览器直连。
- **公司电脑连家里电脑 / 不方便装 Tailscale / 跨网络**：展开页面下方的「**不在同一个网络？用中继**」，两台电脑都主动往外连中继服务器，内容全程端到端加密。

## 三步配好

1. **准备一个中继地址**
   - 自己起：在任意有公网 HTTPS（或 Cloudflare Tunnel）的机器上运行仓库里的 `tunnel-relay/`（见 `tunnel-relay/README.md`）。
   - 或向朋友 / 社区运营者获取一个 `https://...` 地址（若对方开启了准入码，一并拿到准入码）。
2. **被连的电脑（宿主）填地址并生成连接串**
   - 打开 DSH 左栏「**其他电脑**」，展开底部「**不在同一个网络？用中继**」。
   - 填入中继地址（私有中继再填准入码），点「**保存并连接**」，等待状态变为「**已连上**」。
   - 点「**生成连接串**」，页面会显示一行一次性连接串、二维码和 5 分钟倒计时。
3. **要发起连接的电脑（访问端）粘贴并确认**
   - 同样打开「**其他电脑** → **不在同一个网络？用中继**」，把连接串粘贴进右侧输入框。
   - 页面会显示要连的中继地址和对方指纹（前后 8 位），核对无误后选「临时」或「记住这台电脑」，点「**确认连接**」。
   - 连上后，对方会出现在「**我连着的电脑**」列表里并标有「**中继**」标签，点「**打开**」即可像本机一样操作；宿主随时可以在「**已连接的设备**」里一键「**踢掉**」。

> 提示：单次经中继转发的请求体上限为 **1 MB**（受中继默认限制）；大文件附件上传建议改用 Tailscale 直连。

## 中继能看到什么

| 中继看得到 | 中继看不到 |
| --- | --- |
| 两台电脑的 IP、连接时间、流量大小、本机公钥指纹（hostId） | 你打开了哪个频道或接口、聊天消息正文、设备凭据、配对长码 |

两台电脑之间的所有内容均采用每次请求独立的临时密钥进行端到端加密（X25519 + AES-256-GCM），并且配对时双方会互相交换并固定各自的 Ed25519 公钥：中继若试图替换宿主公钥，访问端在本地指纹校验阶段直接拒绝；外部机器即使拿到你的 `hostId`，因为私钥不在宿主的已配对公钥白名单里，请求到达你电脑后会在解密前被直接丢弃；一次性 128 位配对长码 5 分钟有效、错 5 次立即作废。

## 常见报错与处理

- **中继需要准入码，或填写的准入码不对**：该中继开启了准入码限制，请确认准入码填写正确后重新点「保存并连接」。
- **连不上中继服务器**：检查中继地址是否以 `https://` 开头、网络是否能访问该域名，或确认中继容器/隧道正在运行。
- **对方电脑现在不在线**：中继通着，但被连的那台电脑关机、DSH 未启动或还没连上中继。
- **连接已断开，请重新配对**：被对方点「踢掉」或临时连接到期，在宿主重新生成连接串即可。
- **对方身份变了，请重新配对**：对方重置了身份密钥，或中继返回了不匹配的公钥；请向对方核实后重新配对。
- **这条连接串已过期 / 配对失败次数太多**：连接串 5 分钟有效、最多试错 5 次且只能用一次，在宿主重新点「生成连接串」即可。
