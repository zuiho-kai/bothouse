# 网关首包计时与失败清理

2026-10-21，本地候选，未部署。

原playing回执在整段音频按实时节奏发送后才上报，将它当首包会包含整段剩余时长。新日志在第一个`send_bytes`成功返回后单独记录`first_audio_packet`，原回执顺序和完整成功终态约束保持不变。这个时刻是socket发送完成，不是扬声器实际出声。

`recognition_complete`记录解码、ASR请求和本轮函数开始以来的耗时；`first_audio_packet`记录提交调用开始以来、下载和编码耗时。日志只包含阶段、毫秒和字数，不记录正文/音频/凭据。收音结束到任务实际开始之间的时间不在`since_turn_start_ms`内。

空Opus编码不能发tts.start，也不能伪报completed。失败调用上游stop释放占位；HTTP错误或3秒超时不算成功，保留轮次句柄，下一次显式abort/listen只重试幂等stop。清理未确认前不自动收下一轮，不重投模型请求。异常清理中再次取消也保留句柄，旧轮finally不能清掉不同的新轮。

验证：42项网关unittest含真实ffmpeg通过。新增回归覆盖首包与长chunk回执的时间差、空编码、stop失败阻止收音、播放期间取消、异常清理期间取消。两个取消窗口均实跑旧逻辑失败后修复。独立复审最终未见剩余阻塞。
