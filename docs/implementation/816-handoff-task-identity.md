# #816 工作区交接与任务状态一致性

新任务绑定复用工作区，但没有新交接记录时，旧交接在绑定前已暂停，任务板仍会把新任务显示成暂停。

投影现在排除绑定前已经结束的交接；有 Board ID 时要求任务一致，有标题时匹配完整标题、已有短名及 ws-handoff 的 task[:60] 截断格式。无标题是合法旧接口形状，保持原生命周期判定。显式任务板暂停保持有效，不改生产交接或释放逻辑。

独立审阅发现初版忽略无标题、长标题交接，并用测试 Board ID 掩盖了回归，已恢复原夹具并补长标题回归。初版固定入口强制 claim 会破坏池外固定频道，已撤回；派活入口保持原实现。现场缺少新交接的历史写入原因尚未证明，不冒称已修复该原因。

验证包含原问题修前红、修后绿、当前真实暂停和结束、旧任务晚到记录、同任务释放后续接、无标题及长标题生命周期。最终检查与独立审阅以 PR 记录为准。未操作生产状态、配置或工作区，未部署。
