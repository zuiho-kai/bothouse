# Discord 空闲工作区收纳

关联 Issue #1351。工作区最后一项任务结束或暂停、放回共享池后，Discord 适配器将频道移入「空闲工作区」分类；首次使用时尝试创建分类。再次认领或复用时移回共享池的活动分类。归还后的异步搬动会重新检查归属，避免把刚被认领的频道收走。

core 通过可选接口 `TeamWorkspaceShelver` 调用平台能力，以 `TeamChannel.Shelved` 将收纳后的工作区继续计入共享池的复用、编号和列表。其它平台不实现该接口，沿用原流程。权限和网络错误只记录日志，不阻断释放或派活。

归属以本桥的持久登记为准：Discord 在数据目录的 discord_workspace_shelves.json 记录每个服务器的收纳分类 ID 和本桥收纳过的频道 ID。再次收纳优先使用已登记的分类；未登记或分类已删除时，可按名字选择目标并显式记录日志，但该名字不构成对其下频道的归属证明。同名空闲分类中的陌生频道（包括本桥使用的空闲分类中的陌生频道）不会进入共享池候选列表，因而既不参与池位置投票，也不会被自动认领或搬走。记录在搬动前原子保存；保存失败则不搬，读取失败只记录日志并保留活动分类的正常流程。没有登记的手动放入频道不会自动被接管。

- 旧审稿的“未发现阻断”结论已撤回：按同名分类批量标记 Shelved 会误认领陌生频道。本次补入两条回归，分别覆盖两个同名分类只认本桥频道、陌生频道不被自动认领且不发搬动请求；旧实现两条均失败，新实现通过。另覆盖记录落盘与重新加载后继续认出本桥分类及频道。本次修改待非作者重新审核。

权限前提：自动创建分类要求机器人在服务器级有「管理频道」；也可以由服务器管理员先创建该分类并授予机器人该分类的管理权限。Discord 客户端的折叠状态由用户控制，需要手动折叠一次。没有分类的目标频道暂不能通过当前 SDK 的 ChannelEdit 清空 parent_id；这种情况记录错误、继续派活，频道仍在空闲分类。
