# bothouse 的目标与验收

bothouse 是可接入不同平台的团队协作与记忆插件。用户已有的 Claude Code、Codex、Gemini、DSH 等智能体各自保留身份和会话，在同一频道分工、交回结果，并按需读取有来源的共享记忆。

## 首次使用

1. 安装预编译程序，运行后自动打开向导。
2. 选 Discord、飞书或自建平台；本机平台能够一键启动。
3. 给角色选择本机已有的 CLI，设定人设和默认接话的角色。
4. 保存后在频道点名，看到属于该角色的真实回答。

本机 CLI 的安装与登录是使用模型的前提。共享 wiki 和按语义判断谁回话的 gate 是另行配置的组件；只走基础向导不会自动获得它们。飞书当前按单角色接入，DSH 平台走独立首次安装流程：检测 dsh、安装插件、交接启动命令，角色和模型等在 DSH 页面配置。

## 团队与记忆

| 用户操作 | 验收时要看到什么 |
| --- | --- |
| 点名一个角色 | 目标角色回答，其余角色保留上下文 |
| 让队长派活 | 队长点名队员，队员执行并把结果交回，队长汇总 |
| 重新配置或增加角色 | 原有平台、队伍、默认角色和手写人设按文档边界保留 |
| 问到已有约定 | 配好 wiki 后，检索出可追溯的记录；没有来源就说明不知道 |
| 重启或换入口 | 按后端实际支持的会话恢复能力接续，失败须明确反馈 |
| 提交实际任务 | 给出可检查的文件、测试或 PR，明确未完成和失败 |
