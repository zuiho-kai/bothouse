## Highlights

- **Teams work in containers and without write access.** In a container install, wiki tidy-up after a session no longer fails with "Not logged in", large batches no longer hang on a 20-minute timeout, and the nightly scoring runs (#1162). Nightly scoring and stale-memory checks use the nightly model you picked in the wizard instead of a hard-coded CLI, and tell you which wizard item to change when that CLI is missing (#1170). `pr-push` forks and opens the PR when the `gh` account has no write access (#1164), and `bash-guard` points to `pr-push` when a `git push` is rejected (#1167).
- **Any ordinary model can be the gate.** Gate scoring works with a service that returns only the chosen option letter and no probabilities, and turns thinking off for DeepSeek-style reasoning models; when the wizard leaves the gate model empty, the first role model with an API key is tried once and kept only if it passes; when the gate cannot decide (no model, down or timed out) and the bot replies anyway, the turn starts with a reminder to size the task first (#1173). `bothouse setup jev` tests and saves only the gate model, without re-running the whole wizard (#1175).
- **A model refusal no longer stalls a review.** When the reviewer's model refuses, it posts one line and the review is handed to another teammate (or the lead checks it); the review prompt opens neutrally as a check of the product's own fix; scheduled turns that post into a human chat channel go through the reply-length check (#1165).

## Fixes

- A teammate's ordinary reply in a workspace is no longer bounced as a malformed hand-back when the open handoff belongs to someone else (#1168).
- Hooks run in UTF-8 through the hook entry point, so Chinese Windows systems no longer garble hook input and output; installed hooks need no reinstall (#1169).

## Improvements

- **Workspace turns have a step and time cap.** A workspace turn that reaches 81 steps or 20 minutes (whichever comes first; set in `hooks/ws-cap.json`) only allows wrap-up calls (write the handoff, push the branch, `ws-up`, report) and is told to record progress and hand back; scheduled, handoff and review turns are not exempt. The default is the 95th percentile of real workspace turns (#1171). Lead playbooks: heavy reviews woken by a timer are handed to a workspace, the timer only starts them and the lead only reads the result (#1178).
- Removed the chat-channel "8 read-only steps" stop for DSH leads added in v0.1.54 (#1148); the threshold had no data behind it and will be set again from real usage (#1172).

## 重点

- **容器里、没写权限也能跑团队。** 容器装法下，会话结束后的 wiki 整理不再报 Not logged in，大批次不再卡在 20 分钟超时，夜间结算能跑完（#1162）。夜间结算和过时记忆检测改用你在向导「每晚」里选的模型，不再写死某个命令行；那个命令行不在时，提示去向导哪一项改（#1170）。`gh` 账号没有写权限时，`pr-push` 自动 fork 再提 PR（#1164）；`git push` 被拒时，`bash-guard` 提示改用 `pr-push`（#1167）。
- **普通模型也能当闸门。** 服务不给概率、只回一个选项字母时也能打分，DeepSeek 这类推理模型会关掉思考；向导没填闸门模型时，用第一个带 API key 的角色模型试一次，过了才存；闸门判不了（没模型、挂了或超时）而照常回复时，这一轮开头加一句「先分大小」的提醒（#1173）。`bothouse setup jev` 只测试并保存闸门模型，不用重跑整个向导（#1175）。
- **模型拒答不再卡住验收。** 验收人的模型拒答时只发一句话，验收转给另一个队友（都不行就由主角色自验）；验收提示开头说明这是核对自家产品的修复；定时轮的回复贴进真人聊天频道时，也走回复长度检查（#1165）。

## 缺陷修复

- 工作区里开着的交接不是交给自己的时候，队友的普通回复不再被当成格式不对的交回退回（#1168）。
- 钩子总入口统一用 UTF-8，Windows 中文系统上钩子的输入输出不再乱码；已装的钩子不用重装（#1169）。

## 改进

- **工作区一轮有步数和时长上限。** 工作区一轮跑满 81 步或 20 分钟（先到先算，可在 `hooks/ws-cap.json` 改）后，只放行写交接、推分支、`ws-up`、交回这类收尾调用，并提示记下进度交回；定时、交接、验收轮都不豁免。默认值取真实工作区轮次的 95 分位（#1171）。主角色手册：定时叫起来的验收重活交工作区跑，定时只起活，主角色只看结果（#1178）。
- 撤掉 v0.1.54 加的 DSH 主角色「聊天频道连查 8 步就拦」（#1148）：这个门槛没有数据依据，之后按实际使用数据重定（#1172）。
