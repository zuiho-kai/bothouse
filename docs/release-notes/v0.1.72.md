## Highlights

- **Install straight onto a Linux server, no Docker.** New `bothouse daemon autostart [on|off]` turns start-on-boot on or off on a server with no browser, and warns a normal user whose account has no linger. A system service installed as root now carries the installer's HOME, so the bridge no longer stops with `$HOME is not defined` and the AI CLIs find their sign-in. The advanced install guide has a new "Linux server install (no Docker)" section (#1708).
- **A model error is no longer taken as a hand-back.** When a DSH member's reply is a model error (overloaded, timeout, auth), the task is marked as errored, the lead accepts nothing, and the next call sends the work again. The channel shows one Chinese line and the raw error is folded under it (#1715).

## Fixes

- **DSH and first-run fixes from a new-user walk:** DSH CLI members hand work out with @ only; a "thanks" after a hand-back no longer opens a task; task titles keep an @name in mid-sentence; an explicit @ after a delivery waits for the stance. The DSH wizard suggests the names 小橙/小蓝 with the name field outside and says install takes about 4 minutes. The QQ wizard is titled as a NapCat QQ account, with the official bot as a switch (#1712).
- **Hidden setup that new users tripped on:** the team line says to hand work to teammates with @, not the CLI's own sub-agent tools; `install.sh` prints one PATH fix you can paste; setup says the hourly mood job is off and how to turn it on; the chat is told when the model has been retrying for 30 s or more; wizard Codex roles no longer ask for a manual /hooks review; first-run setup writes the team line; docs say `allow_from` defaults to `*` when a server is set (#1711).
- **Fewer false blocks from the reply checks:** the check-first guard is off in team chat channels and looks further back in long workspace turns; vague times such as "tomorrow" no longer count as a timed promise; sentences about the system, a workspace or a teammate are not the agent's promise; a report's doubt no longer needs a quoted line (#1709, #1710).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.72`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **Linux 服务器可以直接装，不用 Docker。** 新命令 `bothouse daemon autostart [on|off]`，没有浏览器的服务器也能开关开机自启；普通账号没开 linger 时会提示。root 装的系统服务现在带上安装者的 HOME，桥不再报 `$HOME is not defined` 停下，AI CLI 也能找到登录。进阶安装文档新增「Linux 服务器直接安装（不用 docker）」一节（#1708）。
- **模型报错不再算交回。** DSH 成员的回复是模型报错（满载、超时、鉴权）时，任务记为出错，主角色不验收，下一次调用会重新派出。频道里只显示一行中文，原始报错折叠在下面（#1715）。

## 缺陷修复

- **DSH 和首次使用的修复（来自新手实走）：** DSH CLI 成员只用 @ 派活；交回后说「谢谢」不再开出新任务；任务标题保留句中的 @名字；交付后再明确 @ 会等对方表态。DSH 向导默认名字是小橙/小蓝，名字框放在外面，安装提示约 4 分钟。QQ 向导标题写明是 NapCat QQ 账号，官方机器人改成开关（#1712）。
- **新手踩到的隐藏配置：** 团队说明改为用 @ 把活交给队友，不用 CLI 自带的子 agent 工具；`install.sh` 打印一条能直接粘贴的 PATH 修法；设置里说明每小时心情任务默认关、怎么打开；模型重试超过 30 秒时在聊天里告诉你；向导建的 Codex 角色不再要求手动 /hooks 审核；首次设置会写入团队说明；文档写明配了服务器时 `allow_from` 默认是 `*`（#1711）。
- **回复检查少误拦：** 「先查再说」检查在团队聊天频道关闭，长的工作区轮次往回看得更远；「明天」这类含糊时间不再算定时承诺；主语是系统、工作区或队友的句子不算角色的承诺；汇报里的存疑不再要求附引文（#1709、#1710）。
