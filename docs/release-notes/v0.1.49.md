## Highlights

- **DSH now works on Windows.** An outside user installed bothouse + DSH on Windows and hit a chain of failures; this release fixes all of them and the same class of problems across the repo: the DSH proxy no longer returns 503, the tray reads DSH-only configs, gate starts with a real cross-process file lock, channel plugins load after an upgrade, the embedded panel no longer opens blank under `/dsh/`, @-mentioning a member no longer fails with `reading 'slice'`, Chinese Windows no longer breaks on GBK, and task scripts, permission hooks and local CLIs are found. CI now runs Windows-only tests on a real Windows runner. Thanks @sgepk203619-a11y for the detailed report and PR #1011 (#1035, #1036, #1037, #1044, #1045, #1046, #1047, #1048).
- **The panel shows DSH members.** With only DSH installed, the Roles page, Overview and Sessions now list DSH members, projects and channels instead of zeros (#1039, #1043, #1049). A new Apps page shows the real state of QQ, Discord, Feishu and DSH, and Wiki Galaxy moves into the panel (#1014, #1021).
- **A reworked channel page.** New layout with activity bar, run strips, step chips, a task board beside the chat, teammates with busy/idle dots, a "waiting for you" tray, a / command menu, Markdown and attachments, light theme by default, and long histories that stay fast (#934, #944, #946, #953, #970, #971, #972, #973, #975, #977, #978, #979, #994, #995, #1001, #1004, #1015).
- **Command DSH from a second computer.** Pair two computers with a number code, and the DSH desktop host uses a fixed bot port (#982, #1012).

## Fixes

- **Re-running the setup wizard no longer creates duplicate members** (Codex-2, 鲸鱼娘-2, DSH-2); team files carry the real member names (#1038, #1040, #1042).
- **DSH and collab stay connected:** stale `dsh-web.json` heals from the host log, the gate port is found without `GATE_PORT`, memory badges fall back to gate's data dir, and kicked computers disappear at once (#1024, #1025, #1028, #1030).
- **Three panel entry bugs fixed:** token links, 0 platforms on the Bridge page, and blank screens on unknown routes (#1017).
- **A quota lock that could freeze the bridge is gone** (#996).
- **Cleaner replies:** punctuated NO_REPLY is suppressed, QQ no longer repeats narration or adds leading spaces and recovers paged history after reconnect, raw backend errors stay out of group chats, and greetings and queued messages survive an abort (#956, #957, #992, #998, #999, #1000).
- **Workspaces and the task board:** unreturned items go back to their workspace, reports carry their images to the chat channel, cron/timer posts reach the main session, `send` finds the current session inside DSH, the hourly workspace release runs on its own loop, and ACP cooldown keys are per backend (#949, #950, #958, #960, #962, #965, #976).
- **Small channel fixes:** right-click an avatar to mention its author, no redundant progress for zero/one-step tasks, consecutive bash steps counted correctly, and two out-of-scope items removed (#988, #989, #991, #1005).
- **Hooks and config:** casual replies are not blocked as work, fixed schedules are not treated as durations, and a misplaced `admin_from` now reports where it belongs (#993, #1007, #1009).

## Improvements

- **Review runs itself:** a non-author reviewer is picked automatically, the review model can be set per tier, small merged tasks close themselves, busy assigners hand acceptance to an idle teammate, and reports self-check before they are sent (#967, #969, #974, #1002, #1003, #1022).
- **Context:** a catalog is injected and bodies are fetched on demand with `bothouse ctx`, gate logs injected sizes, and session swaps keep minutes and rolling memory (#954, #959, #968).
- **Setup:** new Discord bots get default `allow_guilds`, and the wizard sets up a wiki cron without a default channel and stricter role wiki rules (#964, #1052, #1053, #1055).
- **CI catches stale DSH bundles on DSH-only PRs** (#1006).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.49`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 在 Windows 上能用了。** 一位外部用户在 Windows 上装 bothouse + DSH 连着碰壁，这一版把他碰到的和全仓同类问题一起修掉：DSH 代理不再 503，托盘能读只装 DSH 的配置，gate 用真正的跨进程文件锁起得来，升级后频道插件能加载，经 `/dsh/` 打开内嵌面板不再白屏，@成员不再报 `reading 'slice'`，中文 Windows 不再因 GBK 出错，派活脚本、权限 hook 和本机 CLI 都能找到。CI 新增在真 Windows 上跑的专项测试。感谢 @sgepk203619-a11y 详细的报告和 PR #1011（#1035、#1036、#1037、#1044、#1045、#1046、#1047、#1048）。
- **面板能看到 DSH 成员。** 只装 DSH 时，角色页、概览、会话页列出 DSH 成员、项目和频道，不再全是 0（#1039、#1043、#1049）。新增接入应用页，显示 QQ、Discord、飞书、DSH 的真实状态；Wiki 星河并进面板（#1014、#1021）。
- **频道页改版。** 新布局带活动栏、执行条、步骤标签、聊天旁的任务板、队友忙闲圆点、「等你定」托盘、/ 命令菜单、Markdown 与附件，默认浅色，长记录不卡（#934、#944、#946、#953、#970、#971、#972、#973、#975、#977、#978、#979、#994、#995、#1001、#1004、#1015）。
- **从第二台电脑指挥 DSH。** 两台电脑用数字码配对；DSH 桌面宿主用固定 bot 端口（#982、#1012）。

## 缺陷修复

- **重跑安装向导不再多建成员**（Codex-2、鲸鱼娘-2、DSH-2）；团队文件写成员真名（#1038、#1040、#1042）。
- **DSH 与协作保持连通：** `dsh-web.json` 过期时从宿主日志自愈，缺 `GATE_PORT` 也能找到 gate 端口，记忆徽标按 gate 数据目录回退，被踢的电脑立刻消失（#1024、#1025、#1028、#1030）。
- **面板三个入口缺陷：** token 链接、桥接页 0 平台、未知路由白屏（#1017）。
- **去掉一个会卡死桥的额度锁**（#996）。
- **回复更干净：** 带标点的 NO_REPLY 也会被吞掉；QQ 不再重复旁白、不再多前导空格，重连后能补回分页历史；群聊不外发后端原始报错；中断时保留问候和排队消息（#956、#957、#992、#998、#999、#1000）。
- **工作区与任务板：** 没交回就结束的条目放回工作区，交回汇报带图到聊天频道，cron/timer 帖子补给主会话，DSH 里 `send` 能找到当前会话，每小时放回工作区独立成循环，ACP 冷却键按后端区分（#949、#950、#958、#960、#962、#965、#976）。
- **频道小修：** 右键头像直接提及作者，零步或一步任务不显示冗余进度，连续 bash 按真实次数合并，去掉两项范围外改动（#988、#989、#991、#1005）。
- **钩子与配置：** 闲聊不再被当成干活拦下，固定作息不当工期，`admin_from` 写错层时提示该写哪（#993、#1007、#1009）。

## 改进

- **验收自己跑：** 自动选非作者审核人，审核模型每档可选，合并且检查全过的小活自动收口，派活人忙时转空闲队友验收，交回前自查（#967、#969、#974、#1002、#1003、#1022）。
- **上下文：** 注入目录、正文用 `bothouse ctx` 按需取，gate 记录每轮注入字数，换会话保留纪要和滚动记忆（#954、#959、#968）。
- **安装设置：** 新 Discord 机器人默认 `allow_guilds`；向导在没有默认频道时也建 wiki 定时，角色 wiki 规则更严（#964、#1052、#1053、#1055）。
- **只改 DSH 的 PR 上，CI 也能抓到过期的 DSH 打包**（#1006）。
