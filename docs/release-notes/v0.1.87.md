## Highlights

- **A wake now brings its answer back.** Run `bothouse wake` from inside a conversation to ask another session (same bot, any platform — for example your DSH session from Discord) a question or give it a task. The command returns a `wake_id` with status `accepted`; when the woken session finishes, its final reply — or why it failed — comes back to the conversation that asked, as a new turn, even if that conversation's own turn ended long ago. Wakes sent by event hooks stay one-way as before (#2052, closes #2024).
- **Discord meeting assistant.** With `meeting_assistant = true`, `@bot 开会` makes the bot join your voice channel, transcribe each speaker locally, and when the meeting ends post a detailed record and standard minutes (topics, conclusions, to-dos with owner and deadline). Pictures posted in the channel during the meeting, camera stills and — optionally, with a spare account — screen shares go into the minutes with time and person (#2022, #2023, #2029).
- **Feishu catches up with Discord.** Feishu gains team dispatch (lead and members, hand-back to the lead), `send --dm` and `send --channel`, channel history read-back, the channel task board and more; `docs/FEISHU_PARITY.md` lists every Discord feature against Feishu. Covered by tests; not yet run against a live Feishu app (#2025).
- **JiuwenSwarm plugin.** A pip-installed JiuwenSwarm can carry the bothouse role's persona and memory wiki, installed the same way as the DSH plugin — an extension plus a version-checked patch, nothing changed upstream (#2016).
- **Native Windows window for the web panel (contrib).** An optional WebView2 window shell under `bridge/contrib/webview2-window/`; the tray app is unchanged. Thanks @NethielChou (#2030).
- **Connect a local DSH in a few clicks.** Projects → Add platform → DSH (local) lists DSH's group channels and saves the choice on the existing project; the bridge finds DSH Desktop even after it changes port. Thanks @Hiennoob123 (#2004).

## Fixes

- **`bothouse module list` sees DSH Desktop.** With the Channels plugin enabled only in DSH Desktop it used to say `dsh not configured`; it now checks both the web and desktop profiles, like the management API. Thanks @Hiennoob123 (#2021, closes #2020).
- **A DSH member's memory vote no longer leaks into its reply.** Inside DSH's sandbox the vote could not be written and the model told the user so; the gate now writes the vote for it, and a vote that still fails is dropped quietly (#2028).
- **DSH self-heal finds a restarted DSH faster.** Local ports are probed at once instead of one by one, so a port that accepts but never answers no longer eats the whole 5-second round (#2047).
- **Hand-backs that say "再看" (check again) are read correctly** — on the "等外部" (waiting on something external) line (#2017) and as a clock time like `11-23 18:00` (#2046); an unreadable one is logged.
- **ACP agents (Devin and others):** their own slash commands such as `/context` run as typed (#2043); the reply footer names the model the session actually runs after `/model switch` (#2042); replies show live context use and full sessions rotate (#2039); Devin shows the signed-in account's quota (#2037). Thanks @Zssan12.
- **Role wiki upkeep:** tidying a role's wiki is two tool-free model calls with a script doing the writing, and keeps the first extraction for retries (#2019); a relay outage stops the round without counting a failure (#2044); it can use an OpenAI-compatible API with several batches in parallel (#2045). Thanks @Zssan12.
- **Lead hand-over updates mark items from other channels** with the channel they came from (#2033). Thanks @Zssan12.

## Improvements

- **Auto-cleanup.** At start and hourly the bridge removes run folders and test leftovers untouched for 7 days (never anything a task, skill or unpushed work still uses), logs what it removed, and on low disk cleans once and tells the owner. `bothouse cleanup --dry-run` shows what would go; `[cleanup] enabled = false` turns it off (#2032).
- **Questions from a workspace reach you in plain words.** The lead must rewrite them before passing them on; bridge-internal problems stay with the lead (#2031).
- **Discord `ack_emoji`.** Each bot can pick its own "received" reaction instead of 👀 (#2027). Thanks @Zssan12.
- **Test reliability:** a DSH upload-cleanup test waits for the cleanup instead of sampling once (#2000).

## 重点

- **叫醒别的会话，答案会送回来。** 在一个对话里运行 `bothouse wake`，可以问另一个会话一件事或派它一件活（同一个机器人、哪个平台都行，比如在 Discord 里叫醒自己的 DSH 会话）。命令马上返回 `wake_id` 和「已接受」；对方做完后，它的最终回复——或者失败原因——会作为新的一轮回到发起的对话，就算发起那一轮早已结束也一样。事件钩子发的叫醒照旧是单向的（#2052，关闭 #2024）。
- **Discord 会议助手。** 打开 `meeting_assistant = true` 后，`@bot 开会` 让机器人进你所在的语音频道，按人在本机转写，会议结束时发详细记录和标准纪要（议题、结论、带负责人和期限的待办）。开会期间频道里发的图、摄像头画面，以及（可选，用一个备用账号）屏幕共享，都按时间和人写进纪要（#2022、#2023、#2029）。
- **飞书补齐 Discord 的功能。** 飞书支持团队派活（主角色和成员、交回 @ 主角色）、`send --dm` 和 `send --channel`、回读频道历史、频道任务板等；`docs/FEISHU_PARITY.md` 逐项列出 Discord 功能在飞书上的情况。已有测试覆盖，还没在真实飞书应用上跑过（#2025）。
- **JiuwenSwarm 插件。** pip 装的 JiuwenSwarm 可以带上 bothouse 角色的人设和记忆 wiki，装法和 DSH 插件一样：一个扩展加一个按版本校验的补丁，不改上游（#2016）。
- **网页面板的 Windows 原生窗口（附加组件）。** `bridge/contrib/webview2-window/` 下新增可选的 WebView2 窗口壳，托盘程序不变。感谢 @NethielChou（#2030）。
- **几下就接上本机 DSH。** 项目 → 添加平台 → DSH（本机）会列出 DSH 的群频道，选好存进现有项目；DSH 桌面版换了端口桥也能找到。感谢 @Hiennoob123（#2004）。

## 缺陷修复

- **`bothouse module list` 认得 DSH 桌面版。** 只在 DSH 桌面版启用频道插件时，以前会显示 `dsh not configured`；现在和管理接口一样，网页版、桌面版两份配置都查。感谢 @Hiennoob123（#2021，关闭 #2020）。
- **DSH 成员的记忆投票不再写进回话。** 在 DSH 沙盒里投票写不进去，模型就把这事告诉了用户；现在由 gate 代写，还是投不上就安静跳过（#2028）。
- **DSH 自愈更快找到重启后的 DSH。** 本机端口改成同时探，收下连接却不回话的口不再吃掉整轮 5 秒（#2047）。
- **交回里写的「再看」能读对了**：写在「等外部」那一行（#2017）、写成 `11-23 18:00` 这种钟点（#2046）都认；读不懂的会记日志。
- **ACP 代理（Devin 等）：** 代理自己的斜杠命令（如 `/context`）照原样执行（#2043）；`/model switch` 后回复脚注写的是会话实际用的模型（#2042）；回复显示实时上下文占用，满了自动换新会话（#2039）；Devin 显示登录账号的额度（#2037）。感谢 @Zssan12。
- **角色 wiki 整理：** 改成两次不带工具的模型调用、由脚本写入，首次提取结果留着给重试用（#2019）；中转站故障时本轮停下、不计失败（#2044）；可以走 OpenAI 兼容接口，多个批次并发（#2045）。感谢 @Zssan12。
- **主角色交接后的更新里，别的频道的条目会标出来源频道**（#2033）。感谢 @Zssan12。

## 改进

- **自动清理。** 桥启动时和每小时清掉 7 天没动的运行目录和测试残留（任务、技能、没推送的工作还在用的一律不动），记下删了什么；磁盘快满时先清一次再告诉主人。`bothouse cleanup --dry-run` 先看会删什么，`[cleanup] enabled = false` 可关（#2032）。
- **工作区的提问用大白话转给你。** 主角色必须改写后再转；桥内部的问题留给主角色处理（#2031）。
- **Discord `ack_emoji`。** 每个机器人可以换掉默认的 👀「收到」表情（#2027）。感谢 @Zssan12。
- **测试更稳：** DSH 上传清理的用例改成等清理完成再判断，不再只看一次（#2000）。
