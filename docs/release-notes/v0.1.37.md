## Highlights

- **Replies to finished work go back where they belong.** When you reply in a workspace to a message from a task that has already been handed back, it no longer slips into whatever the workspace is doing now. It goes to that task's chat channel, where the lead picks it up and carries the task on; the workspace tells you where it went (#628).
- **The lead waits for you to finish talking.** Wake-ups that did not come from you (workspace handbacks, timers) hold until the chat goes quiet, and a handback posted in your chat shows only its first line (#623).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **回复已交回的活，会回到它该去的地方。** 在工作区回复一件已经交回的活，消息不再插进工作区正在做的活，而是转回那件活的聊天频道，由主角色接着做；工作区里会告诉你转去了哪里（#628）。
- **主角色等你说完再开口。** 不是你发起的叫醒（工作区交回、定时任务）会等聊天频道安静下来再处理，贴进聊天频道的交回只显示第一行（#623）。
