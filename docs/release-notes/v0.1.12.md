## Highlights

- **Open the dashboard from your phone or another computer.** The README now has a Tailscale section: run bothouse on one machine and open the same dashboard from any of your devices. The login page fills in the server address from the page you opened, so a Tailscale address or a phone works without typing it.
- **The dashboard works on phones.** On narrow screens the navigation moves into a drawer and the cards stack in one column; project cards no longer overflow. The desktop layout is unchanged.
- **Add a role without restarting.** A role added in the setup wizard starts right away. The bots already running are not touched.
- **Quiet timers.** `timer add --silent` skips the "timer started" notice and still posts the result.

### Fixes

- **Teammates can hand work back to the lead on Discord.** When a bot mentions another bot's role, that bot now treats the message as addressed to it, instead of only reading it as context. Mentions of other roles and broadcast mentions stay listen-only.
- **Task cards show role names.** The executor and member rows on task cards show each bot's configured name instead of its internal id. Cards created before this release show names after their next refresh.

### Improvements

- **New README.** The opening screen now leads with what the team does for you, with a three-step story and a reordered feature list.
- **Login page icon.** The login page shows the bothouse app icon.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **手机和别的电脑也能打开面板。** README 新增 Tailscale 一节：bothouse 跑在一台机器上，你的其他设备都能打开同一个面板。登录页会按你打开的网页地址自动填好服务器地址，用 Tailscale 地址或手机打开时不用再手动输入。
- **手机上能正常用面板。** 窄屏时导航收进抽屉，卡片排成一列，项目卡片不再溢出；电脑上的布局不变。
- **加角色不用重启。** 在配置向导里新加的角色立即启动，已经在跑的 bot 不受影响。
- **定时任务可以静默。** `timer add --silent` 不发「定时任务开始」的提示，结果照常发出。

### 缺陷修复

- **Discord 上队友交活能叫醒主角色。** 一个 bot 提到另一个 bot 的角色时，被提到的 bot 现在会把这条消息当成发给自己的，而不只是旁听。提到其他角色或全体提及仍然只旁听。
- **任务卡显示角色名。** 任务卡上的执行人和成员行显示每个 bot 配置的名字，不再显示内部编号。这一版之前建的卡片，下次刷新后也会显示名字。

### 改进

- **新版 README。** 开头改为先讲团队能替你做什么，加了三步故事，功能列表重新排序。
- **登录页图标。** 登录页显示 bothouse 应用图标。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）
- **校验：** `SHA256SUMS`

从 v0.1.6 起，以后的版本点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。网速慢时，从 v0.1.10 及更早版本一键更新仍可能超时（下载用的是旧版自带的更新程序）；遇到这种情况，请手动下载安装这一版一次。

安装包未签名。macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键→打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息→仍要运行」。
