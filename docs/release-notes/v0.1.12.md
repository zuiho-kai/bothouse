## Highlights

- **Open the panel from your phone or another computer.** The README now explains how to reach the management panel over Tailscale. The login page fills in the address you opened it from, so it no longer defaults to localhost on another device.
- **Better panel layout on phones.** The dashboard fits narrow screens; the desktop layout is unchanged.
- **Add roles without a restart.** A role added to `config.toml` starts on its own; the other roles keep running.
- **Teammates can hand work back to the lead.** When a teammate mentions the lead role in Discord, the lead now picks up the message.
- **Task cards show role names.** The executor and member rows show each bot's configured name instead of its project id.
- **Silent timers.** `timer add --silent` skips the "started" notice; the result is still delivered.
- **Login page icon.** The login page shows the bothouse icon.
- **New README opening.** The first screen of the README now describes how the team works: parallel jobs, checks by a fresh AI, handoffs, and background jobs.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **手机和别的电脑也能打开管理面板。** README 新增通过 Tailscale 访问管理面板的说明。登录页的服务器地址默认填打开页面时的地址，在别的设备上不再显示 localhost。
- **手机上的面板布局更好用。** 面板适配窄屏；电脑上的布局不变。
- **加角色不用重启。** 在 `config.toml` 里新加的角色会自动启动，其他角色照常运行。
- **队友交活能叫到主角色。** 在 Discord 里队友提到主角色时，主角色会接到这条消息。
- **任务卡显示角色名。** 执行人和成员行显示各 bot 配置的名字，不再显示项目 id。
- **静默定时任务。** `timer add --silent` 不发「已开始」提示，结果照常送达。
- **登录页图标。** 登录页显示 bothouse 图标。
- **README 首屏改版。** README 第一屏改为介绍团队怎么干活：多件活并行、由新开的 AI 检查、交接、后台长任务。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）
- **校验：** `SHA256SUMS`

从 v0.1.6 起，以后的版本点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。网速慢时，从 v0.1.10 及更早版本一键更新仍可能超时（下载用的是旧版自带的更新程序）；遇到这种情况，请手动下载安装这一版一次。

安装包未签名。macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键→打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息→仍要运行」。
