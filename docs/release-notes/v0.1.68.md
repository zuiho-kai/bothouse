## Highlights

- **Memory push finds what this message is about.** The per-turn wiki push searches the speaker's own words (a reply quote joins only for short replies like "继续"), drops swear words and filler before ranking, takes only the 20 rarest content words from the two previous turns, pushes the thread floor that actually matched, and no longer pushes indented quote lists or bridge-generated lines as the user's words (#1649).
- **Stale memory is marked and ranked by project.** Rows in a page's `## 历史` section or written as "曾… → 改为…" are pushed with a `【旧】` prefix and only after better rows; rows saying 推测/没核/未验证 get `【未核】`. Pages a channel mostly works on rank before generic rule pages, derived from the existing push log with no new storage (#1652).
- **Team workspaces run on cheaper models.** `workspace_provider` / `workspace_model` start workspace agents on a separate provider (#1597); each handed-off task is routed once from its handoff file to the cheap lane or the lead model, with `执行路由：…` overrides and a `workspace_route.jsonl` log (#1611); split tasks pick DS (DeepSeek through magpie) or the local Qwen by context size and privacy, with `workspace_ds_provider` / `workspace_ds_model` (#1619).

## Fixes

- **`model auto` really goes back to automatic.** It now deletes the saved hand-picked model at once, also when no tiers are configured, so a workspace picked once no longer stays pinned to an expensive model (#1650, #1651).
- **Quota cooldown:** a person naming a cooling-down role gets one real try (success clears the cooldown); subscription logins are keyed per account, so switching accounts no longer keeps the old lock (#1637, thanks @Zssan12).
- **Who a message calls:** one rule decides self / someone else / no one for the gate path, the no-gate fallback and Discord; in a team without a routing model the lead only answers when called (#1615, #1617).
- **Provider proxy** no longer adds `X-Forwarded-For`, which made magpie reject DS workspace sessions as "Not logged in" (#1621).
- **DSH progress card** groups calls of the same tool into one chip (`run_command ×3`) (#1638, thanks @Zssan12).

## Improvements

- **`bothouse send --channel <name>`** finds a channel by name in the current server and echoes the target channel after sending (#1635).
- Docs: source for the `routeDSCtxTokens` cap (#1630).

## 重点

- **记忆推送对准这句话。** 每轮推送用说话人自己的话去搜（回复引用只在「继续」这类短回复时并入），排序前去掉骂词和虚字，前两轮只带最少见的 20 个实词，帖子推真正对上的那一层，缩进的原话清单和桥自动发的话不再当成用户的话推（#1649）。
- **旧说法打标记、按项目排序。** 页内「## 历史」节或写成「曾… → 改为…」的行，推送时带【旧】并排在后面；写着推测/没核/未验证的行带【未核】。频道主要对应的项目页排在通用规矩页前面，从现有推送日志算出，不另建存储（#1652）。
- **团队工作区用便宜模型跑。** `workspace_provider` / `workspace_model` 让工作区用单独的 provider 起（#1597）；每件交出的活按交接文件路由一次，走便宜通道或主角色模型，可用「执行路由：…」指定，记进 `workspace_route.jsonl`（#1611）；拆开的活按上下文大小和是否涉密，在 DS（经 magpie 的 DeepSeek）和本机千问之间选，新配置 `workspace_ds_provider` / `workspace_ds_model`（#1619）。

## 缺陷修复

- **`model auto` 真的回到自动。** 现在当场删掉存下的手选模型，没配档位时也行；手选过一次的工作区不再一直固定在贵模型上（#1650、#1651）。
- **额度冷却：** 真人点名正在冷却的角色时会真试一次，成功就解除冷却；订阅登录按账号记冷却，换账号后旧锁不再留着（#1637，感谢 @Zssan12）。
- **消息叫的是谁：** gate 路径、无 gate 兜底和 Discord 用同一条规则判断叫自己、叫别人还是谁都没叫；没有路由模型的团队里，主角色只在被叫时回答（#1615、#1617）。
- **provider 代理** 不再加 `X-Forwarded-For`，之前 magpie 因此把 DS 工作区会话当成「未登录」拒掉（#1621）。
- **DSH 进度卡** 把同名工具调用合成一个标签（`run_command ×3`）（#1638，感谢 @Zssan12）。

## 改进
