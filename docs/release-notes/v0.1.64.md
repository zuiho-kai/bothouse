## Highlights

- **Standard duty layer for every role.** The persona now only sets character. What a role does in the team comes from a duty layer that the bridge adds by the role's place in the config: the lead in a chat channel only hands out work and sends big jobs to a workspace first, a lead inside a workspace does the job itself, and a helper states its stance and does not hand out work. When the persona and the duty layer disagree, the duty layer wins (#1528).
- **Big jobs go to a workspace first, from anywhere.** The lead no longer reads manuals, opens a task card or reads source before it hands work off. Forum posts and DMs can now hand off to a workspace too, and the 10-minute watch asks the owner to hand the job back instead of finishing it in place (#1523).
- **Shorter reports.** Each of the four parts sent to the user (background, what was done, what you need to do, what I added) may have at most two sentences. A longer part goes back to the workspace to be rewritten; nothing is cut. In a chat channel the lead leads with the conclusion and keeps a reply to five sentences (#1531).
- **Personal agents share lessons with the team.** A teammate can run their own bothouse with their own CLI and quota. `bothouse send --experience` sends them related team lessons with the job, and every `【经验】` line they send back is filed into the team memory (#1516).
- **Codex runs as the role's OS user.** Codex now honors `run_as_user` like Claude Code, so member directories are protected by the kernel for Codex roles too (#1514).

## Fixes

- **Reports for outside users:** check notes go only to the accepting lead, never into the user's parts. Accepting a report also closes it on the task board, so a restart no longer asks for the same review again. The lead sees the full task board and can answer progress questions. A scheduled turn opens no progress card in the chat channel (#1525).
- **Accepting and returning work:** the accept prompt names the task by number, and `ws-pass` / `ws-forward` understand PR, branch and commit links on the board (#1524). A quoted 「要你做的」 is no longer read as the start of that part (#1513).
- **Report attachments:** when a report has a link, document attachments are not sent; images, audio and video still are (#1520).
- **DSH:** the embedded panel serves and accepts the Grok avatar (#1526). DSH collab `[ask]` / `[report]` apply the same self-route check as the bridge (#1522).

## Improvements

- **Kickoff lists what the job already has** (earlier scripts, outputs, decisions), and a `[report]` needs proof from the place the user actually uses (#1512).
- **Find another way first:** a 「要你做的」 that hands the user something the agent could do itself goes back; questions to the user also say whether the step can be undone (#1511).
- **Workspaces have no cap of four**; open a new one instead of queueing (#1519).
- **Panel avatars:** B-style Q avatars for four roles and the Grok avatar in the panel and DSH embedded panel (#1517, #1521).
- **Docs:** `member` subcommands are not available under `run_as_user`, now written down (#1518).

## 重点

- **每个角色一层标准职责。** 人设现在只管性格。角色在团队里干什么，由桥按它在配置里的位置加一层职责：聊天频道里的主角色只派活，大活第一步交工作区；工作区里的主角色自己做完；副手先表态、不派活。人设和职责冲突时以职责为准（#1528）。
- **大活先交工作区，哪里派都行。** 主角色交活前不再先读说明书、开任务卡或翻源码。论坛帖子和私聊也能交给工作区；10 分钟看门改成催负责人交回，不再让它在原地做完（#1523）。
- **汇报变短。** 发给用户的四段（背景、做了什么、要你做的、我加的）每段最多两句，超了退回工作区重写，不截断。聊天频道里主角色先说结论，每条回复五句以内（#1531）。
- **个人 agent 和团队共享经验。** 队员可以在自己电脑上跑自己的 bothouse，用自己的 CLI 和额度。`bothouse send --experience` 派活时附上团队里相关的经验，他们交回的每条「【经验】」都存进团队记忆（#1516）。
- **Codex 也用角色自己的系统账号跑。** Codex 和 Claude Code 一样认 `run_as_user`，成员目录对 Codex 角色也由系统内核隔离（#1514）。

## 缺陷修复

- **给外部用户的汇报：** 核对说明只给验收的主角色，不再拼进给用户的四段。放行汇报时任务板同时结案，重启后不会再要求验收同一件活。主角色能看到完整任务板，被问进度时答得上来。定时轮不在聊天频道开进度卡（#1525）。
- **验收和打回：** 验收提示按任务号指明哪件活，`ws-pass` / `ws-forward` 认得任务板上的 PR、分支、提交链接（#1524）。引号里的「要你做的」不再被当成这一段的开头（#1513）。
- **汇报附件：** 汇报里有链接时不发文档附件，图片、音频、视频照发（#1520）。
- **DSH：** 内嵌面板能显示和接收 Grok 头像（#1526）。DSH 协作的 `[ask]` / `[report]` 用和桥一样的「自己换路」检查（#1522）。

## 改进

- **开工时列出这件活手里现成的东西**（上一棒的脚本、成品、定案）；`[report]` 要带在用户实际用的入口走过一遍的证据（#1512）。
- **路堵了先自己换路：** 「要你做的」把能自己做的事交给用户就退回；问用户前先说这一步能不能撤回（#1511）。
- **工作区不设 4 个上限**，没空的就新开，不排队（#1519）。
- **面板头像：** 面板和 DSH 内嵌面板换上四个角色的 B 版 Q 头像和 Grok 头像（#1517、#1521）。
- **文档：** 写清 `run_as_user` 下 `member` 子命令不可用（#1518）。
