### Fixes

- **One oversized image no longer drops the whole batch.** When you send several images to a native DSH member and one of them is over the limit, only that one is left out; the others reach the member. The channel now shows a system notice naming the attachment that wasn't delivered and why, instead of relying on the member to mention it (#311).
- **Long screenshots reach DSH members.** The per-side pixel limit for images sent to DSH members was raised, so tall or wide screenshots are no longer refused; images are still scaled down before they go to the model (#304).
- **Slash commands in Discord DMs.** `/new` and the other slash commands now show up in direct messages with the bot, not only in the server (#310).
- **Safer updates.** An update can now only be handed to a running bothouse by the same program, and only to a newer release; `bothouse update --help` shows help instead of running an update (#312, #313).
- **Task board dispatch asks for a reference.** Assigning a task on the DSH task board or with `task assign` now asks for a reference implementation (`file:line`, or "none (new)"), plus a base branch when several people edit the same files; sending work back for rework needs a reason (#301, #307).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

### 缺陷修复

- **多图里一张超限，不再整批丢。** 一次给 DSH 原生成员发几张图，只要有一张超限，过去整批都发不出去；现在只丢那一张，其余照常送到。频道里会出一条系统提示，写明哪张没送到、为什么，不再靠成员自己转述（#311）。
- **长截图能发给 DSH 成员了。** 发给 DSH 成员的图片单边像素上限放宽，长图、宽图不再被拒；图片送给模型前仍会按预算缩小（#304）。
- **Discord 私信里也有斜杠命令。** `/new` 等斜杠命令在和 bot 的私信里也能用了，不再只在服务器里出现（#310）。
- **升级更安全。** 只有同一个程序才能给正在运行的 bothouse 转交升级，而且只升不降；`bothouse update --help` 只显示帮助，不再真的执行升级（#312、#313）。
- **任务板派活要写参照。** 在 DSH 任务板或用 `task assign` 派活时要写参照实现（`文件:行`，非代码活写「无（新建）」），多人改同一批文件还要写起点分支；打回返工要写原因（#301、#307）。
