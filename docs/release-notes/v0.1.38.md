## Highlights

- **A workspace handoff comes with its own safety timer.** When the lead hands a big task to a workspace, a one-shot timer starts in the chat channel (30 minutes by default). If the workspace has not handed back by then, the lead checks the task board and tells you where the work is stuck. The timer goes away by itself when the task is reported, paused, asked back or reassigned (#635).
- **One bot, several servers, no double replies.** The new Discord option `allow_guilds` limits a bot to the servers you list (add `dm` to keep DMs). Run the same bot token in two projects or on two machines, each with its own list, and every server keeps its own sessions, work folders and memory (#634).
- **Channel settings in tabs.** The channel settings dialog is now split into Basic, Dispatch and Workspace tabs. Each tab saves on its own, unsaved edits survive switching tabs, and you are asked before closing with unsaved changes — thanks @HarunaRyo-051 (#637).

### Fixes

- **Workspaces no longer get stuck forever.** A task whose owner was removed is closed automatically (tasks you paused yourself are never touched), and a reclaimed workspace with no task behind it goes back to the pool — thanks @HarunaRyo-051 (#614).
- **A workspace report posts once, in full.** The chat channel shows the report's headline followed by its full text, also when the report has no headline; each report posts only once, and a report for a task that is already closed is not posted again (#631, #632, #633).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **交给工作区的活自带兜底定时器。** 主角色把大活交给工作区时，会在聊天频道挂一个一次性定时器（默认 30 分钟）。到点还没交回，主角色会查任务板，告诉你活卡在哪里。活交回、暂停、转回提问或换人时，定时器自动撤掉（#635）。
- **一个 bot 进多个服务器，不再重复回复。** Discord 新增 `allow_guilds` 选项，只让 bot 服务列出的服务器（加上 `dm` 保留私聊）。同一个 bot token 可以在两个项目或两台机器上跑，各配各的列表，每个服务器的会话、工作目录和记忆互不干扰（#634）。
- **频道设置分标签页。** 频道设置弹窗拆成「基本」「派活」「工作区」三个标签页，每页单独保存；切换标签页时没保存的改动还在，有未保存改动关闭前会先问你。感谢 @HarunaRyo-051（#637）。

### 缺陷修复

- **工作区不再永久卡死。** 负责人已被移除的活会自动收口（你自己暂停的活不受影响）；重新认领但后面没有活的工作区会放回池子。感谢 @HarunaRyo-051（#614）。
- **工作区交回只贴一次，而且贴全文。** 聊天频道先贴交回的标题，再贴全文，没写标题的交回也贴全文；每条交回只贴一次，已经收口的活不再重复贴（#631、#632、#633）。
