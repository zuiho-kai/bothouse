## Highlights

- **Task states show up in the chat.** Each Discord chat channel gets one message listing that channel's tasks waiting for you, numbered so you can answer with a digit; answered items are struck through in place. A task that newly stops is announced once with when it stopped, what it is waiting for and what happens next, and a finished task leads with its result. Only the channel's own tasks are shown (#2155, #2163, #2164).
- **Task posts show the work.** A task that has a post (task forum post or card thread) now gets the workspace's step cards, what the workspace said and the full hand-back text in the post, so opening it is no longer empty (#2172).
- **Hand-backs must carry what you should look at.** Workspace hand-backs have a required "For you:" line (a link or full file path, or "none") posted together with the summary; when the report asks you to look at something, only links in the posted part count (#2173).
- **The workspace gets your own words.** The exported discussion keeps only the questions the lead asked you, not the lead's proposals, and `ws-handoff` was cut from 1381 to 953 lines (#2150, #2152).
- **Memory forum threads itself nightly.** New and existing installs get a muted 06:00 job that groups entries asking the same thing into one thread (#2159).

## Fixes

- **Idle wake-ups:** a waiting-external retry that fails on its model config stops once instead of retrying every ten minutes, and turns that would only answer NO_REPLY are no longer woken (#2157).
- **Claude subagents** compact in place instead of being stopped and replaced by a fresh agent that rereads everything; the main session keeps its whole window (#2151).
- **Cron:** a run held by model cooling is no longer reported as an empty response and is delivered again after cooling (#2154).
- **Queues:** a queued message taken off the queue as its session dies gets the dropped-queue notice instead of a raw send error (#2136).
- **Gate port:** a transient or wildcard port conflict no longer leaves the memory gate stuck as external (#2158).
- **Usage:** Claude five-hour windows expire at the real reset time, and the account is shown (#1918).
- **Antigravity:** quota lookup tries both credential paths agy writes (#1973); attachment files stay after the turn ends (#2171).
- **Wiki:** restructuring and recovery keep every original block (#1853); failed model calls are retried before falling back, and role nightly passes run concurrently (#1929); pages keep stable PR references instead of stale workflow state (#1954); selected context rows are anchored to the current topic (#1972).
- **Labels:** fixed blocks no longer say they are attached every turn; they are attached on the first turn of each session (#2165).

## Improvements

- **Quieter logs:** archived task posts are re-read at most hourly, the sweep stops when Discord is not connected, and routine successes log at DEBUG (#2161).

## 重点

- **活的状态进聊天。** 每个 Discord 聊天频道有一条消息列出本频道等你定的活，带编号，回数字就能答；答掉的就地划掉。活新停下时只说一次：几点停、卡在哪、接下来会怎样；做完的活先说结果。只显示本频道的活（#2155、#2163、#2164）。
- **任务帖里看得到干活过程。** 有帖子的活（任务论坛帖或卡片子区），工作区每轮的步骤卡、工作区说的话、交回全文都放进帖子，点进去不再是空的（#2172）。
- **交回必须带要你看的东西。** 工作区交回加必填「给你的：」一行（网址或文件完整路径，没有写「无」），和四段一起贴出；交回要你看东西时，只认贴出那几段里的链接（#2173）。
- **工作区拿到的是你的原话。** 导出给工作区的讨论里，主角色的话只留她问你的问句，不放她的提议；`ws-handoff` 从 1381 行砍到 953 行（#2150、#2152）。
- **记忆论坛每晚自动归帖。** 新装和已装的都加一个静音的 06:00 定时任务，把问同一件事的条目归到一个帖子里（#2159）。

## 缺陷修复

- **空转叫醒：** 等外部的重试因模型配置失败时停一次，不再每 10 分钟重试；只会回 NO_REPLY 的轮不再被叫醒（#2157）。
- **Claude 子 agent** 上下文满了就地压缩，不再被停掉换新 agent 从头重读；主会话窗口保持完整（#2151）。
- **定时任务：** 因模型冷却被挂起的一轮不再报空回复，冷却后正常重投（#2154）。
- **排队消息：** 会话关掉时已出队的消息收到「排队已丢弃」提示，不再是原始发送错误（#2136）。
- **记忆服务端口：** 临时或通配地址的端口冲突不再把记忆服务卡成外部模式（#2158）。
- **额度：** Claude 5 小时窗口按真实重置时间过期，并显示账号（#1918）。
- **Antigravity：** 查额度按顺序找 agy 实际写的凭据文件（#1973）；回合结束后附件文件不再被删（#2171）。
- **记忆 wiki：** 重组和恢复时保留每个原始块（#1853）；模型调用失败先重试再换模型，各角色夜间整理并行跑（#1929）；页面保留稳定的 PR 引用，不写过时的进度状态（#1954）；选出的上下文行锚定当前话题（#1972）。
- **文字：** 固定块的说明不再写「每轮附」，实际是每会话首轮附（#2165）。

## 改进

- **日志降噪：** 已归档的任务帖每小时最多读一次，Discord 未连上时停止清扫，例行成功降到 DEBUG（#2161）。
