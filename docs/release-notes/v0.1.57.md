## Highlights

- **Quiet turns leave nothing in the channel.** A turn that ends with NO_REPLY deletes its progress card, including the copy in the task thread; platforms that cannot delete (Slack) keep the card marked "no reply needed" (#1229).
- **Paused work stays quiet.** A paused task-board item no longer appears in the hourly review list and no longer wakes anyone; reminders queued by older bridges for paused items run as no-ops. Resuming the item brings normal review back (#1244).
- **A workspace [report] is checked against the request before it is posted.** A small model compares the report with the handoff's original request, goal and settled decisions: did it test what was asked, does its conclusion run against a settled decision without testing that version, does it propose a fix the user already rejected (#1243).
- **Per-person profile pages.** Each person gets their own profile page and each turn pushes only the sender's page (#1230, #1231).

## Fixes

- **Workspaces:** output stays in the task's own chat — ws-forward does not push into a workspace busy with another chat's task, and `bothouse send` inside a workspace sends to the task's chat (#1228); progress from timer turns in an unfinished workspace is no longer promoted to a final report (#1222).
- **Collab pages:** the "other computers" page explains in plain words when Tailscale is not running, instead of showing a JSON parse error (#1239); when the panel cannot open, the page says why, what to do next, and offers a Retry button (#1240); the lead card in a channel is clickable and opens channel settings at the lead picker, and says so plainly when no lead is set (#1241).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.57`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **不出声的一轮，频道里什么都不留。** 一轮以 NO_REPLY 收尾时删掉这轮的进度卡（含任务子话题里的副本）；不能删的平台（Slack）照旧留卡并标「本轮不需要回复」（#1229）。
- **暂停的活不再出声。** 任务板上暂停的活不再进整点待验收清单，也不叫醒人；旧版桥排好的暂停提醒到点空转。恢复后照常验收（#1244）。
- **工作区 [report] 发出前先对题。** 小模型拿交接里的用户原话、总目标和旧定案对照汇报：测的是不是用户要的东西、结论是否没测用户那版就反着定案走、解法是不是用户否过的（#1243）。
- **懂你画像每人一页。** 每个人一页画像，每轮只推发话人的那页（#1230、#1231）。

## 缺陷修复

- **工作区：** 输出留在任务所属的聊天频道——ws-forward 不往正在做别的频道活的工作区转，工作区里 `bothouse send` 发到任务的聊天频道（#1228）；没做完的工作区里定时轮的进度不再被当成最终汇报（#1222）。
- **协作页：** 「其他电脑」页在 Tailscale 没运行时说人话，不再露 JSON 解析报错（#1239）；面板打不开时说清原因和下一步，带「重试」按钮（#1240）；频道里的主角色卡可点，直接进频道设置选主角色，没设时写清楚（#1241）。
