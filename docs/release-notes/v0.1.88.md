## Highlights

- **The DSH plugin brings its background service back by itself.** If the bothouse service behind the DSH plugin is killed or crashes, the plugin notices the moment a member drops, starts it again, and the members are back online within seconds — no reopening DSH. If it cannot come up, #general says why (exit code and what the new start wrote to its log) (#2101).
- **Answers for messages sent while the bridge was down.** After a restart, Discord messages posted while the bridge was offline are answered; older ones are folded together instead of flooding the channel (#2061).
- **One control plane for proactive messages.** Jobs due at the same time are merged, each chat has a cap, and the bot backs off when nobody answers; daily reports stay separate. Proactive messages are off by default and switched on in one place (#2062, #2063, #2065, #2074).
- **Every feature switch on one page.** The web panel gets a feature-switch page, and `bothouse features list` prints the same registry (#2064).
- **`bothouse secret run/list`.** Roles use SSH passwords and the management token through `bothouse secret run <name> -- <command>` without the secret ever appearing in the conversation (#2057).

## Fixes

- **A hanging ACP handshake no longer deadlocks the bridge** (#2100).
- **Card progress style keeps tool-to-tool narration and thinking out of the chat;** `thinking_messages` is off by default (#2098). Interim sentences a scheduled turn writes between tool calls are no longer sent either (#2069).
- **Gate routing:** a member the gate hands a reply to answers it even without an @ (#2080); a new un-@ topic the gate did not hand to a sub goes only to the lead (#1889).
- **QQ:** replies and @s aimed at other members are marked as addressed to someone else (#2081, #2082).
- **Team workspaces:** an answered question resumes in the workspace that holds its session (#2050); `ws-handoff --resume` no longer goes back to the previous owner, and a paused board task is released on time (#2087).
- **ACP usage** is read from the session/prompt response (#2059); **Devin** usage is imported from its CLI session store and priced from its own catalog (#2067, #2072, #2073).
- **Antigravity:** a spent quota reaches the chat as a quota failure (#1976).
- **Role wiki:** Claude model aliases are pinned and mismatched results rejected (#1975); raw log appends are accepted and only real errors repaired (#1978).
- **Lead scripts:** safe-restart and iso-check variable names are delimited before non-ASCII text (#2093); lead tests stay off the live board (#2078, #2094).

## Improvements

- **Hand-offs:** the channel discussion is exported from the bridge history, one line per speaker (#2056); a hand-off can pick the workspace's model and effort (#2076); a task waiting on a pull request comes back when the pull request has news (#2060).
- **@ the person who assigned a task** on hand-back and decision questions, behind the switches `mention_assigner` and `mention_human_gate`, both off by default (#2084, #2090, #2096).
- **QQ watched groups** are collected silently and summarised in private batches (#2035).
- **Role wiki proposals** can use the Devin engine (#2051).
- **Workspace sessions** get a reminder at 250k context (#2099).

## 重点

- **DSH 插件自己把后台拉回来。** DSH 插件背后的 bothouse 后台被杀或崩掉时，插件在成员掉线那一刻发现，自动重新启动，几秒内成员回到在线，不用重开 DSH。拉不起来时 #general 写明原因（退出码和这次启动写的日志）（#2101）。
- **桥停机期间发的消息也会回。** 重启后，桥离线时 Discord 里发的消息会被回复；较早的合在一起，不刷屏（#2061）。
- **主动消息统一控制。** 同时到点的任务合并发，每个聊天有上限，没人回就放慢；日报单独发。主动消息默认关，一处开关（#2062、#2063、#2065、#2074）。
- **所有功能开关一页管。** 网页面板新增功能开关页，`bothouse features list` 打印同一份清单（#2064）。
- **`bothouse secret run/list`。** 角色用 `bothouse secret run <名字> -- <命令>` 使用 SSH 密码和管理令牌，原文不进会话（#2057）。

## 缺陷修复

- **ACP 握手卡住不再把桥锁死**（#2100）。
- **卡片进度模式下，工具之间的过程话和思考不再漏到群里；** `thinking_messages` 默认关（#2098）。定时轮在工具调用之间写的过渡句也不再发出（#2069）。
- **gate 分发：** gate 交给某成员回的消息，没 @ 它也会回（#2080）；gate 没交给副手的新话题、没 @ 人时只给主角色（#1889）。
- **QQ：** 回复或 @ 别的成员的消息标为说给别人（#2081、#2082）。
- **团队工作区：** 答复过的提问回到持有会话的工作区继续（#2050）；`ws-handoff --resume` 不再分回原负责人，任务板暂停的活按时放回（#2087）。
- **ACP 用量** 从 session/prompt 的回应里读（#2059）；**Devin** 用量从它的 CLI 会话库导入、按它自己的价目计价（#2067、#2072、#2073）。
- **Antigravity：** 额度用完时聊天里显示为额度失败（#1976）。
- **角色 wiki：** 固定 Claude 模型别名、拒收模型对不上的结果（#1975）；接受原始日志追加，只修真错误（#1978）。
- **主角色脚本：** safe-restart、iso-check 的变量名在中文前显式定界（#2093）；主角色测试不碰线上任务板（#2078、#2094）。

## 改进

- **交接：** 频道讨论从桥的历史导出，一人一行（#2056）；交活时可指定工作区的模型和推理强度（#2076）；等 PR 的活在 PR 有动静时交回（#2060）。
- **交回和拍板提问 @ 布置任务的人**，由 `mention_assigner`、`mention_human_gate` 两个开关控制，默认都关（#2084、#2090、#2096）。
- **QQ 关注群** 静默收集，私聊里分批汇总（#2035）。
- **角色 wiki 提案** 可用 Devin 引擎（#2051）。
- **工作区会话** 上下文到 250k 时提醒（#2099）。
