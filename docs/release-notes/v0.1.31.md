## Highlights

- **A dispatch opened from a chat message shows its text once.** When the lead dispatches a task with an @ message in a DSH channel, the task card now sits under that message and no extra "dispatch" record repeats the full text. Records in other rooms keep a short line without the title (#542).

### Fixes

- **Workspaces cannot claim other workspaces.** `bothouse workspace claim` now rejects requests that come from a workspace, including a released one, with a clear message: run the claim from the original chat channel, or finish the task in the workspace. Nothing is changed when a claim is rejected (#541).
- **Reports are recovered for older workspace handoffs.** Handoff rows written by older versions are now matched to their workspace, so a workspace that finishes or waits without a report is asked for it and the report reaches the parent channel (#543).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **从聊天消息开的派活，原文只出现一次。** 主角色在 DSH 频道用 @ 消息派活时，任务卡直接挂在这条消息下，不再另发一条重复整段原文的「派活」记录；其他频道里的记录只留一行简短说明，不带标题（#542）。

### 缺陷修复

- **工作区不能再认领别的工作区。** 从工作区（包括已释放的工作区）发起 `bothouse workspace claim` 会被拒绝，并提示回原聊天频道认领，或在工作区里就地完成任务；被拒绝时不改动任何状态（#541）。
- **旧版工作区交接也能补回汇报。** 旧版本写下的交接记录现在能对上所属工作区；工作区完成或进入等待却没发汇报时，会被要求补交，汇报转到上级频道（#543）。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
- **校验：** `SHA256SUMS`

从 v0.1.6 起，点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。旧版更新程序若下载超时，请手动下载安装。

macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键 → 打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息 → 仍要运行」。
