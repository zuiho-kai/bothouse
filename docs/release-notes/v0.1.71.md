## Highlights

- **Runs on older Macs again.** The macOS app was built for macOS 27 only, so on macOS 15 and other older systems a double-click failed with "requires a newer version of macOS". The Mac binaries now target macOS 13 or later, the app declares the same minimum, and the release stops if the two ever disagree (#1705).

## Fixes

- **No crash when a session is cleaned up mid-turn:** a turn reads its agent session once under the lock, so cleanup can no longer leave it nil halfway through (#1704).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.71`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **老一点的 Mac 又能用了。** 之前的 Mac 包只按 macOS 27 编，macOS 15 等老系统双击会提示「需要更新版本的 macOS」打不开。现在 Mac 程序支持 macOS 13 及以上，应用声明的最低版本和程序一致，两者对不上时发版会直接停下（#1705）。

## 缺陷修复

- **清理会话不再让一轮半路崩溃：** 每一轮只在锁里读一次代理会话，清理不会把它中途置空（#1704）。

### 安装

- **macOS 13 及以上（Apple Silicon + Intel）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
- **校验：** `SHA256SUMS`
- **DSH 插件：** `npm i bothouse-dsh@0.1.71`

已经是 v0.1.6 或更新？点左下角的 **更新到 vX** 按钮。v0.1.5 或更早的，下载安装这一版一次。旧版更新器超时的话，手动下载安装这一版。

macOS：把 **Bothouse.app** 拖进「应用程序」，第一次 **右键 → 打开**。Windows：SmartScreen 提示时点 **更多信息 → 仍要运行**。
