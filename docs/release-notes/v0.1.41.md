## Highlights

- **`/model` shows the model a channel is actually using.** For Codex roles, `/model`, the model card and `bothouse model list --json` used to show the configured default instead of the channel's real model. They now read the current session's model. When a Codex sandbox cannot reach the bridge, `bothouse model list/info/status` falls back to the current thread's own metadata (marked `source: local_session`); switching still requires the bridge. Subcommands no longer open the daemon log, so a read-only sandbox can run them (#669).
- **A workspace `[ask] #N` pauses task #N.** On DSH, an `[ask]` that named its task only in the first line paused whichever task was listed first in that workspace instead. It now pauses the task the first line names (#676).
- **The task board counts every task it cuts.** When the "running N" summary line did not fit, the overflow note said "0 more"; it now counts those N tasks (#676).
- **A stopped task's report no longer swallows another task's.** The bridge now decides whether a workspace report belongs to a stopped task by the task number on its first line, not by the task the workspace took last (#687).
- **The gate no longer replies to everyone when it cannot judge who was addressed** (#686).
- **`bothouse-dsh` is published to npm with each release** (#684).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **`/model` 显示频道实际在用的型号。** Codex 角色的 `/model`、型号卡片和 `bothouse model list --json` 以前显示的是配置里的默认值，不是这个频道真正在用的型号；现在读当前会话的型号。Codex 沙箱连不上桥时，`bothouse model list/info/status` 改读当前线程自己的记录（标 `source: local_session`），切换型号仍要连上桥。子命令不再打开后台日志，只读沙箱里也能跑（#669）。
- **工作区 `[ask] #N` 暂停的就是 #N。** DSH 上，只在第一行写了编号的 `[ask]`，以前会暂停工作区里排最前的那件；现在按第一行的编号暂停（#676）。
- **任务板放不下时计数正确。** 「在做 N」那一行放不下时，提示以前写「还有 0 件」；现在把这 N 件算进去（#676）。
- **叫停的活不再吞掉别的活的回报。** 桥判断工作区回报是不是属于已叫停的活，改按第一行的任务编号，不再看工作区最近接的那件（#687）。
- **判断不出在叫谁时，不再所有角色一起回**（#686）。
- **每次发版同时把 `bothouse-dsh` 发到 npm**（#684）。
