## Highlights

- **Two role avatar sets.** Roles now show their vendor's own icon by default (Claude, OpenAI, DeepSeek, Gemini, Grok, MiniMax); the chibi set is one click away in Settings → Role avatars, or `[display] avatar_style = "brand" | "chibi"`. The web panel and the DSH channel page read the same setting, and an avatar you picked yourself still wins (#1530, thanks @Zssan12).
- **A wrongly refused reply is asked again.** When an upstream safety classifier refuses a Claude turn, the bridge no longer posts the refusal text; it opens a fresh session with the old one's handoff and answers once more, and reports an error only if that is refused too (#1585, #1586).
- **Desktop pet: a new chibi look for 橘.** Pick it from right-click → Change look; the old one stays and remains the default (#1458).

## Fixes

- **Hand-backs:** the lead's pass or reject is kept once per task and every held report of that task settles from it (#1579); `ws-pass` with attachments also releases the held text report (#1573); a report attaches a document only when it says it produced one, so a wiki page that was merely mentioned is no longer sent as a file (#1578).
- **Ten-minute watch:** a member who answers 【接】 in a chat channel with no task behind it is done in that turn and is no longer nudged in a loop (#1580).
- **Lead switch:** switching the lead to a role that has no team status while the current lead has one is refused with a hint to restart first, instead of leaving the team without a lead (#1574).
- **DSH on macOS:** a `dsh web` started by launchd is taken over through the job's own log, so the bridge no longer starts a second one when the announced URL has no port (#1584, thanks @Zssan12).
- **Codex:** closing a session, killing the transport or cancelling the parent now cleans up the whole app-server process tree; Unix workers are no longer left behind (#483, thanks @Zssan12).
- **Role wiki:** scheduled runs pass their deadline down, so a wiki pass that runs out of time keeps its accepted progress and hands back early instead of being cut off (#1564, thanks @Zssan12). The DSH engine records real per-step token usage, shrinks a failed batch before retrying, backfills newest first and no longer crashes on a non-object JSON line (#1581, thanks @Zssan12).

## Improvements

- **Fewer false blocks from the hooks.** Four rule-based checks that mostly blocked correct replies are removed, and the ask exit no longer fights the handoff exit (#1589). The ask-only guard reads a message sent while a turn is running and ignores `?` inside links (#1587). A handoff may claim a conflict with the user only by quoting the user's exact words; unclear readings are asked without a suggested answer, and newer wording on the same topic wins (#1588).
- **README:** the team desk and pairing screenshots are smaller and sit side by side (#1575).

## 重点

- **角色头像有两套。** 默认显示各家模型自己的图标（Claude、OpenAI、DeepSeek、Gemini、Grok、MiniMax）；娘化头像在「设置 → 角色头像」里点一下就换回来，也可以写 `[display] avatar_style = "brand" | "chibi"`。网页面板和 DSH 频道页读同一个设置，自己选过的头像仍然优先（#1530，感谢 @Zssan12）。
- **被误拒的回复会重答一次。** 上游安全检查拒掉 Claude 的一轮时，桥不再把拒答原文发出去，而是带着旧会话的交接开新会话重答一次，再被拒才报错（#1585、#1586）。
- **桌宠：橘多了一个新画风的 Q 版形象。** 右键「换形象」里选；原来的形象保留，仍是默认（#1458）。

## 缺陷修复

- **交回：** 主角色的放行或打回按一件活只记一份，这件活所有挂着的汇报都从它了结（#1579）；带附件的 `ws-pass` 同时放行挂着的文字汇报（#1573）；汇报只在说了产出文档时才附文档，只是提到某页 wiki 不再把它当附件发出去（#1578）。
- **十分钟看门：** 成员在聊天频道回【接】、身后没有挂任务的，当轮就算答完，不再被反复催（#1580）。
- **切主角色：** 当前主角色有团队状态、目标角色没有时拒绝切换并提示先重启，不再出现团队没有主角色的情况（#1574）。
- **macOS 上的 DSH：** 由 launchd 拉起的 `dsh web` 按该作业自己的日志接管，公告地址不带端口时桥不再另起一个（#1584，感谢 @Zssan12）。
- **Codex：** 关会话、断连接或取消上层任务时清掉整棵 app-server 进程树，Unix 上不再留下 worker（#483，感谢 @Zssan12）。
- **角色 wiki：** 定时任务把期限传下去，wiki 整理时间用完时保住已接受的进度并提前交回，不再被整个掐掉（#1564，感谢 @Zssan12）。DSH 引擎记下每一步真实的 token 用量，失败的批次缩小后再重试，回填从最新的开始，遇到不是对象的 JSON 行不再崩（#1581，感谢 @Zssan12）。

## 改进

- **钩子少误拦。** 删掉四道多半在拦正确回复的规则式检查，发问出口不再和交接出口打架（#1589）。只问不改的检查能读到一轮进行中发来的消息，链接里的 `?` 不算提问（#1587）。交接里说和用户冲突，必须引用用户的原话；拿不准的理解直接问、不带建议答案，同一话题新说法优先于旧定案（#1588）。
- **README：** 团队工作台和配对两张截图缩小并排（#1575）。
