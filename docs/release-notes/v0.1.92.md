## Highlights

- **A new front page.** The README opens with a 9-second loop that shows one job end to end — you ask, the lead splits it between two workspaces, both finish, you say go and it lands. The Chinese page also gets a refreshed memory-forum screenshot and a shorter tour; the English page uses the same loop with English lines (#2186, #2189).

## Fixes

- **Quota takeover hands out only unfinished work.** When cooling quota moves work to another teammate, a finished task is no longer handed out again: the takeover reads the board row behind each watch record and skips the ones already done (#2184).
- **Usage around midnight.** A usage range that starts late at night and ends after midnight now reads both days instead of returning nothing (#2188).

## Improvements

- **Memory forum threads group by module.** A group is titled "[board] subject" like a NGA megathread, candidates on the same page come first, and a one-off regroup can resume and run concurrently; history rows and down-voted folded floors are no longer pushed (#2174).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.92`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **新的 README 首页。** README 首屏换成一段 9 秒循环动画，只演一件事：你说一句话，组长拆给两个工作区，两边同时做完，你说「合吧」，活就合进来了。中文页的论坛截图也换成新版、介绍收紧；英文页用同一段动画的英文台词（#2186、#2189）。

## 缺陷修复

- **额度接管只发还没做完的活。** 额度冷却把活转给别人时，已经做完的活不再被重新派出去：接管前先看每条看门记录对应的任务板行，已经做完的就跳过（#2184）。
- **半夜查用量。** 从深夜查到第二天凌晨的用量范围现在两天都读，不再返回空（#2188）。

## 改进

- **记忆论坛按模块归帖。** 标题改成 NGA 集中贴那样「[版块] 对象」，同一页的候选帖优先；另加一次性重归帖，能续跑、能并发。历史节的行和被踩折叠的楼不再推送（#2174）。
