## Highlights

- **Model boxes work like CC Switch.** Every model field (setup wizard "use a third-party API", the panel's global provider defaults, per-CLI models and model list, and project providers) has a **Fetch model list** button that asks the provider's `/v1/models`; pick one from a searchable list or type any ID by hand. (#2338)
- **A display name is no longer sent as a model ID.** A model written as a display name such as "Opus 4.7" is turned into the provider's real ID (`claude-opus-4-7`) before it is saved, or refused with the list of valid IDs; old configs are fixed at startup. The overview counts an offline role as "needs a look" and says why. The README now recommends letting your AI install bothouse. (#2337)
- **Waiting tasks say they are waiting.** The task board has a new "waiting" state for tasks that wait on a time, another task, a pull request or a release; only a real stop is reported as stopped, and a waiting task that misses its time by 30 minutes turns "stuck". A pause during a quota cooldown becomes a wait that resumes once, after the cooldown. (#2310, #2322, #2323, #2325)
- **Optional meaning-based search for memory push.** With `[gate] vector` on, memory push also searches by meaning through an embedding service and merges both lists; off by default, and with it off the push is unchanged. (#2319)
- **Activity snapshot for tracker plugins.** `GET /api/v1/activity` lists busy projects and workspace sessions, active relay jobs and DSH channels with working members. (#2315, thanks @Hiennoob123)

## Fixes

- **Claude Code with an API key no longer gets a false "Credit balance is too low".** API-key logins keep the CLI's own `sdk-cli` entrypoint; subscription logins are unchanged. (#2336)
- **ACP model lists show real model IDs** instead of DSH's `["provider","model"]` arrays, so picking a model by ID works. (#2317)
- **DSH port self-heal no longer sends HTTP to other programs' ports.** It checks who owns a port before probing it. (#2307)
- **Cron and timer turns in their own session resume after a restart** instead of being dropped because the main session replied. (#2302)
- **The watchdog no longer escalates a busy workspace** whose turn has started but is not recorded yet. (#2318)
- **A workspace only answers to the member who took the job**, and a hand-off wake-up is dropped if its task has left that workspace. (#2327)
- **An @ inside code is not a mention.** Task posts show the assignee's stage notes, and the progress card starts folded. (#2326)
- **Every @-mentioned role replies when several are mentioned together**, including a switched lead. (#2321)
- **Hand-off discussion windows read level-1 quote headings**, so earlier messages are no longer left out. (#2311)
- **Feishu:** tool calls and results are grouped on the progress card, long output is trimmed near the size limit, rich cards continue below an inserted message, and Codex retries resuming a session the previous process still holds. (#2304, thanks @yzdnh123-a11y; #2320)
- **Wiki lossless check accepts a line split at a full stop.** (#2331)
- **The rules conflict check's sample hand-back has the "for you" line** the report check now needs. (#2308)
- **Two flaky core tests are fixed.** (#2328)

## Improvements

- **House rules per session type.** The lead's chat, workspaces and teammates each get their own rules file, falling back to the shared one. (#2309)

## Not in the product yet

- The local reranker model service used by memory push on the maintainer's machine is not shipped; the product calls one only when `GATE_RERANK` points to it and otherwise uses the keyword floor.

## 重点

- **模型框照 CC Switch 来。** 所有模型框（向导「改用第三方 API」、管理页全局服务商的默认模型、各 CLI 模型和可用模型列表、项目服务商）都有「获取模型列表」按钮，去问中转站的 `/v1/models`；拉到后在可搜索的列表里点一个，也能直接手填任意 ID。 (#2338)
- **显示名不再当模型 ID 发出去。** 写成「Opus 4.7」这种显示名的，保存前换成中转站真正的 ID（`claude-opus-4-7`），换不了就报错并列出可用 ID；老配置启动时自动改好。概览把不在线的角色算「需要看」并写明原因。README 首推让 AI 帮你装。 (#2337)
- **在等的活就显示在等。** 任务板加了「在等」状态：等时间、等另一件活、等合并请求、等发版的都不再算停了；只有真停才报停了，在等的过了约定时间 30 分钟没接上变「卡住」。额度冷却时的暂停记成等冷却，冷却完只续派一次。 (#2310, #2322, #2323, #2325)
- **记忆推送可选按意思找。** 打开 `[gate] vector` 后，除了关键词，还通过向量服务按意思找一路，两路合并；默认关，关着时推送和以前完全一样。 (#2319)
- **给追踪插件的活动快照。** `GET /api/v1/activity` 列出在忙的项目和工作区会话、在跑的中继、有人在干活的 DSH 频道。 (#2315，感谢 @Hiennoob123)

## 缺陷修复

- **Claude Code 用 API key 登录不再误报「余额不足」。** API key 登录保留 CLI 自己的 `sdk-cli` 入口，订阅登录照旧。 (#2336)
- **ACP 的模型列表显示真实模型 ID**，不再把 DSH 的 `["provider","model"]` 数组当名字，按 ID 选模型能用了。 (#2317)
- **DSH 换端口自愈不再往别的程序的端口发 HTTP**，先判端口归属再探。 (#2307)
- **单开会话跑的定时、延时任务，桥重启后照常续上**，不再因为主会话回过话被丢。 (#2302)
- **看门不再把在忙的工作区当停了升级**（这轮已开跑、还没记下的情况）。 (#2318)
- **工作区只认接这件活的人**；交接叫醒到点时，那件活已不在这个工作区就丢掉。 (#2327)
- **代码里的 @ 不算点名。** 任务帖显示接活人的阶段说明，进度卡默认收起。 (#2326)
- **一条消息同时 @ 几个角色，被 @ 的都直接回**，换过的主角色也一样。 (#2321)
- **交接讨论时间窗认一级标题的引述节**，不再漏掉更早的话。 (#2311)
- **飞书：** 进度卡把工具调用和结果放一起，接近大小上限时精简长输出，中途插入消息后在下面续卡；Codex 恢复被上一进程占着的会话时会重试。 (#2304，感谢 @yzdnh123-a11y；#2320)
- **wiki 无损检查认句号处拆开的行。** (#2331)
- **守则冲突检查的交回样例补上「给你的：」行**，跟上交回检查的新要求。 (#2308)
- **修了两条偶发失败的 core 测试。** (#2328)

## 改进

- **守则按会话分开发。** 主角色聊天、工作区、队友各收各的守则文件，缺了退回共用那份。 (#2309)
