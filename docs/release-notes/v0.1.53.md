> v0.1.52 was never published (its release pipeline stopped at the Windows smoke check); everything planned for it ships in this release.

## Highlights

- **Windows DSH install works on a desktop-only DeepSeek Harness.** The installer finds `dsh.cmd` the same way the bridge does (PATH, then the DeepSeek Harness install folders), and a `.cmd` launcher is treated as the desktop app, so it no longer borrows a mismatched `dsh-web-app` from npm. Thanks @Zssan12 (#1086).
- **Windows install no longer needs a second run.** npm's global prefix in `C:\...` form is converted to a shell path before it goes into PATH, so `pnpm` is found right after it is installed. Thanks @Zssan12 (#1085).

## Fixes

- **Team board shows a started workspace task as 在做.** When a workspace starts a task, the board marks it 在做 and fills in the first tool step after 「已开工」; the backstop prompt carries the live state (#1083).

## Improvements

- **CI:** a Windows end-to-end install smoke test runs in CI, and the release pipeline verifies the Windows install again (#1061). The Windows smoke check reads the `--version` output, because the GUI build does not set an exit code (#1089).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.53`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **Windows 只装了桌面版 DeepSeek Harness 也能装 DSH 插件。** 安装脚本按桥的同一顺序找 `dsh.cmd`（先 PATH，再 DeepSeek Harness 安装目录）；`.cmd` 启动器按桌面版处理，不再去借 npm 里版本对不上的 `dsh-web-app`。感谢 @Zssan12（#1086）。
- **Windows 安装不用再跑第二遍。** npm 给出的 `C:\...` 形式全局目录先转成 shell 路径再进 PATH，装完 `pnpm` 马上就能找到。感谢 @Zssan12（#1085）。

## 缺陷修复

- **任务板把已开工的工作区任务标成「在做」。** 工作区开工后，任务板标「在做」，并在「已开工」后补上第一步工具动作；兜底提示带上实时状态（#1083）。

## 改进

- **CI：** Windows 端到端安装冒烟测试进 CI，发版流水线重新加回 Windows 验装（#1061）。Windows 冒烟检查按 `--version` 输出判断，因为 GUI 版程序不设退出码（#1089）。

- **校验：** `SHA256SUMS`
- **DSH 插件：** `npm i bothouse-dsh@0.1.53`
