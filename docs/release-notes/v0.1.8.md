## Highlights

- **A chat channel plus workspaces: one channel runs every project.** The channel you talk in stays free for conversation; the actual work moves into workspaces underneath it. Workspace 1 is created for you, and the team opens workspace 2, 3 and beyond as the load grows. One place to talk, many places to work, nobody talking over anybody.
- **Task dispatch with a task board.** Hand a task to a role, and it lands on the board with an owner, a status line and a check-in time. Progress shows up on the task itself instead of scrolling away in chat. Everyone can see who is on what, and the board counts rework when a task comes back.
- **Three ways to run the team.** Choose how work is assigned: all to your own sub-agents, all to the teammates in the channel, or mixed — whichever suits the job. The lead follows the mode you pick.
- **Ask the user from anywhere.** A role working in a workspace can raise a question with `[ask]` or post a stage result with `[report]`; both surface in the chat channel, and your answer is routed back to the exact workspace and role that asked.
- **Workspaces on all four platforms.** Discord, Feishu, the self-hosted web channel and DSH web all create and route workspaces. Nothing is wired to one platform any more.
- **Direct messages, on Discord.** On Discord a bot can open a DM with its admin — `bothouse send --dm` — and owner DMs skip the dispatcher, so a private word stays private.
- **Pick the lead on the channel page.** A "who leads" selector on the channel page sets the default responder for the whole team. The choice is saved with your data, shared by the channel and the bridge, and survives a restart.
- **Busy checks across workspaces.** Before a task is handed over, the team checks whether that role is already busy in another workspace or channel, and says where. No more stacking the same role twice.

### Collaboration tools now ship with the app

- **`bothouse setup lead install`** installs the task board, the "check back later" timer, the 10-minute nudge, workspace handoff, safe restart and the lead playbook into `<data_dir>/collaboration/lead` in one command, and adds a short usage note to the role's persona file. If you have edited one of those scripts, the installer leaves it alone and lists it; `--force` overwrites.
- **The conventions are built in.** Every delivery carries the shared team rules, so a freshly installed role already knows the four-part status line 【接】【问】【退】【升】, how to call a teammate, and when to nudge: no persona editing required.
- **The lead playbook got four more rules**: at most two review rounds, review scaled to risk, how to assign long tasks, and how the status line and teammate calls work.

### Channel page

- **Permission prompts as buttons.** When a bot needs approval in the web channel, it is a button, not a paragraph to type at.
- **Replies stream in.** Answers appear as they are written instead of after a long pause.
- **Reply to a single message**, with the original quoted above your answer.
- **Member avatars open a quick @ menu**, the channel and member columns collapse, and the @ picker closes when you click outside it.

## Improvements

- **Apache-2.0 licence** for project-owned code, with third-party notices kept in place.
- **Ready for open source**: a security policy, install docs that no longer assume a private repository, fork pull requests checked on GitHub-hosted runners, and internal records moved out of the public tree.
- **Real IDs scrubbed** from docs and tests before opening up.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **聊天频道加工作区：一个频道管所有项目。** 你说话的那个频道保持畅通，真正的活挪到它下面的工作区里做。第一次交活时会自动开出工作区 1，忙起来再开工作区 2、3……聊天在一个地方，干活在另一个地方，谁也不会抢话。
- **任务分发和任务板。** 把活派给某个角色，它就上任务板：谁在做、什么状态、几点回查，一清二楚。进度长在这件事本身，不再被聊天刷走；返工也算得出来。
- **三种派活方式。** 可以全交给自己开的子任务，可以全派给频道里的成员，也可以混合——按事情挑。主角色照你选的方式走。
- **在工作区里也能问到你。** 角色用 `[ask]` 发问题、用 `[report]` 交阶段结果，两者都会出现在聊天频道；你的回答会送回原来那个工作区、原来问的那个人手里。
- **四个平台都有工作区。** Discord、飞书、自建网页频道、DSH 网页都能建工作区、派活、转话，不再只认一个平台。
- **私信（目前只支持 Discord）。** Discord 上机器人可以用 `bothouse send --dm` 私信它的管理员，管理员的私信不走调度员，两个人说的话就只是两个人的。
- **在频道页上选谁当主。** 频道页有「谁当主」选择器，选定后全队默认由他接话。选择存在你的数据里，频道和桥共用，重启之后还是他。
- **跨工作区忙碌检查。** 派活前先看这个人在别的工作区或频道有没有活，有就告诉你在哪。同一个人不会再被压在两件事上。

### 协作工具随安装包一起发

- **`bothouse setup lead install`** 一条命令，把任务板、「过会儿回来」、十分钟催办、工作区交接、安全重启和主角色手册装进 `<data_dir>/collaboration/lead`，再往角色人设里写一小段用法说明。你改过的脚本它不覆盖，会列出来，加 `--force` 才替换。
- **协作规矩是内置的。** 每次投递都带上共用规矩，新装的角色天生就会首行表态【接】【问】【退】【升】、知道怎么叫队友、什么时候催办，不用改人设。
- **主角色手册补了四条**：审稿最多两轮、审查按风险分级、长任务怎么派、表态和叫队友怎么写。

### 频道页

- **权限请求变成按钮。** 机器人在网页频道里要授权时，点按钮就行，不用照着文字敲。
- **回答边写边出。** 不用等一整段生成完才看到字。
- **可以对着单条消息回复**，上面带原话引用。
- **点头像快速 @ 人**；频道栏和成员栏可以收起；@ 选择框点外面就关。
