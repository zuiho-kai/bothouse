## Highlights

- **The memory forum now learns from what actually happened.** When a role says it used a pushed memory entry, that is only recorded as a citation. Each night the forum checks the turn that cited it: if your next message was not a correction, the entry gets one success; if it was, one failure. Ranking uses only these results, so votes a model casts on its own no longer move an entry (#914).
- **Outdated memories move aside instead of piling up.** Every time the wiki is updated, new facts are checked against the old lines on the same page. A line the new fact overturns is moved, word for word, to that page's "History" section, not deleted. A line you correct in chat goes through the same check at night. Running the setup wizard with a wiki it made adds this nightly settlement at 05:30 (#914).
- **The team desk is a pixel office.** Each member is a pixel sprite drawn from their official character sheet. They wander between the window, whiteboard, bookshelf and coffee machine when idle and run back to their desk when they have a task. Dispatches fly as little letters, hand-backs and rejections as light balls. The room's light follows your local time. Name tags show the model name (Claude, DeepSeek, GPT, Gemini, Grok) by default; click one to rename it, and the name stays across refreshes and devices (#906, #911, #912).
- **The desk, the wiki galaxy and the bothouse panel are in the DSH sidebar.** The channel plugin adds three entries under "Channels". The full management panel opens inside DSH through a signed proxy: your token never reaches the browser (#905).

## Fixes

- **A timed-out scheduled turn is really stopped.** Before, a cron, timer or heartbeat turn that ran past its limit only logged a line and kept running, so the session stayed busy for hours. Now it is stopped like `/stop` (#902).
- **A slash command held by the gate runs once.** It used to run twice, and the "not a bothouse command" notice was sent twice (#899).
- **DSH pages work through the panel's `/dsh/` proxy.** The DSH home page, the channel page, the team desk and the wiki galaxy failed to load when opened through the management panel (for example over Tailscale or on a phone); they now work the same as a direct connection (#903).
- **The ACP bridge no longer replays a prompt after a tool already ran.** A capacity error after a tool event could repeat work; ACP failures now also come in order (#844).
- **The task board no longer shows a merged task twice,** counts only workspaces that are really running, and shows a short current stop reason with its owner (#908).
- **Channel members still start on a DSH host without preset leases,** and the card says what to do when the preset interface is missing (#910).

## Improvements

- **The web panel is redesigned.** Shared components use design tokens with three skins: light (default), dark, and brand warm white (#891). Settings and monitoring pages (overview, usage, providers, devices, cron, system, bridge) share one layout with simple charts (#892). The Projects page has search, filters, card and row views, a detail drawer and batch delete; the Sessions page, which had no route before, is now wired in (#893).
- **Screenshot regression tests for the channel page** (desktop and phone, light and dark) and a smoke test for the team desk (#890).

## 重点

- **记忆论坛按真实结果学。** 角色说用到了哪条推送的记忆，只记一次「引用」。每晚回看引用它的那一轮：你的下一句不是纠正，这条记一次成功；是纠正，记一次失败。排序只看这些结果，模型自己投的票不再影响条目（#914）。
- **过时的记忆会让位，不再堆着。** 每次 wiki 更新，新事实和同页旧行比对；被新事实推翻的旧行原样挪进该页「历史」段，不删。你在聊天里纠正过的条目，夜里也走同一比对。跑一次向导（它建的 wiki）就会加上每天 05:30 的这次结算（#914）。
- **团队工作台变成像素办公室。** 每个成员一个按官方设定板画的像素小人，空闲时在窗边、白板、书架、咖啡机之间溜达，有活就跑回工位。派活是飞过去的小信，交回、打回是光球。屋里明暗跟着本地时间走。名牌默认显示模型名（Claude、DeepSeek、GPT、Gemini、Grok），点名牌可改名，刷新、换设备都在（#906、#911、#912）。
- **DSH 左边栏直达工作台、Wiki 星河和 bothouse 面板。** 频道插件在「频道」下加三个入口；整个管理面板经签名转发在 DSH 里打开，令牌不进浏览器（#905）。

## 缺陷修复

- **定时任务超时后真停掉那一轮。** 以前 cron、timer、心跳超时只记一行日志，agent 接着跑，会话一忙几个小时；现在像 `/stop` 一样停掉（#902）。
- **被闸门挂起的斜杠命令只跑一次。** 以前会跑两遍，「不是 bothouse 命令」的提示也发两遍（#899）。
- **经面板 `/dsh/` 转发打开 DSH 页面正常了。** 以前经管理面板（如 Tailscale、手机）打开时，DSH 首页、频道页、团队工作台、Wiki 星河都加载失败；现在和直连一样（#903）。
- **ACP 桥在工具已经跑过后不再重放提示。** 工具事件之后的容量报错可能让同一件事做两遍；ACP 的失败也按顺序报（#844）。
- **任务板不再把已并入的任务显示两遍，** 只数真在跑的工作区，并写出当前卡在哪、归谁（#908）。
- **DSH 宿主没有预设租约接口时，频道成员照样能用，** 预设接口缺失时卡片会写明怎么办（#910）。

## 改进

- **网页面板重做。** 公共组件接入设计令牌，三套皮肤：浅色（默认）、暗色、品牌暖白（#891）。设置与监控类页面（概览、用量、服务商、设备、定时任务、系统、桥接）统一骨架，加了简洁图表（#892）。项目页有搜索、筛选、卡片与紧凑两种视图、详情抽屉和批量删除；之前没有路由的会话页也接上了（#893）。
- **频道页截图回归测试**（桌面、手机 × 亮、暗），团队工作台冒烟测试（#890）。
