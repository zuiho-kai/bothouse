### Fixes

- **Send button on phones.** The channel page now has a **Send** button next to the input, so you can send from a phone keyboard that only inserts new lines. Enter sends, Shift+Enter adds a new line, and pressing Enter to pick a word in an input method no longer sends the message, saves an edit, picks an @ mention or creates a channel by mistake (#318).
- **Recall no longer hidden under the reply arrow.** On your own messages, **Edit** and **Recall** now sit to the left of the reply arrow instead of under it, on phones and desktop (#318).
- **Short input hint on narrow screens.** On phones and narrow windows the input shows a short hint ("Message #room") on one line instead of a long hint wrapped over several lines (#318).
- **Undelivered attachment reasons in Chinese.** When an attachment can't reach a DSH member, the channel notice now gives the reason in plain Chinese (for example "图片太大，超过像素上限") instead of an English error, and the member's own reply uses the same wording (#318).

### Changes

- **Workspace tasks are checked every 10 minutes.** A task worked in a DSH workspace is now checked 10 minutes after it starts. If the task owner posted progress, it gets another 10 minutes (up to two times); otherwise the task is paused and the owner is @-mentioned. Answering or handing the task back resumes it. Before, a task was only paused after an hour with no activity (#315).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

### 缺陷修复

- **手机上有发送按钮了。** 频道页输入框旁加了「发送」按钮，手机键盘回车只能换行时也能发出去。回车发送、Shift+回车换行；用输入法选字时按回车，不会误发消息、误保存编辑、误选 @ 成员或误建频道（#318）。
- **撤回不再被回复箭头压住。** 自己消息上的「编辑」「撤回」挪到回复箭头左边，手机和桌面都不再叠在一起（#318）。
- **窄屏输入框提示变短。** 手机和窄窗口里，输入框提示改成一行短句「发消息到 #频道」，不再折成好几行（#318）。
- **附件没送到的原因改成中文。** 附件没送到 DSH 成员时，频道系统提示写中文原因（比如「图片太大，超过像素上限」），不再是英文报错；成员自己转述时也是同样的中文说明（#318）。

### 改动

- **工作区任务每 10 分钟查一次进展。** 在 DSH 工作区里做的任务，开始 10 分钟后查一次：任务负责人发过进展就再给 10 分钟（最多续两次）；没有进展就暂停任务并 @ 负责人，负责人表态或交回即恢复。过去要一小时没动静才暂停（#315）。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）

安装包未签名。macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键→打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息→仍要运行」。
