## Highlights

- **Progress cards show up even when the bot opens none.** In a workspace channel, when a turn does real work (two or more tool steps, or still running after 1 minute) and the bot has not opened, continued or handed off a task card, bothouse opens one for it. The title is the text of the message that started the turn; no extra model call. If the bot opens its own card later, it takes over the same card (#356, #366).
- **Cursor and DSH roles stop asking for approval after the upgrade.** On the first start after the upgrade, Cursor (ACP) and DSH roles that never had a permission mode get the same full-auto default that the wizard gives new roles. The one-time hint now lists only roles it could not change, with the reason (#357).
- **A fresh install has more working out of the box.** The wizard installs the collaboration helpers for the new lead role (#360) and gives each new role its memory wiki index, so the first turn of a new session sees it (#364). The gate finds or installs a Python 3.12 by itself and starts without jev (#362). The bridge, setup, task board and gate all use one data folder (#361).

### Fixes

- **Automatic progress card titles show only the message text.** The title no longer shows the hints bothouse adds for the model. Automatic cards open only in workspace channels; regular chat channels, DMs and voice turns do not get one. Cards the bot opens itself work everywhere as before (#366).
- **No more endless retries when Discord refuses a delivery for good.** Progress cards, task updates and channel boards sent to a deleted channel, a channel the bot can no longer access, or an archived thread are dropped after one warning instead of retried every second. A newer update tries once more (#359).
- **Old team boards that can never be deleted stop the warnings.** After the lead role moves to another bot, an old board in an archived thread is given up after one warning. A board that can no longer be edited waits for new activity before it tries again (#355).
- **Voice: a failed save on the first turn no longer locks the channel.** If the first turn of a voice conversation could not be saved (also when it was cancelled or timed out), the next turn starts a new conversation instead of failing every time (#358).
- **Voice: a failed save no longer clears the answer.** The answer is kept and a warning is logged (#352).
- **Voice: history stays on topic and replies are saved.** The voice channel no longer carries other channels' status into every turn; teammate status is looked up when needed. Replies are saved before the voice session closes (#347, thanks @Zssan12).
- **Tray: icon only, and Exit really exits.** The tray shows only its icon and is hidden for test or headless instances (`BOTHOUSE_TRAY=auto|on|off`). On macOS, Exit stops the background service so it does not start again right away; it still starts at the next login if start at login is on (#349).

### Improvements

- **Start at login is off by default and can be switched in the panel.** New installs do not start at login. Turn it on or off in the panel settings; the change applies at once without stopping the running bridge (#354).
- **New "Bright yellow-white" theme for the management panel, now the default.** Pick Light, Dark, System or Bright yellow-white in the panel settings. Browsers that never chose a theme switch to Bright yellow-white; Dark and System stay as they are (#351, #353).
- **Team watch counts real progress.** A busy session or a new post from the owner in the workspace channel extends the 10-minute watch (up to two times) (#363).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. On a slow connection, the one-click update from v0.1.10 or earlier can still time out (the old updater is the one that downloads); if it does, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **bot 没开进度卡时，bothouse 自动开。** 在工作区频道，一轮里真在干活（两步以上工具调用，或超过 1 分钟还没结束），而 bot 没有开、续上或转交任务卡时，bothouse 替它开一张。标题用触发这一轮的消息文字，不多调模型。bot 之后自己开卡，会接管同一张卡（#356、#366）。
- **升级后 Cursor 和 DSH 角色不再反复要审批。** 升级后第一次启动，没设过权限模式的 Cursor（ACP）和 DSH 角色改成和向导新角色一样的免审批默认值。一次性提示只列出没能改的角色，并写明原因（#357）。
- **新装机开箱即用的更多了。** 向导给新的主角色装好协作工具（#360），给每个新角色写上记忆 wiki 目录页，新会话首轮就能看到（#364）。gate 自己找或装好 Python 3.12，没有 jev 也能启动（#362）。桥、向导、任务板和 gate 用同一个数据目录（#361）。

### 缺陷修复

- **自动开的进度卡标题只显示消息本身。** 标题不再露出 bothouse 给模型加的提示文字。自动开卡只在工作区频道开，普通聊天频道、私聊和语音回合不自动开；bot 自己开的卡照旧（#366）。
- **Discord 永久拒收的投递不再无限重试。** 进度卡、任务更新和频道看板投到已删除的频道、已无权限的频道或已归档的帖子时，报一次警告后放弃，不再每秒重试刷日志。有新的更新时再试一次（#359）。
- **删不掉的旧看板不再刷警告。** 主角色换到别的 bot 后，归档帖子里的旧看板报一次警告后放弃；改不动的看板等频道有新动静再试（#355）。
- **语音：第一轮保存失败不再让频道卡死。** 语音会话第一轮没能保存（包括被取消或超时）时，下一轮开新会话，不再每轮都失败（#358）。
- **语音：保存失败不再清空回答。** 回答保留，只记一条警告（#352）。
- **语音：历史聚焦在本频道，会话能续上。** 语音频道不再每轮带上其他频道的状态，队友状态按需查询；回答在语音会话关闭前存好（#347，感谢 @Zssan12）。
- **托盘只显示图标，「退出」真的退出。** 托盘只显示图标，测试实例和无界面实例默认不显示（`BOTHOUSE_TRAY=auto|on|off`）。macOS 上点「退出」会停掉后台服务，不会马上又被拉起；开了开机自启的，下次登录照常启动（#349）。

### 改进

- **开机自启默认关，可在面板里开关。** 新装默认不开机自启。在「系统 → 全局设置」里开关，立即生效，不停正在运行的桥（#354）。
- **管理面板新增「黄白明亮」主题并设为默认。** 在「系统 → 全局设置」里可选浅色、深色、跟随系统、黄白明亮。没选过主题的浏览器改用黄白明亮；选过深色或跟随系统的不变（#351、#353）。
- **看门认真实进展。** 工作区会话在忙，或负责人在工作区频道有新发言，十分钟看门就续期，最多两次（#363）。
