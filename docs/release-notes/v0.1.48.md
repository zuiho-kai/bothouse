## Highlights

- **One sentence builds a team in DSH.** In a DSH channel, tell the lead role something like "make a writer and a programmer, both on deepseek-v4.1-flash, and put them in a channel". It creates the new channel and the roles in one step and becomes that channel's lead. Without a model name, the new roles use DSH's default model. A single-model user can now run a multi-role team without any setup (#938).
- **The team desk shows clones when one member has several tasks.** Up to four copies of the sprite work at once; more show as ×N (#945).

## Fixes

- **Scheduled turns stop at their time limit in every case.** A cron or timer turn that waited in the queue, or that resumed an earlier session, used to lose its timeout and could keep a session busy for hours. Roles on outing channels can no longer set timers for themselves (#925, #931, #935).
- **Old progress cards no longer stay on "working" forever after the bridge restarts** (#928).
- **Member failure notes tell a restart apart from a relay that cannot be reached,** instead of always saying "check your config" (#921).
- **Refreshing the page returns to the channel you had open** (#927).
- **The live stream on the team desk no longer draws tasks as empty rows** (#923).
- **Choosing "not selected (use original config)" again in channel settings no longer errors** (#919).

## Improvements

- **You can recall your own message on the channel page.** Recalling it also stops the answer it started (#917).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.48`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 里一句话拉团队。** 在 DSH 频道里对主角色说一句，比如「建写手、程序员两个角色，都用 deepseek-v4.1-flash，拉个频道」，它一步建好新频道和这些角色，自己当这个频道的主角色。不说模型时，新角色用 DSH 默认模型。只有一个模型的用户，不用任何配置也能带一支多角色团队（#938）。
- **一个成员手上多件活时，工作台出分身。** 最多四个小人同时干活，再多显示 ×N（#945）。

## 缺陷修复

- **定时任务在各种情况下都会到点停。** 以前在队列里等过的、或接着旧会话续跑的 cron、timer 一轮会丢掉超时，会话可能一忙几个小时。外出频道的角色也不能再给自己挂定时器（#925、#931、#935）。
- **桥重启后，旧进度卡不再永久停在「处理中」**（#928）。
- **成员失败提示区分「重启打断」和「中转连不上」，** 不再一律写「请检查配置」（#921）。
- **刷新页面后回到上次打开的频道**（#927）。
- **工作台实时流不再把任务画成空行**（#923）。
- **频道设置选回「未选择（按原配置）」时不再报错**（#919）。

## 改进

- **频道页可以撤回自己的消息。** 撤回时，这条消息发起的回答也一起停下（#917）。
