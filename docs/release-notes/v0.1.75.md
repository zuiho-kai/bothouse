## Highlights

- **Faster workspace turns.** A workspace turn no longer carries the role's daily page, teammate status or member recommendation, and code maps are read by keyword instead of whole (#1789). The workspace kickoff prompt inlines the handoff, merges steps into fewer round trips, hands back in one call and stops at the acceptance criteria (#1797, #1798, #1800, #1808).
- **`bgrun` wakes you when it ends.** A long command started with `bgrun` from a bridge session wakes that session when it finishes (success, failure or timeout), with the exit code and the log tail; no more waiting for someone to happen by (#1797).
- **A stop word stops your own work.** An unaddressed "stop" from an admin still stops the whole channel; from anyone else it stops only the turns that person started. `/stop all` and "@bot stop" are unchanged (#1809).
- **Core cleanup.** Each message runs through the pipeline once (#1790, #1795); one bridge-side writer for task board rows with structured fields (#1791, #1799, #1801); session save lock and gate config split (#1792); startup and reload share one settings path (#1793); retries read structured error kinds (#1803); prompt markers in one place (#1804); the interactive turn and its result split into a struct and methods (#1815, #1816); model-only prompt text goes through i18n (#1813).

## Fixes

- **No second report nag**: a workspace without a task record that handed back by command is no longer asked for its report again at the turn's end; develop CI green again after the cleanup batch (#1817).
- **Handbacks come only from the command**: the bridge no longer reads a handback from reply text (#1802).
- **Scheduled turn limits**: a scheduled turn's time limit stops only its own turn (#1776, thanks @Zssan12).
- **Workspaces stay in their channel**: a workspace is reused only in its own channel, never moved across channels (#1771, thanks @Zssan12).
- **Session handoff lists what is owed from records**: pending items and handback state come from the records (#1767, thanks @Zssan12).
- **Role wiki manuals**: numbers in manuals and templates come from `lint.py` (#1768, thanks @Zssan12).
- **Acceptance gate**: checks every held report without `--id`, and must have looked at the report's screenshots, duplicates included (#1774, #1777).
- **Report attachments**: an image path quoted or borrowed in a report is not its attachment (#1778).
- **DSH**: issues from a fresh desktop install walk (#1773); channel page tidied, commands folded to one line, one workspace per job for several members (#1779, #1780); a joint job tells both members the shared dir and teammate files, folded to one line (#1782, #1783, #1786).

## Improvements

- **Fewer wording guards**: hooks that policed how the model words a reply are removed; only fact-checking guards stay (#1807, #1814); the narration regex is gone, the receipt says not to narrate (#1806).
- **Simpler picks**: quota cooldown picks a teammate by one rule (bound, free, not cooling, first by name) (#1805); the timer anti-spin check counts wakes, not words (#1810); workspace routing no longer checks privacy keywords (#1796).
- **Session history per session**: each session's history is an append-only file beside the store; the old store is migrated once and backed up as `.pre-history.bak` (#1812).
- **Build**: the DSH bundle is generated at build time, not kept in git (#1811); the committed binary and stray files are gone (#1772, #1794).
- **Tests**: QQ ACP media and QQ on Windows covered (#1753, thanks @jsk11231); QQ harness socket under the macOS path limit (#1770); CLI /stop test polls instead of sleeping (#1769).

## 重点

- **工作区一轮更快。** 工作区轮不再带角色的小日子、队友状态和成员推荐，代码地图按关键词读、不整份读（#1789）。工作区开工提示把交接内联、步骤并成更少的来回、交回一次调用、做到验收标准为止（#1797、#1798、#1800、#1808）。
- **`bgrun` 结束自动叫醒。** 在桥会话里用 `bgrun` 起的长命令，结束时（成功、失败、超时都算）叫醒发起它的会话，带退出码和日志末尾，不用再等人碰巧来叫（#1797）。
- **停止词只停自己的活。** 没 @ 的「停」：管理员照旧停整个频道；其他人只停自己那条消息发起的轮。`/stop all` 和「@某 bot 停」不变（#1809）。
- **核心清理。** 每条消息只走一遍处理流程（#1790、#1795）；任务板行由桥一处写、带结构化字段（#1791、#1799、#1801）；会话存盘锁、gate 配置和运行态分开（#1792）；启动和重载共用一条设置路径（#1793）；重试先看结构化错误类型（#1803）；提示词标记收成一处（#1804）；交互轮收成结构体、结果处理拆成方法（#1815、#1816）；只给模型读的注入话术走 i18n（#1813）。

## 缺陷修复

- **不再二次催交回**：没有任务记录的工作区用命令交回后，轮末不再再催一次；清理那批合进后变红的开发分支检查重新变绿（#1817）。
- **交回只认命令**：桥不再从回复正文认交回（#1802）。
- **定时轮时限**：定时轮的时限只停它自己那一轮（#1776，感谢 @Zssan12）。
- **工作区不跨频道**：工作区只在本频道复用，不跨频道改挂（#1771，感谢 @Zssan12）。
- **换会话交接按记录列待办**：待办和交回状态按记录列出（#1767，感谢 @Zssan12）。
- **角色 wiki 手册**：手册和模板里的数字取自 `lint.py`（#1768，感谢 @Zssan12）。
- **验收闸**：不带 `--id` 也查所有待验的汇报，放行前必须看过汇报里的截图，重复截图也拦（#1774、#1777）。
- **汇报附件**：汇报里引用或借用的图片路径不算它的附件（#1778）。
- **DSH**：新装桌面版走查发现的问题（#1773）；频道页整理、命令折成一行、多人一件活一个工作区（#1779、#1780）；联合任务告诉两人共享目录和队友文件，并折成一行（#1782、#1783、#1786）。

## 改进

- **少了管措辞的守卫**：管模型怎么措辞的 hook 删掉，只留查事实的（#1807、#1814）；删掉过程复述正则，回执写明不要复述（#1806）。
- **选人规则更简单**：额度冷却选人只留一条规则（同频道绑定、空着、没在冷却、按名字取第一个）（#1805）；定时防空转按唤醒次数计、不看字（#1810）；工作区路由不再查隐私关键词（#1796）。
- **会话历史每会话一个文件**：每个会话的历史存成存档旁的只追加文件；旧存档一次性迁移，原文件备份为 `.pre-history.bak`（#1812）。
- **构建**：DSH 插件包构建时生成，不再进 git（#1811）；误提交的二进制和杂文件删掉（#1772、#1794）。
- **测试**：覆盖 QQ ACP 媒体和 Windows 上的 QQ（#1753，感谢 @jsk11231）；QQ 测试套接字路径在 macOS 长度限制内（#1770）；CLI /stop 测试改轮询、不固定等待（#1769）。
