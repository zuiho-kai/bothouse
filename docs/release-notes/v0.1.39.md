## Highlights

- **Reply to a task, and the agent knows which task you mean.** Reply to a task card or a workspace report in Discord, Feishu, the web client or DSH, and the turn now starts with that task's background: number and title, overall goal, related changes, the original request and the latest report. The quoted message is kept in full instead of being cut to 80 characters (#671, #675).
- **Questions get answers, not dispatches.** A new `ask-only-guard` hook stops the agent from handing off, forwarding, scheduling or editing files when your latest message only asks a question, so it answers first and asks before acting. Installed for Claude Code, DSH, Codex and agy (#666, #678).
- **Long sessions start fresh without losing open work.** When a chat channel's context grows too large, the next message starts a fresh session whose handoff lists the channel's unfinished tasks (goal and where each one stopped). Workspaces and projects with `auto_compress` are left alone (#670).
- **Better handoffs to workspaces.** A handoff must now state the overall goal, related changes (with an explicit conflict line), scope (what to change and what not to) and what was already checked. One rules file drives both `ws-handoff` and DSH collab. Team rules are sent once per context instead of every turn, which keeps the lead's context small (#672, #673, #679).

### Fixes

- **A workspace report is no longer dropped** when the workspace marked its board item done before reporting (#667).
- **CI is green again:** stale test expectations updated, a hanging core shard fixed, plus two real fixes — cross-workspace dispatch no longer counts the target workspace's own claim as busy, and lead scripts work on macOS bash 3.2 (#674).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **回复任务，agent 就知道你说的是哪件活。** 在 Discord、飞书、自建网页或 DSH 里回复任务卡或工作区交回，这一轮会先带上那件活的背景：编号与标题、总目标、相关改动、需求原文和最近一次汇报。被引用的消息保留全文，不再只剩前 80 字（#671、#675）。
- **只是提问，就先回答，不派活。** 新增 `ask-only-guard` 钩子：你最新一条消息只是在问，agent 就不能交接、转发、挂定时或改文件，先回答，要动手先问你。Claude Code、DSH、Codex、agy 都装上了（#666、#678）。
- **长会话自动换新，没做完的活不丢。** 聊天频道上下文太大时，下一条消息换新会话，交接里列出本频道没做完的活（总目标和停在哪）。工作区和开了 `auto_compress` 的项目不受影响（#670）。
- **交给工作区的交接更完整。** 交接必须写总目标、相关改动（带明确的冲突行）、范围（改什么、不改什么）和已查过什么。`ws-handoff` 和 DSH 协作共用同一份规则文件。团队规矩每个上下文只发一次，不再每轮都发，主角色上下文更省（#672、#673、#679）。

### 缺陷修复

- **工作区交回不再被吞。** 工作区先把任务板条目标成完成、再交回时，交回照样贴出（#667）。
- **CI 恢复全绿：** 更新过时的测试期望，修好卡死的 core 分片；另修两处真 bug：跨工作区派活不再把目标工作区自己的认领算成忙，主角色脚本在 macOS 自带 bash 3.2 上不再报错（#674）。
