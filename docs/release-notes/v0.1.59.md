## Highlights

- **The DSH plugin installs in seconds.** `bothouse-dsh` no longer pulls the Claude Code and Codex adapters into every install; they download the first time you add such a member (Claude Code about 125 MB). On a fresh DSH with an empty pnpm store, the install went from about 480 MB / 100 s to about 8.8 MB / 2.6 s (#1302). `zod`, the peer the ACP SDK needs, is now a direct dependency (#1303).
- **A reply a Stop hook blocked is no longer sent twice.** When a Stop hook rejects a finished reply and asks for a rewrite, the draft that was already streaming is withdrawn; a rewrite replaces it, a short addition is appended to it (#1300). DSH hooks find their session through `CC_SESSION` when withdrawing the draft (#1301).

## Fixes

- **DSH plugin docs:** installed from the plugin page, switch bothouse on under "Installed plugins" and "Channels" appears right away, no restart (#1306); the Claude Code / Codex adapters download on first use (#1304).

## Improvements

- **CI:** the global DSH install is cached on Windows, keyed by the version npm would install (#1296).
- **Tests:** placeholder, self-testing and duplicate unit tests removed from core, agent and platform (#1297, #1298, #1299).
- **README:** team mode and hardware added as new directions, the personal-first opening kept (#1305, #1307).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.59`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 插件几秒装好。** `bothouse-dsh` 不再每次安装都带上 Claude Code 和 Codex 的接入适配器，第一次把它们加成成员时才下载（Claude Code 约 125 MB）。在全新 DSH、空 pnpm 缓存上实测，安装从约 480 MB / 100 秒降到约 8.8 MB / 2.6 秒（#1302）。ACP SDK 需要的 `zod` 改成直接依赖（#1303）。
- **Stop 钩子拦下的回复不再发两次。** Stop 钩子拦下已写好的回复、要求重写时，已经流式发出的初稿会被收回；重写替换初稿，短补充接在初稿后面（#1300）。DSH 钩子收回初稿时通过 `CC_SESSION` 找到会话（#1301）。

## 缺陷修复

- **DSH 插件说明：** 从插件页装完，在「已安装插件」里把 bothouse 的开关打开，左侧马上出现「频道」，不用重启（#1306）；Claude Code / Codex 适配器第一次用时才下载（#1304）。

## 改进

- **CI：** Windows 上缓存全局 DSH 安装，按 npm 将装的版本做键（#1296）。
- **测试：** 删掉 core、agent、platform 里的占位、自己测自己和重复的单测（#1297、#1298、#1299）。
- **README：** 加上团队模式和硬件两个新方向，保留个人用户的首屏（#1305、#1307）。
