## Highlights

- **Our own desktop pet with HD role skins.** The desktop pet is now bothouse's own, forked from [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) into `plugins/desktop-pet`, with a right-click menu wired to bothouse (admin page, usage, task board, role lines, chat with the bound role) (#1429). The pet wears the bound role's look and shows a read-only todo panel (#1436), and the release now ships the pet window code (#1432). Built-in HD chibi skins for our roles and for Claude / GPT / DeepSeek / Gemini / Grok, grouped in the 换形象 menu; open-source skins are opt-in downloads (#1441, #1446). Skins are crisper (#1439), idle animations no longer jitter and talk / work moves are calmer (#1453); switching skins reloads the body animation (#1450), and clicking an installed recommended skin wears it instead of downloading it again (#1443). The plugin page connects per-role bindings and role events to local pet playback (#416, #1350), and failed turns no longer show as a celebrate action (#1457).
- **Voice messages.** Discord sends TTS and audio as native voice messages, falling back to a file if that fails (#1433). New TTS provider `local` talks to a local voice-clone server (default `http://127.0.0.1:8790/v1`, no API key) (#1430).
- **Idle workspaces are tucked away.** On Discord, workspaces returned to the pool move into an "idle workspaces" category and come back when a task is handed out; only channels this bridge registered are touched (#1352).
- **Antigravity takes messages mid-turn.** When the agy role is busy, messages that name it join the running turn instead of waiting in the queue (#1462).
- **Mention-only mode keeps memory.** Choosing "reply only when mentioned" in the setup wizard now still starts the gate, so per-turn wiki suggestions, notes, speaker profiles, task board and teammate status are injected as before (#1463).

## Fixes

- **QQ:** re-running the wizard for an existing QQ role keeps its CLI, persona and saved access token (#1425).
- **Workspaces:** reclaiming workspaces gives a bound item's recent activity a 10-minute grace (#1404); board progress write-back treats English `done` as closed, like the watch and `board.py` (#1440); messages queued just before a turn's journal entry is written survive a restart (#1422).
- **Plugins:** on Windows, installing a plugin by path accepts drive letters and UNC paths (#1435).
- **DSH:** transient Windows failures while replacing `cordis.patch.yml` are retried (#1424).
- **Quota:** role quota snapshots are bound to the account that made the request, sparse updates no longer extend untouched windows, and streamed Antigravity quota reaches the role card (#1356).
- **Wiki:** role wikis read renamed Codex sessions and the role's own `codex_home`, and the dsh engine really calls DSH (#1413).
- **macOS:** the release app includes its automation (Apple Events) usage description (#1461).

## Improvements

- **Wiki ingest** checks every claim attributed to the user in a daily entry against a verbatim quote (#1468).
- **Office desk view:** working roles sit at their desks facing us; idle roles walk around the room (#1427, #1428).
- **DSH docs** explain the idle gate and forced cutover of `run-cutover.py` and the real fields of `stopped_no_authorizer` (#1455, #1465).
- **CI:** develop PRs also run the web vitest suite; test fixes (#1417, #1418, #1419, #1426, #1437).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.62`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **自家桌宠，带高清角色形象。** 桌宠改成 bothouse 自己的，从 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 分叉进 `plugins/desktop-pet`，右键菜单接上 bothouse（管理页、用量、任务板、角色台词、和绑定角色聊天）（#1429）。桌宠穿绑定角色的形象，待办面板只读（#1436），发布包里带上桌宠窗口代码（#1432）。内置我们几个角色和 Claude / GPT / DeepSeek / Gemini / Grok 的高清 Q 版形象，「换形象」菜单分组；开源形象改成按需下载（#1441、#1446）。形象更清晰（#1439），待机动画不再抖，说话、干活动作放慢放轻（#1453）；换形象时身体动画跟着换（#1450），点已装的推荐形象直接换上，不再重新下载（#1443）。插件页把每个角色的绑定和角色事件接到本机桌宠播放（#416、#1350），失败的回合不再显示成庆祝动作（#1457）。
- **语音消息。** Discord 把 TTS 和音频发成原生语音消息，失败时退回发文件（#1433）。新增 TTS 服务 `local`，接本机声音克隆服务（默认 `http://127.0.0.1:8790/v1`，不用 API key）（#1430）。
- **空闲工作区收起来。** Discord 上放回池子的工作区移进「空闲工作区」分类，派活时再搬回来；只动本桥登记过的频道（#1352）。
- **Antigravity 能在一轮中途接消息。** agy 角色忙时，点它名的消息并进正在跑的这一轮，不再排队等（#1462）。
- **仅点名模式也带记忆。** 向导里选「仅被点名时回复」也照常起 gate，每轮的 wiki 推荐、经验、发言人画像、任务板、队友状态照常注入（#1463）。

## 缺陷修复

- **QQ：** 已有 QQ 角色重跑向导，保留原来的 CLI、人设和已存的访问令牌（#1425）。
- **工作区：** 回收工作区时给绑定条目的最近活动留 10 分钟宽限（#1404）；任务板进度写回认英文 `done` 为收尾，和看门、`board.py` 一致（#1440）；一轮的 journal 条目落盘前入队的消息，重启后也能续上（#1422）。
- **插件：** Windows 上插件页按路径安装认盘符和 UNC 路径（#1435）。
- **DSH：** Windows 上替换 `cordis.patch.yml` 偶发失败时自动重试（#1424）。
- **额度：** 角色额度快照绑定到实际发请求的账号，稀疏更新不再给没更新的窗口续期，流式 Antigravity 读到的额度也进角色卡（#1356）。
- **Wiki：** 角色 wiki 读得到改名后的 Codex 会话和角色自己的 `codex_home`，dsh 引擎真正调用 DSH（#1413）。
- **macOS：** 发布的 app 带上自动化（Apple Events）用途说明（#1461）。
