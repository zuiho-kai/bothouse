## Highlights

- **A blocked reply is no longer cut to its last line.** When a Stop hook blocked the end of a turn and the model then wrote only a short addendum, the channel used to get that addendum alone. Claude Code roles now send the reply written before the block followed by the addendum, and the bundled hook runner asks the model to rewrite its full reply after a block (#682).
- **Grok roles get `ask-only-guard` too.** `setup hooks --cli grok` installs it, so a Grok role that is only asked a question answers instead of dispatching or editing files (#681).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **回复被拦后不再只剩最后一句。** 一轮结束时被 Stop 钩子拦下，模型接着只补了一句，以前频道里就只收到这一句。现在 Claude Code 角色会把被拦前写的回复和补的那句一起发出；随包的钩子入口也会在拦下时要求模型把完整回复从头重写一遍（#682）。
- **Grok 角色也装上 `ask-only-guard`。** `setup hooks --cli grok` 会装好它：只是问 Grok 角色问题时，它先回答，不派活、不改文件（#681）。

### 安装

- **macOS（Apple 芯片 + Intel）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
- **校验：** `SHA256SUMS`
