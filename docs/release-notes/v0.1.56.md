## Highlights

- **Back on the v0.1.54 code, without the v0.1.55 overnight patches.** The changes released in v0.1.55 were withdrawn from the branch (#1187); this release is v0.1.54 plus the fixes below.
- **The bridge, not the CLI, decides when a long session starts over.** Claude Code and Codex no longer compact a session in place; the bridge opens a fresh session with a handoff instead, so the two no longer fight (#1195).
- **New `bothouse wake` command.** A hook (for example a member-joined event) can hand a piece of text to a role as one turn; the role's reply goes to the channel as usual and the text itself is never posted (#1209).
- **Talk to a role in a DM without @.** Discord DMs are accepted by default (add `-dm` to turn them off), a channel only the owner and the bot can see counts as private, and when the gate has no model a person's DM is answered without an @ (#1217, #1218).
- **New Gate page in the panel:** three buttons, one switch per role and a model API card. Thanks @Zssan12 (#1213).

## Fixes

- **Progress cards:** a turn interrupted by /stop or the gate shows "interrupted" instead of "failed" (#1208); steps are still counted when tool details are hidden (#1201, thanks @Zssan12).
- **Idle watch:** a 【接】 that already answered in one turn is no longer registered as unfinished work (#1194); the watch's own nudges no longer count as progress, and a lone `adapter_eof` is treated as retryable (#1216); renewing the watch writes the latest progress back to the task board (#1206). Thanks @Zssan12.
- **Quota:** cooldown notices show a readable local time and the time left (#1202); an unreachable retry time no longer blocks rollback, and ProbeStatus is actually logged (#1211); a cooldown resend normalizes the session key before looking up handoffs, so a task is not run twice (#1203). Thanks @Zssan12.
- **DSH:** the release switch entry calls the state write-back script again (#1204); self-heal only takes over a real host and does not back up again after a cooldown (#1205); the embedded client bundle is rebuilt so long names no longer squeeze the lead's avatar (#1210); in narrow windows the input box grows to fit its placeholder instead of cutting the second line (#1215). Thanks @Zssan12.
- **QQ:** "stuck" notices are only logged, not posted to the group (#1212). Thanks @Zssan12.
- **Updates:** a self-built copy says it cannot self-update when checking, instead of first offering an update (#1199). Thanks @Zssan12.
- **Panel:** the language button in the top bar keeps its icon and label on one line (#1198); the English `/help` entry for direct messages names the real English buttons (#1146). Thanks @Zssan12.
- **Claude Code usage:** the weekly reset line in the form "Nov 6 at 2pm" is parsed (#1196).
- **Hooks:** deliver-check recognizes Codex code-mode file reads and image views (#1220); two hook fixes from the running machine are brought into the mainline — promise-guard parses outing-tick jobs started by an interpreter, and day words in a reply are not taken as an unfounded estimate (#1219).

## Improvements

- **Task board:** backlog items are shown apart from active work and do not take a workspace (#1207, thanks @Zssan12); a second rejection of the same item pauses it and asks the user, with both review reasons (#1191).
- **Handoff checks:** fact checks (paths, dated quotes, PR numbers) run for every lead; format checks only for DS-type leads (#1189, #1190).
- **check-first guard:** a reply that states the current state or proposes an addition without having checked it in this turn is stopped once (#1192).
- **QQ:** a message inserted while the bot is busy gets a reaction on the original message as its receipt (#1200). Thanks @Zssan12.
- **DSH chat page:** valid @role mentions show as pill badges (#1214). Thanks @Zssan12.
- **Memory push:** at most 5 wiki rows per turn, heading lines skipped (#1223).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.56`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **回到 v0.1.54 的代码，不带 v0.1.55 那批夜里补丁。** v0.1.55 里发出的改动已从分支撤回（#1187）；这一版是 v0.1.54 加下面这些修复。
- **长会话什么时候重开，由桥决定，不由 CLI 决定。** Claude Code 和 Codex 不再原地压缩会话，改由桥带交接开新会话，两边不再打架（#1195）。
- **新命令 `bothouse wake`。** 钩子（比如新成员进群）可以把一段文字当一轮输入交给角色；角色照常回到频道，文字本身不发出去（#1209）。
- **私聊不用 @ 也能叫到角色。** Discord 默认接私聊（写 `-dm` 关掉）；只有主人和 bot 看得见的频道算私人频道；判断器没配模型时，真人私聊不用 @ 也回（#1217、#1218）。
- **面板新增闸门页：** 三个按钮、每个角色一行开关、模型 API 卡片。感谢 @Zssan12（#1213）。

## 缺陷修复

- **进度卡：** 被 /stop 或判断器打断的一轮写「已打断」，不再写失败（#1208）；隐藏工具详情时步数照样累计（#1201，感谢 @Zssan12）。
- **看门：** 一轮就答完的【接】不再登记成没做完的活（#1194）；看门自己的催办不再算进展，单独出现的 `adapter_eof` 按可重试处理（#1216）；看门续期时把最近进度写回任务板（#1206）。感谢 @Zssan12。
- **额度：** 冷却提示写本地时间和剩余时长（#1202）；到不了的重试时间不再卡死回滚，ProbeStatus 真正写进日志（#1211）；冷却重发先把会话键归一再查交接，同一件活不会跑两遍（#1203）。感谢 @Zssan12。
- **DSH：** 发布切换入口重新调用状态回写脚本（#1204）；自愈只接管真实宿主，冷却后不重复备份（#1205）；重建内嵌 client bundle，长名字不再挤窄主角色头像（#1210）；窄窗口下输入框按提示文字撑高，不再截掉第二行（#1215）。感谢 @Zssan12。
- **QQ：** 卡住提示只记日志，不发到群里（#1212）。感谢 @Zssan12。
- **更新：** 自编译版在查询更新时就说明不能自我升级，不再先提示可更新（#1199）。感谢 @Zssan12。
- **面板：** 顶栏语言按钮的图标和文字保持一行（#1198）；英文 `/help` 里私聊那条改成英文界面上真实的按钮名（#1146）。感谢 @Zssan12。
- **Claude Code 用量：** 能解析「Nov 6 at 2pm」这种写法的周额度重置时间（#1196）。
- **钩子：** deliver-check 认得 Codex 代码模式下的读文件和看图（#1220）；把线上机器上较新的两处钩子修复合回主线：promise-guard 能解析用解释器启动的 outing-tick 任务，回复里的日期词不再被当成没根据的工期（#1219）。

## 改进

- **任务板：** 待办和进行中的活分开显示，待办不占工作区（#1207，感谢 @Zssan12）；同一件活第二次被退回就暂停并问用户，附两次审稿理由（#1191）。
- **交活检查：** 核事实（路径、带日期的引语、PR 号）对所有主角色开；核格式只对 DS 类主角色开（#1189、#1190）。
- **先查再说守卫：** 回复断言现状或建议加东西、但这一轮没查过时，拦一次（#1192）。
- **QQ：** 忙时插进来的消息，用给原消息点表情作回执（#1200）。感谢 @Zssan12。
- **DSH 聊天页：** 有效的 @角色 显示成药丸徽章（#1214）。感谢 @Zssan12。
- **记忆推送：** 每轮最多推 5 条 wiki，跳过标题行（#1223）。
