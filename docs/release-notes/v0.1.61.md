## Highlights

- **Work blocked outside no longer loops.** When a workspace cannot go on because of something outside (no free GPU, waiting for CI, waiting for the other side), it says so in its report with a line `等外部：<what blocks it>` and optionally `再看：2h`. The report skips the intent check and is posted as usual; the board item is marked "waiting on external" with a retry time, the workspace is freed, and neither the 30-minute guard nor the 10-minute watch wakes it. At the retry time it goes to a free workspace again, which first checks the condition (#1408).
- **The lead accepts a workspace's text report before the user sees it.** A workspace `[report]` is held for the chat lead, who passes it (`ws-pass`) or sends it back (`ws-forward`); with no lead it is posted marked as unchecked (#1362). Workspace hand-backs are found from the last reply for every agent backend (#1363), Codex reports after progress lines are forwarded too (#1361), and a queued acceptance wake survives a restart in full (#1390).
- **Plugin template and three role-event plugins.** `plugins/template` wraps role events and role bindings with no dependencies; `new-plugin.mjs` copies it. Built on it: `bothouse-role-webhook` (Discord / Slack / Feishu message when a role hands back or fails), `bothouse-role-journal` (daily JSON Lines of role events) and `bothouse-role-notify` (desktop notification). Guide in `docs/plugins/plugin-dev.md` (#1406).
- **Nightly memory tools for every install.** The wiki ingest / search / lint / session tools are productized with user-specific paths and roles, and the setup wizard installs the muted reflector and nightly scorer jobs (#1317).

## Fixes

- **Workspaces:** a channel made with `bothouse channel create` is a chat channel at once, so workspaces can be opened from it (#1389); new channels are placed above the workspaces (#1359). A workspace that pauses its own task keeps its turn and its report (#1386). The watch never mentions a person as a task owner (#1402).
- **QQ:** voice transcription notices are no longer posted in group and quiet chats (#1281).
- **DSH channels:** the message hover toolbar sits next to the bubble instead of the far right of the row (#1233); private chats can no longer get members added, and the backend refuses it (#1154); consecutive-message layout, empty states and stopped cards shown as failed are fixed (#937); the workbench restores running tasks on open and refresh (#930).
- **Panel:** with only DSH Desktop installed, the overview shows DSH members and channels (#1264).
- **Release:** the macOS dmg is built without mounting (#1349).

## Improvements

- **Handoff minutes** written on session renewal use eight fixed sections (goal, user decisions, assistant additions, artifacts, findings, open items, next steps, file pointers) (#1365).
- **Stand-in review** keeps the tier model, cannot pick a cheaper role, and says so when the model did not take effect (#980).
- **Role cards** show quota windows (#846).
- **QQ setup** in the web panel is complete, with editable OneBot settings (#711).
- **README** rewritten for DSH and single-model users first (#848).

## 重点

- **被外部卡住的活不再循环重跑。** 工作区因为外部条件做不下去（没空卡、等 CI、等对方）时，在汇报里写一行 `等外部：<卡在什么>`，可加一行 `再看：2h`。这份汇报跳过对题检查，照常贴回；任务板标「等外部」并记下再看的时间，工作区放回池子，半小时兜底和十分钟看门都不再叫醒它。到点后交给空工作区接着做，先查条件满足没有（#1408）。
- **工作区的文字汇报先过主角色验收再给用户看。** 工作区 `[report]` 先交聊天频道的主角色，放行（`ws-pass`）或打回（`ws-forward`）；没有主角色时照发并标「未验收」（#1362）。各家后端的工作区交回都按最后一条回复识别（#1363），Codex 在进度话之后的汇报也能转回（#1361），排队中的验收提醒重启后完整送到（#1390）。
- **插件模板和三个角色事件插件。** `plugins/template` 零依赖包好角色事件和角色绑定，`new-plugin.mjs` 一键复制。用它做了 `bothouse-role-webhook`（角色交活、出错时往 Discord / Slack / 飞书发一句）、`bothouse-role-journal`（角色事件按天写 JSON Lines）、`bothouse-role-notify`（桌面通知）。开发说明见 `docs/plugins/plugin-dev.md`（#1406）。
- **夜间记忆工具人人可用。** wiki 的导入、搜索、检查、会话工具改成按用户配置路径和角色，向导装上静音的反思和夜间打分任务（#1317）。

## 缺陷修复

- **工作区：** 用 `bothouse channel create` 建的频道当场算聊天频道，能在里面开工作区（#1389）；新频道排在工作区上面（#1359）。工作区自己暂停自己的活时，这一轮和它的汇报都保留（#1386）。看门不再把真人 @ 成任务负责人（#1402）。
- **QQ：** 群聊和静音聊天里不再发语音转写提示（#1281）。
- **DSH 频道：** 消息悬停工具条贴到气泡旁，不再钉在整行最右（#1233）；私聊里不能再加成员，后端也拒绝（#1154）；修好连续消息排版、空状态不收起、停止卡显示成失败（#937）；工作台打开、刷新时还原进行中的任务（#930）。
- **面板：** 只装 DSH 桌面版时，概览也显示 DSH 成员和频道（#1264）。
- **发版：** macOS dmg 打包不再挂载磁盘镜像（#1349）。
