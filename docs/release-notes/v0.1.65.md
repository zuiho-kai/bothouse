## Highlights

- **The team desk shows who handed what to whom.** Dispatches fly over as envelopes and land as task tags, progress notes float back to the lead's desk, hand-backs stack up there waiting for review, rejected work comes back as a crumpled paper ball, and a paused member raises a hand. Even when nothing moves, each tag carries the sender's colour and the real dispatch links replay every few seconds (#1544, #1545, #1548, #1568, #1569).
- **Bigger, cleaner characters.** The desk fits its window, the five roles share one head width and screen-face width, sitting and standing are the same size, nobody's face hides behind a monitor, props are redrawn larger and name tags dodge each other (#1543, #1551, #1552, #1558, #1560, #1561, #1567). Animations are capped and do not pile up in a background tab (#1549).
- **README now covers team mode, the team desk and remote pairing**, with real screenshots (#1571).

## Fixes

- **Windows:** the release exe is a console program again, so `bothouse --version` and other commands print in PowerShell (#1555, thanks @Zssan12). The bridge reads whatever a request left unread before closing, so Windows clients no longer get a connection reset after a 200 (#1566).
- **Release builds** keep the work tree clean, so the binary is no longer marked modified and the bundled DSH plugin updates as it should (#1556, thanks @Zssan12).
- **Hand-backs:** a final report is no longer withdrawn when the hand-back itself closes the task (#1557); progress and superseded held reports no longer raise 「主角色未验收」, and `ws-forward` resumes jobs parked as waiting on something external (#1542).
- **Panel:** the Overview left column no longer leaves a gap, and DSH channels read their latest message through the owner route instead of failing every row (#1554, thanks @Zssan12).
- **Local platforms** no longer depend on a dead proxy; a proxy error is reported right away (#1547, thanks @Zssan12).
- **Desktop pet** wears the avatar pack each role picked (#1540, thanks @Zssan12).

## Improvements

- **Discord workspaces live in one 「工作区」 category**; the old idle/in-use split is gone and existing channels move over by themselves (#1559).
- **DSH wizard** writes an output cap (maxTokens) for third-party providers (#1546, thanks @Zssan12).
- **Team mode wording:** roles no longer talk about an "owner"; a member asking about a personal directory gets an answer from its actual state (#1550).
- **Tests:** the gate port migration test no longer races across CI shards (#1565).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.65`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **工作台看得出谁把活派给了谁。** 派活是一封飞过去的信，落桌变成任务牌；干活中的纸条飘回主角色桌；交回的活在主角色桌上摞成一摞等验收；打回是一个纸团砸回去；暂停的人会举手。画面静止时，任务牌也带着派活人的颜色，每隔几秒重放一次真实的派活关系（#1544、#1545、#1548、#1568、#1569）。
- **人物更大更齐。** 工作台随窗口自适应，五个角色头宽和屏幕脸宽对齐，坐姿站姿一样大，坐着不再被显示器挡脸，道具重画放大，走动名牌互相避让（#1543、#1551、#1552、#1558、#1560、#1561、#1567）。动效设了上限，切到后台不攒动画（#1549）。

## 缺陷修复

- **Windows：** 正式包的 exe 改回控制台程序，在 PowerShell 里直接打 `bothouse --version` 等命令能看到输出（#1555，感谢 @Zssan12）。桥关连接前先读完请求里没读的部分，Windows 客户端不会在收到 200 后又被重置连接（#1566）。
- **发版构建** 保持工作区干净，二进制不再被标成「改过」，内置 DSH 插件能正常更新（#1556，感谢 @Zssan12）。
- **交回：** 交回流程自己结案时不再撤掉挂起的最终汇报（#1557）；进度和被取代的挂起汇报不再报「主角色未验收」，`ws-forward` 能接着做标了等外部的活（#1542）。
- **面板：** 概览左栏不再留空；DSH 频道改走 owner 路由读最新消息，不再每行都读取失败（#1554，感谢 @Zssan12）。
- **本机平台** 不再押在失效的代理上，代理出错立即报（#1547，感谢 @Zssan12）。
- **桌宠** 穿上每个角色选的形象包（#1540，感谢 @Zssan12）。

## 改进

- **Discord 工作区统一放进「工作区」分类**，不再分空闲和在用，旧频道自动挪过去（#1559）。
