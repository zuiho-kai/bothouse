# bothouse v0.1.65

本版基于 v0.1.64，仅包含 Windows 命令行输出与发布构建清洁度两项修复。

- Windows 包改为控制台子系统，在 PowerShell 里直接运行 `bothouse --version`、`bothouse model list` 等命令可接收输出和退出码。双击进入托盘时释放程序自己的控制台；从已有终端启动时保留该终端。Refs #1495。
- 发布产物目录不再使工作树变脏；构建前检查工作树，构建后检查版本元数据，阻止带 `vcs.modified=true` 的包发布。本地开发构建的插件保护逻辑不变。Refs #1496。

## 已知问题

- 旧 DSH 插件若只有 `dev` 版本戳、没有提交和构建时间，本版仍保留它，避免以无法证明来源的代码覆盖现有插件。这一旧插件升级问题尚未解决；请勿把发布构建修复理解为已完成旧 dev 插件迁移。
- 同版本、不同提交或构建时间的插件仍需来源可比较才可自动升级，不能只以时间更晚判断新旧。
- macOS 未公证，首次打开可能需要右键打开；Windows 无 Authenticode 签名，可能显示 SmartScreen 提示。
