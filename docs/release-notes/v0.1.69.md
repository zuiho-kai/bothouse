## Highlights

- **New README.** The front page now tells one story: several different AIs join one group, a team-lead AI splits the work, and they share one memory. It opens with an overview picture, the demo video and the install command; two more pictures show how one task gets done and what the team can do. Details moved into `docs/` (#1689).
- **Task state has one source of truth.** Every workspace task now lives in one state record that the bridge changes: a turn knows which task it belongs to; busy, idle, claim and reconcile read that record (#1632, thanks @Zssan12; #1665). A workspace hands back only through `ws-up --report`, never from reply text (#1668, #1683). The task board calls the bridge to change state (`bothouse workspace transition`), and the old patch layers are gone: closing words in board text, the "no activity for an hour" pause, and the watchdog reading channel history (#1676).
- **Role skills from nightly drafts.** Nightly ingest drafts new role skills and revisions; the Skills page previews, edits, discards and approves them per role or native DSH member, and DSH loads only the enabled role view (#1648, thanks @Zssan12).

## Fixes

- **Handbacks:** a handback by command is the report, so no "report missing" nag follows it and the queued session reset runs (#1688); a bounced or undeliverable handback keeps the task in work (#1674); a rejected held report no longer counts as posted (#1667); with verification off, only a posted handback closes a task as done (#1681).
- **Common-sense fixes across the team mode (#1492):** a failed model-list lookup is not cached as "not supported", a quick lead off/on leaves one board loop, a failed release save does not release the workspace, the scan pass closes the board item, and quota takeover resets watch counts (#1684); the pinned task table keeps thread, forum and DM tasks, does not shelve tasks stuck over a day, and counts waiting time from the question (#1685); a refused workspace claim undoes the platform claim too (#1675); a second rejection no longer claims an `[ask]` it failed to send (#1673); lead scripts report what really happened when a recall, judge or wake-up fails (#1686).
- **Cooldowns:** provider cooldown starts at 5 minutes and stops at 20 (was 10 with no ceiling) (#1658, thanks @Zssan12); a model cooldown no longer skips shell jobs or marks a skipped timer as fired (#1672).
- **Separate data directory:** with a non-default `BOTHOUSE_DATA_DIR`, the main wiki goes to `<data>/wiki`; default installs keep `~/wiki` (#1663).
- **DSH collab watchdog** judges text-row progress by `created_at`, so a streaming message from before the window is not new progress (#1661).

## Improvements

- Bash guard catches wait loops that sleep through an inline interpreter and the `alarm N; exec @ARGV` wrapper (#1662).
- Removed confirmed dead code after an audit (#1664); four CI tests follow the new task-state rules (#1687).

## 重点

- **新 README。** 首页只讲一件事：几个不同的 AI 进一个群，组长 AI 分活，大家共用一份记忆。开头是总览图、演示视频和安装命令，另有两张图讲一件活怎么做完、团队能做什么；细节挪进 `docs/`（#1689）。
- **任务状态只有一份。** 每件工作区的活都记在桥管的一份状态里：轮次知道自己属于哪件活，忙、空闲、认领、对账都读这份状态（#1632，感谢 @Zssan12；#1665）。工作区只通过 `ws-up --report` 交回，不再从回复文字里认（#1668、#1683）。任务板改调桥改状态（`bothouse workspace transition`），旧补丁层删掉：板上文字里的收尾词、「一小时没动就暂停」、看门读频道历史（#1676）。
- **夜里起草角色技能。** 夜间整理会起草新的角色技能和修订；技能页按角色或 DSH 成员预览、编辑、丢弃、确认，DSH 只加载该角色已启用的技能（#1648，感谢 @Zssan12）。

## 缺陷修复

- **交回：** 用命令交回就算交了报告，之后不再催「没交报告」，排着的会话重置照常执行（#1688）；交回被退回或发不出去时，活仍算在做（#1674）；被打回的暂存报告不再算已贴出（#1667）；验收关着时，只有真贴出的交回才把活标完成（#1681）。
- **团队模式常识梳理（#1492）：** 查模型列表失败不再缓存成「不支持」，主角色快速关开只留一个置顶表循环，释放工作区存盘失败就不释放，扫描放行也关任务板条目，额度换主时清看门计数（#1684）；置顶任务表保留子区、论坛帖、私聊派的活，卡住超过一天的活不收进搁置，「等了多久」从提问时算（#1685）；工作区认领被拒时，平台侧认领也撤回（#1675）；第二次打回不再声称发了其实没发出的 `[ask]`（#1673）；主角色脚本在搜旧定案、判断、叫醒失败时照实报告（#1686）。
- **冷却：** provider 冷却从 5 分钟起、最长 20 分钟（之前从 10 分钟起且没有上限）（#1658，感谢 @Zssan12）；模型冷却不再跳过 shell 定时任务，也不再把跳过的定时器标成已触发（#1672）。
- **独立数据目录：** `BOTHOUSE_DATA_DIR` 不是默认目录时，主 wiki 放在 `<data>/wiki`；默认安装仍用 `~/wiki`（#1663）。
- **DSH 协作页看门** 文本行按 `created_at` 判进展，窗口前发出、还在流式变长的消息不再算新进展（#1661）。
