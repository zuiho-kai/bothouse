## Highlights

- **Roles can say what bothouse is.** Product notes now ship inside the binary (`bridge/about/ABOUT.md`, `ABOUT.zh-CN.md`) and update with every release. The new `bothouse about` command prints them, along with the version and this machine's roles, CLIs and platforms. It prints names and types only, no option values or tokens. Every agent gets a one-line hint to read them when asked "what are you" or "how does it compare". The README comparison now includes LobeHub (#1506).
- **One desktop pet per role.** Each bound role gets its own pet in its own skin. The pet moves, shows bubbles and opens chat only for that role. Pets have a per-pet size (small / medium / large) in the right-click menu (#1452). The plugin page lists the hunmer/aboutme-pets packs with source and license. They download from the author's pinned commit only after you click, and they install only if every file passes its SHA256 check (#1473).
- **Redesigned panel.** The web panel and the DSH "bothouse panel" share one frontend. It now has a top bar with five tabs (Overview, Roles, Chat, Sessions, Usage) plus an "All features" launcher, and a bottom tab bar on phones. Overview says who is busy and if anything needs attention, role cards lead with the current task, and chat uses an inbox-style list. Every old route still works (#1483).
- **Phone browser pairing.** Over Tailscale, a phone without DSH can open the paired machine's pairing port in a browser. It enters the same 6-digit code to see channels and send messages. The phone shows up under connected devices, and kicking it closes its session right away (#1477).
- **Quick messages from one person are merged.** When one person sends several short messages in a row, the gate waits until they stop for `gate_sender_silence_ms` (default 1500 ms) and answers them in one turn. The wait is capped at `gate_sender_silence_max_ms` (default 6000 ms) (#1484). Another person's message is no longer merged into that batch (#1500).
- **Discord wizard lets the whole server give orders.** If you pick a server and give no `allow_from`, the wizard now writes `allow_from = "*"`, so other members of a team channel get answers too. `allow_guilds` still keeps the bots to that server, and the owners keep `admin_from` (#1476).

## Fixes

- **Workspaces and reports:** a late `[report]` / `[ask]` goes to the task's own chat (#1485). Thread (sub-channel) dispatch works, and one-role teams review their own handbacks in a fresh side session (#1488). A `[report]` with gaps goes to the lead with a note instead of bouncing, and `[ask]` bounce reasons are no longer posted in the channel (#1487). Accepting a report the checker doubted needs a quote of the user's own words (#1493). Reports carry their documents, missing permissions are reported, and late session minutes are written (#1492). A board PR link no longer overwrites the handoff path (#1489). `ws-pass` no longer crashes on a fresh install (#1503). Teammate status also lists idle members and how to @ them (#1482).
- **Direct messages:** `send --dm --to <member>` works, and an ownerless `--dm` is refused in a turn that is not the owner's (#1491). If Discord refuses the DM, it falls back to a private thread with that member (#1501).
- **Hooks:** installed hook scripts refresh after a release upgrade (#1490). `ask-only-guard` treats polite requests as requests (#1486).
- **Gate:** after a 404 from the lead, the gate no longer takes messages that clearly name another role (#1451). The "knows you" profile is pushed as a whole page (#1464).
- **Setup and pet:** the wizard re-checks CLI login when you reach the step. The pet waits for a recommended skin to finish downloading (#1481).
- **DSH:** three fixes for "Open DSH" on Mac, and it takes over the web process by trying the candidate logs one by one (#1255). The sidebar keeps the open panel in the URL hash, so a refresh or bookmark opens the same panel (#1474). Over-long channel messages are checked by character count before sending, and the too-long error is localized (#1475).
- **Wiki:** `--pending` handles one model batch per run, and timed-out cron / timer jobs cancel their whole process tree (#1467). Quote checks are tighter, and an optional QQ memory commit guard was added (it is not turned on yet) (#1469).
- **Web:** the gradient on the overview's Wiki galaxy card no longer bleeds past the canvas (#1505).

## Improvements

- **Queue receipts** show how long the current task has run, how many messages are waiting, and what `/stop` does to the queue (#1442).
- **The plugin page** can uninstall a package (#1420).
- **Claude Code** can switch to Fable (`bothouse model set fable`) (#1478).
- **Tests:** Discord webhook people, wizard expectations, `send --dm` end to end, and the test-instance `env.sh` (#1479, #1480, #1502, #1504).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.63`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **角色能说清 bothouse 是什么。** 产品说明随程序一起发（`bridge/about/ABOUT.md`、`ABOUT.zh-CN.md`），每版跟着更新。新命令 `bothouse about` 打印说明、版本，以及这台机器的角色、CLI 和平台。它只打印名字和类型，不打印配置值和令牌。每个 agent 都有一句提示：被问「你是什么」「和别家比怎样」时先读它。README 对比表补上了 LobeHub（#1506）。
- **一个角色一只桌宠。** 每个绑定的角色都有自己的一只桌宠，穿自己的形象。桌宠的动作、气泡和聊天只跟着这个角色。右键菜单可以给每只单独调大小（小 / 中 / 大）（#1452）。插件页列出 hunmer/aboutme-pets 四个形象包，附来源和许可。点了才从作者仓库的固定提交下载，每个文件都过 SHA256 校验才安装（#1473）。
- **面板改版。** 网页面板和 DSH 里的「bothouse 面板」用同一套前端。现在顶栏有五个主页签（概览、角色、聊天、会话、用量），另有「全部功能」入口；手机上是底部页签栏。概览说清谁在忙、有没有要处理的事；角色卡先显示当前在做的活；聊天改成收件箱式列表。原来的页面地址都还能打开（#1483）。
- **手机浏览器配对。** 手机不用装 DSH：开着 Tailscale，用浏览器打开被指挥那台电脑的配对口，输同一套 6 位码，就能看频道、发消息。手机会出现在「已连接的设备」里，踢掉后当场断开（#1477）。
- **同一个人连发会合成一轮。** 一个人连着发几条短消息时，gate 等他停手 `gate_sender_silence_ms`（默认 1500 毫秒）再一起回。最多等 `gate_sender_silence_max_ms`（默认 6000 毫秒）（#1484）。别人发的消息不会被并进这一批（#1500）。
- **Discord 向导默认让整个服务器都能指挥。** 选了服务器又没填 `allow_from` 时，向导现在写 `allow_from = "*"`，团队频道里的其他成员也能得到回复。`allow_guilds` 照样只让机器人留在这个服务器，所有者保留 `admin_from`（#1476）。

## 缺陷修复

- **工作区和汇报：** 晚到的 `[report]` / `[ask]` 发回这件活自己的聊天频道（#1485）。子区里能派活；只有一个角色的团队，交回的活由它在新开的旁路会话里验收（#1488）。有缺项的 `[report]` 带着一行说明交给主角色，不再退回；`[ask]` 的退回原因不再贴进频道（#1487）。核对标了疑点的汇报，要引用户本人的原话才能放行（#1493）。汇报带上文档，缺权限会报出来，晚到的会话摘要会补写（#1492）。任务板的 PR 链接不再覆盖交接路径（#1489）。新装时 `ws-pass` 不再崩（#1503）。队友状态也列出空着的队员和 @ 法（#1482）。
- **私信：** `send --dm --to <成员>` 能用；不是所有者的那一轮里，没指定成员的 `--dm` 会被拒（#1491）。Discord 拒收私信时，改在私密子区里发给这个成员（#1501）。
- **钩子：** 升级到新版后，已装的钩子脚本会跟着刷新（#1490）。`ask-only-guard` 把客气的请求当成请求（#1486）。
- **Gate：** 主角色请求 404 之后，不再接走明确点名其他角色的消息（#1451）。「懂你」画像整页推送（#1464）。
- **向导和桌宠：** 向导到 CLI 那一步时重新检查登录状态。桌宠等推荐形象下载完（#1481）。
- **DSH：** 修了 Mac「打开 DSH」的三处问题，并按候选日志逐份试着接管网页进程（#1255）。侧栏把打开的面板写进地址栏 hash，刷新或收藏后回到同一面板（#1474）。频道页的超长消息发送前按字符数检查，too-long 报错显示成本地语言（#1475）。
- **Wiki：** `--pending` 每次只处理一批模型批次；cron / timer 超时时取消整棵进程树（#1467）。原话核对更严；新加一个可选的 QQ 记忆提交守卫（还没启用）（#1469）。
- **网页：** 概览里 Wiki 星河卡的渐变不再透出画布（#1505）。

## 改进

- **排队回执** 显示当前任务跑了多久、还有几条消息在等，以及 `/stop` 会对队列做什么（#1442）。
- **插件页** 可以卸载一个包（#1420）。
- **Claude Code** 能切到 Fable（`bothouse model set fable`）（#1478）。
