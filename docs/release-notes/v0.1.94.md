## Highlights

- **Old memory learns what it is: fact, inference, or guess.** Every line the wiki's idle and nightly passes write now carries one of the four credibility classes, and a new retag tool brings existing pages along. A line keeps its wording and gets a `（推论）` or `（推测）` marker at the end; a line the page itself has plainly overturned moves, verbatim, into that page's `## 历史` section. The no-forgetting check now treats those end-of-line markers as metadata, so tagging an old line — or correcting its tag — no longer reads as a lost line, while any other change to the wording still does. (#2231)

## Fixes

- **`NO_REPLY` inside a sentence is content again.** Only a `NO_REPLY` that stands on its own line silences a turn; mentioning it mid-sentence no longer swallows the reply. (#2227)

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.94`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **旧记忆也分得清事实、推论和猜测了。** 空闲总结和凌晨总结写下的每一行现在都带四类可信度，存量页面也有专门的重标工具跟上：原文一个字不动，只在行尾补「（推论）」或「（推测）」；被本页后文明确推翻的行，原样挪进本页的「## 历史」。防遗忘检查现在把行尾这四类标记当元数据，给旧行补标、改标不再算丢行，改其它字仍然报丢。 (#2231)

## 缺陷修复

- **句子里提到 `NO_REPLY` 不再吞掉回复。** 只有单独一行写 `NO_REPLY` 才静默，句中出现只当普通文字。 (#2227)
