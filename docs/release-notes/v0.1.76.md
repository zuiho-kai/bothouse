## Highlights

- **DSH plugin works on its own.** If you install only DSH and the bothouse DSH plugin (no bridge), members now get their own memory directory (`~/.bothouse` by default, with a starter `MEMORY.md` on the first turn), their name and persona go into the DSH system prompt, and when the memory service (gate) is missing the channel shows one notice instead of failing silently (#1826).
- **Plugin-only install on Windows.** The local commands members are told to run (one-off check, open workspace, build team) now use PowerShell syntax on Windows; members can write their memory pages outside DSH's file sandbox through `later.mjs memory` (#1838). Inside the DSH desktop app, local commands carry `ELECTRON_RUN_AS_NODE`, CLI members get both PowerShell and Git Bash forms of the follow-up command, and the plugin package ships the Claude/Codex ACP adapters, so CLI members start even when `node` is not on PATH (#1839).
- **Big jobs keep the chat context.** When a DSH chat hands a big job to a workspace, the workspace's first turn gets the last 50 lines of the chat, members can read the results handed back, and the channel says so when a lost session is replaced (#1836).
- **Plugin-only smoke test before every merge.** A new `dsh-plugin-solo` CI job packs the plugin, installs it into an empty HOME with `dsh plugin add`, starts `dsh web` and checks the memory directory, persona and missing-gate notice (#1832).
- **Discord task forum, first batch.** Each Discord task gets a post in a "Tasks" forum; the first post shows status, what the user needs to do, owner, workspace and source link, and tracks the task board; handbacks and questions go to the same post (#1785, thanks @Zssan12).

## Fixes

- **Profile rewrite keeps every line**: lines that don't match the format and other `##` sections move into "History" instead of being dropped; on start, the bridge refreshes the programs of the wizard-built main wiki from its own package (#1835).
- **Quota evidence for dispatch**: teammate status, board, voice desk and dispatch share one quota evidence; unknown or exhausted quota is not dispatched to (#1831, thanks @Zssan12).
- **`/usage` shows every window**: Claude's model-specific weekly quota is shown and each query is logged (#1830, thanks @Zssan12).
- **Cancellation per turn**: a queued turn no longer inherits the previous turn's cancellation, so its errors are shown and counted (#1788, thanks @Zssan12).
- **Workspaces and code maps**: handbacks add code map entries again, dispatch shows the map format, idle workspaces are shared (#1823); stale pause records no longer block idle workspaces (#1824).

## Improvements

- **Core cleanup**: new `core/team` package for handback rules and board row storage, and a narrow `team.Host` interface (#1818, #1821); core tests compile again after the move (#1822).
- **Tests**: exit rules test follows the moved file (#1833); DSH code map retry test uses the real rewritten arguments (#1834).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.76`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **只装 DSH 插件也能用。** 只装 DSH 和 bothouse 的 DSH 插件（不装桥）时，成员有自己的记忆目录（默认 `~/.bothouse`，首轮自动建 `MEMORY.md` 起始页），成员名和人设进 DSH 系统提示词；缺记忆服务（gate）时频道里提示一次，不再悄悄失效（#1826）。
- **Windows 上插件单装。** 让成员跑的本机命令（一次性回查、开工作区、建团队）在 Windows 上改成 PowerShell 写法；成员通过 `later.mjs memory` 写 DSH 文件沙箱外的记忆页（#1838）。DSH 桌面版里本机命令自带 `ELECTRON_RUN_AS_NODE`，CLI 成员的回查命令给 PowerShell 和 Git Bash 两种写法；插件包带上 Claude/Codex 的 ACP 适配器，PATH 里没有 `node` 也能起 CLI 成员（#1839）。
- **大活转工作区带上聊天上文。** DSH 聊天把大活转给工作区时，工作区第一轮附上聊天最近 50 行，交回的结果成员读得到；绑定会话丢了换新会话时频道里说一句（#1836）。
- **合并前自动按插件单装冒烟。** 新增 `dsh-plugin-solo` 检查：打包插件、`dsh plugin add` 装进空白 HOME、起 `dsh web`，核对记忆目录、人设和缺 gate 提示（#1832）。
- **Discord 任务论坛第一批。** Discord 来的每件活在「任务」论坛有一个帖子，首楼显示状态、要用户做的事、负责人、工作区和来源链接，跟着任务板更新；交回和提问发到同一个帖子（#1785，感谢 @Zssan12）。

## 缺陷修复

- **画像重写不丢行**：对不上格式的行和其他「##」节的行挪进「历史」，不再丢；桥启动时把向导建的主 wiki 的程序换成本包的（#1835）。
- **派活按额度证据**：队友状态、看板、语音台和派活共用一份额度证据，额度未知或用完的不派（#1831，感谢 @Zssan12）。
- **`/usage` 显示全部窗口**：显示 Claude 模型专属周额度，并记录每次查询结果（#1830，感谢 @Zssan12）。
- **取消状态按轮算**：排队的轮不再继承上一轮的取消状态，它的报错照常显示、计入失败（#1788，感谢 @Zssan12）。
- **工作区和代码地图**：交回重新补地图、派活附地图格式、空闲工作区共用（#1823）；过时的暂停记录不再挡空闲工作区（#1824）。

## 改进

- **核心清理**：新建 `core/team` 包放交回规则和板行存储，定 `team.Host` 窄接口（#1818、#1821）；搬完后 core 测试重新能编（#1822）。
- **测试**：交回规则测试跟着文件搬家（#1833）；DSH 代码地图重试测试用真实改写后的参数（#1834）。
