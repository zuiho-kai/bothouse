## Highlights

- **DSH desktop is the default setup route.** Setup now walks through the DSH desktop app first, with the web version as an option; DSH setup survives a page reload, and a DSH-only overview shows members and channels first (#1263, #1265, #1270).
- **The judge model is optional.** It is off by default with a one-click Qwen3.5-4B preset; without it, only @-mentioned roles answer, and setup says so. Qwen3 0.6B is no longer recommended anywhere (#1257, #1260, #1262, #1267, #1268).
- **QQ quoted replies.** A quoted QQ message keeps its author and text even after a restart (it is fetched with OneBot `get_msg` when not cached), and roles can send native QQ quoted replies (#1275, thanks @Zssan12).
- **Memory forum as threaded posts.** The memory forum becomes a thread list with floors: each push carries the thread title and its top-scored floor, and new content is added as a new floor; the forum page loads in about 0.6 s instead of 13 s+ (#1276, #1277, #1269).
- **Usage page date ranges.** Quick date-range filters and a token consumption breakdown on the usage page (#951, thanks @Zssan12).
- **Hand-back review can be turned off.** `[team_review] disabled` switches off the automatic review of workspace hand-backs (#1284).

## Fixes

- **Idle watch:** the main chat channel no longer gets an idle watch just because of a board item (#1250); a later `[report]` line ends the watch and stale numberless watches close before they wake anyone (#1278, #1279); a `[report]` without a board number ends its watch, and a turn that ran tools no longer revives a watch that already escalated (#1156, thanks @Zssan12); failures that are not the task's own (timer timeouts, /stop, rate-limit retries) no longer count against it (#1235, thanks @Zssan12).
- **Scheduled turns** no longer make a role report to the user out of turn (#1283).
- **Discord cards:** switching between detailed and brief view redraws cards from finished turns and from before a restart (#1286, #1288); the detailed view keeps every line of the turn in full, paged when it exceeds the embed limit, in task threads too (#1291, #1292).
- **DSH:** reopening DSH after it stopped works, with clearer prerequisites for new users (#1259); a second DSH instance connects to the running channel host instead of failing (#1236); `/stop` and the stop button interrupt a DSH member's turn at once (#1272); queued tasks are cancelled when a member is recycled, leaving no orphan processes (#1254); plugin refresh no longer sticks on an old-format version stamp (#1256); @-mention rules match between front and back end, and inline code no longer wakes anyone (#1249); remote channels use the React channel page, with @ suggestions and message tools (#1234); the panel explains why DSH failed (ported from the QQ production bridge, #1282, thanks @Zssan12).
- **Voice:** transcribed speech is marked as coming from voice, and group queue batches are labelled per message (#1238, thanks @Zssan12).
- **Board and quota:** board writes use a unique temp file with bounded retries on Windows file locks (#1251); quota cooldown is decided in one place, so handing the lead back and taking over read the same state (#1252) (thanks @Zssan12).
- **Other computers:** unpaired computers no longer send heartbeats, so no phantom device appears in the panel (#1253, thanks @Zssan12).
- **Chinese UI:** renaming a channel or member shows a Chinese error message when it fails (#1273, thanks @Zssan12).

## Improvements

- **DSH channels:** valid @-mentions are highlighted while typing (#1232); attachments upload as a stream with a configurable size limit (default 1 GB) and show progress (#1237) (thanks @Zssan12).
- **Setup page dark theme** and header and role-list tweaks (ported from #1282, thanks @Zssan12).
- **Task reminders:** re-arms of a later reminder are capped at 6 per task per 24 h (#1271).
- **Docs:** getting started without rollback, architecture packages, upgrade notes; Discord go-live steps in order; a DSH no-key card (#1258, #1267).

## 重点

- **DSH 桌面版成为默认安装路线。** 设置向导先走 DSH 桌面版，网页版可选；DSH 设置刷新页面不丢，只用 DSH 时概览先显示成员和频道（#1263、#1265、#1270）。
- **判断模型可选。** 默认关闭，一键套用 Qwen3.5-4B；不开时只有被 @ 的角色回话，向导里写明；各处不再推荐 Qwen3 0.6B（#1257、#1260、#1262、#1267、#1268）。
- **QQ 引用回复。** QQ 里被引用的消息重启后也保留原作者和原文（缓存没有时用 OneBot `get_msg` 补取），角色可以发 QQ 原生引用回复（#1275，感谢 @Zssan12）。
- **记忆论坛改成楼层帖。** 帖子列表加楼层：推送带帖子标题和最高分楼，新内容跟楼；论坛页加载从 13 秒以上降到约 0.6 秒（#1276、#1277、#1269）。
- **用量页日期快选。** 用量页加日期范围快选和 token 消耗拆分（#951，感谢 @Zssan12）。
- **交回自动验收可关。** `[team_review] disabled` 关掉工作区交回的自动验收（#1284）。

## 缺陷修复

- **看门：** 主聊天频道不再因为板上条目挂空闲看门（#1250）；后面行里的 `[report]` 也能收口，过期的无编号看门在叫人前关掉（#1278、#1279）；没写任务板编号的 `[report]` 能收口，已升级的看门不会被一轮跑了工具的回合复活（#1156，感谢 @Zssan12）；不是这件活本身的失败（定时轮超时、/stop、限流重试接手）不再算到任务头上（#1235，感谢 @Zssan12）。
- **定时轮** 不再让角色对用户乱汇报（#1283）。
- **Discord 卡片：** 细节/简略切换能重画已结束轮和重启前的卡（#1286、#1288）；细节档保留整轮全部行、每行全文，超长分页，任务子话题里也一样（#1291、#1292）。
- **DSH：** DSH 停了以后能重新打开，新用户的前置条件写得更清楚（#1259）；后开的 DSH 自动连上已在运行的频道宿主，不再报错（#1236）；`/stop` 和停止按钮立即打断 DSH 成员当前轮次（#1272）；成员回收后打断排队任务，不留孤儿进程（#1254）；插件刷新不再卡在旧格式版本戳上（#1256）；@ 规则前后端一致，行内代码不再叫醒人（#1249）；远程频道改用 React 频道页，有 @ 候选和消息工具条（#1234）；面板说明 DSH 失败原因（从 QQ 生产桥搬回，#1282，感谢 @Zssan12）。
- **语音：** 语音转写标明来自语音，群队列批按条标注（#1238，感谢 @Zssan12）。
- **任务板和额度：** 任务板落盘用唯一临时名，Windows 文件被占用时有界重试（#1251）；额度冷却判定收在一处，还主角色和接管读同一份（#1252）（感谢 @Zssan12）。
- **其他电脑：** 没配对的电脑不发心跳，面板不再出现假设备（#1253，感谢 @Zssan12）。
- **中文界面：** 改频道名、成员名失败时显示中文错误提示（#1273，感谢 @Zssan12）。

## 改进

- **DSH 频道：** 输入框里有效的 @ 成员实时变色（#1232）；附件改流式上传，上限可配（默认 1 GB），带上传进度（#1237）（感谢 @Zssan12）。
