## Highlights

- **DSH plugin becomes a thin adapter.** The DSH channels plugin now keeps only channels, messages, attachments, the member list and pages; members run as bothouse roles, so team logic (tasks, timers, memory, dispatch rules, quota) lives in the bridge once. The plugin hands its members to `bothouse setup apply`, starts bothouse if it is not running, and runs the official installer when bothouse is missing (#1847).
- **@ parsing moves into the bridge.** Who is called, what each bot reads, reply routing and text permission answers ("允许" / "deny") are now decided by the bridge for DSH channels; the plugin's duplicate copies of mention parsing, permission vocabulary, persona catalog and its old task tables are removed (#1849).
- **Discord task forums per category.** Discord tasks now get one task forum per source-channel category instead of one server-wide forum; each post keeps its task ID and original conversation, and channels without a category get a prompt to classify them (#1825, thanks @Zssan12).

## Fixes

- **Missing agent CLI no longer stops the bridge**: a role whose CLI is not installed is skipped with an error log, and the other roles start (#1850).
- **Codex members in DSH**: they no longer get local commands their network-less sandbox cannot reach, and when asked to hand work to a teammate they just @ her (#1846).
- **DM replies without tools**: the empty "step 0" progress card is deleted at the end of the turn, so the reply is the only message (#1843).
- **Wiki nightly jobs**: dream skips batches with no quotable user line instead of calling the model; manual registration follows split index pages; Agent SDK buffer raised to 64 MB (#1840). Dream sends each quotable user line together with the reply it got (#1845), matched by whole line (#1851).
- **Wiki page split**: an overview page whose directory is already full is merged into an existing page in the same directory instead of retrying every night (#1851).

## Improvements

- **Wiki tools in the repo**: the nightly restate pass and `search.py` id lookup move from the live wiki into the repo (#1854).
- **README**: the top banner shows the supported tools' icons; the characters move to an optional "Roles" section (#1848).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.77`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 插件变成薄适配层。** DSH 频道插件只留频道、消息、附件、成员列表和页面；成员作为 bothouse 角色运行，派活、定时、记忆、派活规矩、额度这些团队逻辑只在桥里一份。插件把成员交给 `bothouse setup apply`，bothouse 没在跑就拉起，没装就跑官方安装器（#1847）。
- **@ 解析搬进桥。** DSH 频道里叫到谁、每个 bot 读到什么、回复发去哪、文字回答权限（「允许」/「拒绝」）都由桥决定；插件里重复的 @ 解析、权限词表、人设目录和旧任务表都删掉（#1849）。
- **Discord 任务论坛按分类分开。** Discord 来的活不再共用全服一个论坛，改成每个来源频道分类一个任务论坛；每个帖子保留任务号和原对话，没有分类的频道会提示先归类（#1825，感谢 @Zssan12）。

## 缺陷修复

- **缺 agent CLI 不再让桥退出**：CLI 没装的角色记一条错误日志后跳过，其他角色照常起（#1850）。
- **DSH 里的 Codex 成员**：不再拿到沙箱断网、根本连不上的本机命令；被要求派给队友时直接 @ 她（#1846）。
- **私聊不用工具的回复**：回合结束时删掉「第 0 步」空进度卡，只剩正文一条（#1843）。
- **wiki 夜间任务**：dream 遇到没有可引用用户消息的批次不再调模型；manuals 登记跟着拆页走；Agent SDK 缓冲调到 64MB（#1840）。dream 把每条可引用用户消息和它得到的回复一起送模型（#1845），按整行配对（#1851）。
- **wiki 拆页**：目录已满的总览页改成并进同目录已有页，不再每晚重试（#1851）。

## 改进

- **wiki 工具进仓库**：夜间 restate 合并和 `search.py` 按 id 查找从线上 wiki 搬进仓库（#1854）。
- **README**：顶部横幅换成支持的各家工具图标，角色挪到可选的「角色」小节（#1848）。
