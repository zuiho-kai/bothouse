## Highlights

- **README without the AI look.** The purple/blue/green gradients are gone and the architecture diagram is redrawn as a plain component diagram: chat on the left, bothouse in the middle, CLIs below, memory and private repo on the right (#1860). The numbered section banners, star banner, features infographic and repository status card are removed; the top image is a real Discord handoff screenshot and the promo cover is a real frame from the video (#1861). Both English and Chinese READMEs.

## Fixes

- **Discord task forums skip the workspace category**: a source channel inside the workspace category no longer gets a task forum; tasks that only recorded a workspace go to the forum of the main chat channel's category (#1859).
- **Discord bot identity race**: the bot and application IDs set on Ready are now read and written under a lock, removing a data race with other event handlers (#1858).

## Improvements

- **Optional Discord ack reactions**: with `ack_reaction = true` (off by default) the bot puts 👀 on each message it takes on and swaps it for ✅ when the turn finishes or ❌ when it fails; a 👀 left by a restart is cleared on reconnect (#1858).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.78`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

- **README 去掉 AI 味。** 去掉紫蓝绿渐变，架构图重画成朴素的组件图：左边聊天软件，中间 bothouse，下面各家 CLI，右边记忆和私有仓库（#1860）。删掉带编号的章节横幅、星标横幅、功能信息图和仓库状态卡；顶部换成真实的 Discord 派活截图，宣传片封面换成视频里的真实画面（#1861）。中英两份 README 都改了。

## 缺陷修复

- **Discord 任务论坛不进工作区分类**：来源频道在「工作区」分类里时不再建任务论坛；只记了工作区的活改挂到主聊天频道所在分类的论坛（#1859）。
- **Discord 机器人身份字段竞争**：Ready 时写入的机器人 ID 和应用 ID 改为加锁读写，消除与其他事件处理的数据竞争（#1858）。

## 改进

- **可选的 Discord 回执表情**：设 `ack_reaction = true`（默认关）后，bot 接下消息先贴 👀，这一轮结束换成 ✅（完成）或 ❌（出错）；重启留下的 👀 会在重连时清掉（#1858）。
