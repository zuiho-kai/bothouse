Task watches keep going while there is progress, and the lead is woken when a task ends. DSH handbacks and teammate calls are read more reliably.

## Task watch and relay

- **A task relay is not cut off by the drain timer.** A dispatched task runs as long as the 10-minute watch sees progress. When it ends (result handed back, stopped by the watch, or no result), the lead session gets one wake-up with the task, the owner and the result. A watch with progress now renews with no limit (#430).
- **Watch gaps closed.** "Busy" alone renews at most 2 times, then counts as no progress. If the watch cannot start, the 10-minute drain limit still applies. After a bridge restart, an interrupted relay wakes the lead once (#452).
- **Clean shutdown.** On stop, sessions close in parallel with a 20-second total limit. Sessions that do not close in time are force-killed, so no orphan agent processes stay behind (#439).
- **Turn journal.** The bridge writes a record when a turn starts, deletes it when the turn ends, and marks it interrupted on shutdown (#440).

## DSH and teamwork

- **More [report] forms count as a handback.** A `[report]` after a leading `@` counts (#428). A later line in the same message that starts with `@lead [report]` also counts (#434). Answers forwarded into a workspace show the member name, not an internal id (#428).
- **Praise is not a new task.** After a task is handed back or accepted, calling a teammate by bare name waits for her stance (accept / ask / decline / escalate) before a task opens. An explicit `@` opens a task at once, as before (#447).
- **Busy is per channel.** A teammate busy in another channel or a DM no longer blocks dispatch in this channel (#451).
- **Channel-scoped members and session directories.** Members and bots can be scoped to channels. New sessions use the directory set for each channel; workspaces inherit from their parent channel. Disconnected bots stay in the roster as offline (#398).
- **CLI start errors keep the details.** When a CLI cannot start, the error shows the channel, the working directory and the original cause. The next ask retries after you fix it (#438). A collab test no longer fails when the repo path has non-ASCII characters (#405).
- **acp + DSH roles start fresh after idle again.** DSH session logs now feed the idle-handoff reader. If cold-cache fresh start is on but the backend cannot read its logs, the bridge prints a warning at startup (#444).

## Setup, workspaces and task board

- **Role directories get `notes/`.** Setup creates `notes/` in each new role directory, so the first handoff file can be written (#432).
- **No repeated workspace names on cards.** Cards show "Workspace1·name", both in the main channel (#432) and in the workspace's own channel (#436).
- **Setup accepts CLI names.** `agent_type` values such as `claude`, `agy` or `cursor-agent` map to the registered agent. An unknown type is rejected before anything is written (#449).
- **Discord workspace tests.** Workspace creation, watch nudges, restart and missing permissions are tested against a fake Discord API (#435).

## 看门和派工

- **派工不再被收尾计时掐断。** 派出去的任务，只要十分钟看门看到进展就一直跑。结束时（交回结果、被看门停下、没有结果）给主 bot 会话发一次唤醒，写明任务、执行者和结果。有进展的看门续期不设上限（#430）。
- **补齐看门缺口。** 只是「忙」最多续 2 次，之后按没进展处理。看门起不来时，仍按 10 分钟收尾期限结束。桥重启后，被打断的派工会叫醒主 bot 一次（#452）。
- **停机干净。** 停机时并行关会话，总时长封顶 20 秒；到点没关完的强制结束，不再留下孤儿 agent 进程（#439）。
