## Highlights

- **Only the primary role answers unaddressed group messages.** With several roles in one group, a message that names nobody is answered by the configured primary role only; when you name a teammate, the primary role stays quiet. This now works even without a team runtime.
- **New Codex roles can ask for permission.** The setup wizard gives new Codex roles the `app_server` backend and the provider's model, so a request that needs a permission shows an approval card instead of being refused.
- **`update` updates the right instance.** The update command now targets the instance of the current HOME / `--config`, so it no longer connects to another running instance on the same machine.
- **One owner per workspace.** A workspace belongs to one chat channel at a time; questions and reports go straight back to that channel, and the workspace is released when its tasks are done or the primary role starts a new session.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **没点名的群消息只由主角色回。** 一个群里有多个角色时，没点名的消息只由配置的主角色回答；点了队友的名，主角色不插话。没有团队运行时也生效。
- **新建的 Codex 角色能申请权限。** 向导给新的 Codex 角色默认用 `app_server` 后端和服务商的模型，需要权限的请求会弹出审批卡片，不再直接被拒。
- **`update` 只更新当前这一份。** 更新命令按当前 HOME / `--config` 找实例，不再连到同一台机器上另一个正在运行的实例。
- **工作区一次只归一个聊天频道。** 提问和汇报直接回到这个频道；活做完或主角色开新会话时，工作区自动释放。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）
- **校验：** `SHA256SUMS`

从 v0.1.6 起，以后的版本点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。
