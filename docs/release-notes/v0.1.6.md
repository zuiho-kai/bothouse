## Highlights

- **Version and one-click update in the sidebar.** The bottom-left corner now shows the version you are running. When a new release is out, an **Update to vX** button appears. Click it: bothouse downloads the new version, restarts, and the page reloads on the new version. With the sidebar collapsed you still get a small version label and an update icon.
- **Safe updates.** After an update, bothouse checks that the new version starts. If it does not, it automatically goes back to the previous version. If the update fails, you see the reason and an **Open download page** button.
- **Your data stays.** Updating does not touch your settings, personas, wiki, sessions, avatar library, channel history or model keys. The built-in DSH plugin code is refreshed to match the new version, and your DSH settings are kept.
- **DSH plugin as a separate package.** The bothouse channels can now be installed into DeepSeek Harness (DSH) on their own as the `bothouse-dsh` plugin, without the full app: a Discord-style channel page where DSH models and local Claude Code, Codex and Gemini CLIs are members. An empty channel guides you to **Add member**. See `dsh/plugin-pkg/README.md`.

## Improvements

- **Dependencies reinstall when they change.** The installer now reinstalls dependencies whenever the package list or lockfile changes, so an update never runs against stale ones.
- **Faster, steadier release builds** on our own build machines.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Future updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **左下角显示版本，一键更新。** 侧栏左下角显示当前版本。有新版时出现「更新到 vX」按钮，点一下就下载新版、自动重启，页面刷新后就是新版本。侧栏收起时也有小号版本和更新图标。
- **更新失败自动退回旧版。** 更新后 bothouse 会检查新版能不能正常启动，起不来就自动回到原来的版本。更新失败时显示原因和「打开下载页」按钮。
- **用户数据不动。** 更新不碰你的设置、人设、wiki、会话、头像库、频道记录和模型 Key。内置的 DSH 插件代码会随新版刷新，你的 DSH 配置保留。
- **DSH 插件可单独装。** bothouse 的频道现在可以作为 `bothouse-dsh` 插件单独装进 DeepSeek Harness（DSH），不用装完整版：Discord 式的频道页，DSH 里的模型和本机的 Claude Code、Codex、Gemini CLI 都能当成员。频道里还没有成员时，页面会引导你「添加成员」。用法见 `dsh/plugin-pkg/README.md`。

## 改进

- **依赖有变就重装。** 安装脚本在依赖清单或锁文件变化时自动重装依赖，更新后不会用到旧依赖。
- **出包改在自己的构建机上跑，更快更稳。**

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）（`chmod +x` 后运行）
- **校验：** `SHA256SUMS`

从 v0.1.6 起，以后的版本点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。

安装包未签名。macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键→打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息→仍要运行」。
