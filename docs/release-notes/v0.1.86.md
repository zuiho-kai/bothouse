## Highlights

- **The DSH plugin sets itself up in one click.** Type the package name `bothouse-dsh` on DSH's Plugins page, install, click Enable — that is it. On first start the plugin adds a DSH member plus one member for each CLI it finds on this computer (Claude Code, Codex, Gemini), named after the software and shown with its icon, and makes DSH the primary role. It then installs and starts the background service, the memory service and the memory wiki (an existing wiki is reused, otherwise one is made), checks each one, and says 装好了 in #general only when everything passes; otherwise it lists exactly what is stuck and how to fix it (for example a CLI that still needs a login). While it prepares, #general shows progress, and messages you send in the meantime are answered once the members are up. A message that @s no one is answered by the primary role. A member whose CLI is not logged in shows "needs sign-in" with the login hint instead of a green online dot. The add-member dialog only asks which role to connect; name, avatar and persona live under **More**. The setup wizard's saved-steps list folds into one line, and four DSH experimental plugins (voice input, custom plugin index, auto-approval review, Git worktrees) are hidden on the Plugins page. Installing without a version number now gets the latest release: the plugin updates itself to npm's latest (#2005).

## Fixes

- **The self-check no longer says "DSH is not logged in" while DSH is answering.** The bridge only looked at DSH's top-level settings for a model; it now also reads the web and desktop profiles and the DeepSeek key in DSH's `.env` (#2005).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.86`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 插件点一下就装好。** 在 DSH 插件页输包名 `bothouse-dsh`、安装、点启用，就完了。第一次启动时插件自动加成员：一个 DSH，外加这台电脑上找到的每个命令行工具一个（Claude Code、Codex、Gemini），名字跟软件走，头像用软件图标，DSH 设为主角色。接着它把后台服务、记忆服务和记忆 wiki 装好起好（本机已有 wiki 就复用，没有就新建），逐项自检，全过才在 #general 说「装好了」；没过就写清卡在哪、怎么修（比如某个命令行工具还没登录）。准备期间 #general 会显示进度，这时发的消息等成员上线后接着回。不 @ 任何人直接打字，由主角色接话。命令行工具没登录的成员显示「需登录」和登录方法，不再亮绿点。「添加成员」只问接哪个角色，名字、头像、人设收进「更多」。设置向导保存后的步骤列表折叠成一句，DSH 插件页里四个实验插件（语音输入、自定义插件索引、自动授权审查、Git 工作树）不再显示。不写版本号安装也能拿到最新版：插件会自己更新到 npm 上的最新版（#2005）。

## 缺陷修复

- **DSH 明明在回话，自检不再说「DSH 还没登录」。** 桥以前只看 DSH 顶层配置里有没有模型，现在也读网页版、桌面版配置和 DSH `.env` 里的 DeepSeek 密钥（#2005）。
