## Highlights

- **Any agent CLI can set bothouse up by itself.** README (English and Chinese) gives AI the three commands to run; AGENTS.md says not to clone the repo, to fall back to `nohup` when `daemon install` fails in a sandbox, and not to self-test with the bot's own token. `install.sh` falls back to `$HOME/.cache` when `mktemp` fails. In an isolated rerun, DSH went from start to a full Discord setup in about 3.5 minutes instead of about 10.5 (#1311, #1312). For DSH, `module add dsh` now works on a Mac that only has DSH Desktop (it borrows the desktop's bundled Node) and tells the agent setup is done, with no restart and no self-test (#1313, #1314).
- **Edit plugin configuration in the panel.** Third-party plugins without their own form get an inline YAML editor that saves or clears the override inside the DSH profile lock; comments and disabled state are kept, recognised secrets are never sent back to the browser, and the request body is capped at 1 MiB. DSH still needs a restart to pick the change up (#1329).
- **Replace a QQ moment in one action.** A new endpoint posts the new moment first and deletes the old one only after that succeeds. It is two ordered steps, not an atomic edit: if posting fails the old one stays untouched; if deleting fails it reports that two now exist (#1322). If the old moment has an image without a usable address, the replace is refused before any write (#1335).
- **`life_page` project option.** Point it at a file and its content goes in front of every turn (messages, cron, timers, relays) as the role's current state, capped at 2000 characters; a missing file is created from a short template. Off unless set (#1337).

## Fixes

- **Cron in quiet groups:** a failed scheduled task now DMs the owner instead of posting into a quiet group (#1319); the `⏰` progress and result lines of shell and check tasks stay in the log instead of the group (#1323). The unit test for normal groups now really uses a non-quiet group (#1331).
- **Workspaces:** queued handoffs no longer get stuck behind one handed off from inside a workspace; new handoffs drain the queue first (#1315). `ws-forward` wakes the workspace's own project instead of the caller's (#1321). On the pinned team card, a paused item is marked paused instead of "nobody reviewed", and an item with a named owner is no longer listed as unassigned (#1341).
- **Tool output on cards:** backends no longer cut tool output to 500/800 characters; the detailed card view keeps the full text while chat and forwards keep their limits (#1316).
- **DSH channels:** with no lead chosen, a one-member channel answers by default and a multi-member channel waits for a choice; the legacy `/collab` page loads older history on scroll and failed cards get a retry button again (#1332). Rename errors for channels and members are shown in Chinese when the UI is in Chinese (#1324).
- **Watchdog:** quota-exhausted results no longer reset the failure count, and an unexpected stream exit counts as a failure (#1333).
- **Plugins:** two writers taking over a stale profile lock at once can no longer remove each other's lock (#1325).
- **Wiki galaxy:** its entry moved from the sidebar into the panel overview (#1330); when DSH is stopped it no longer nests the panel inside itself (#1339).
- **Tests:** a flaky QQ quote test now waits for a non-empty capture (#1340).

## Improvements

- **Tray:** today's usage is shown in M, and each row opens the matching panel page (#1338).
- **Role cards:** the long "SERVER MEMBERS INTENT" warning became a small grey badge next to the platform, with the full text on hover (#1334, #1336).
- **Diagnostics:** DSH configure/open requests are logged with request IDs alongside the management server's connection and exit events, to trace Windows setup failures (#1320).
- **Docs:** v0.1.59 install size corrected to the measured 16 MB / 3 s (#1310).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.60`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **任何 AI 命令行都能自己把 bothouse 配起来。** README（中英）给 AI 写了三条命令；AGENTS.md 写明不用克隆仓库、沙箱里 `daemon install` 失败就退到 `nohup`、不要用 bot 自己的令牌自测。`install.sh` 在 `mktemp` 失败时退到 `$HOME/.cache`。隔离复测里，DSH 从开跑到配好 Discord 由约 10.5 分钟降到约 3.5 分钟（#1311、#1312）。DSH 路线：只装了 DSH 桌面版的 Mac 上 `module add dsh` 也能装（借桌面版自带的 Node），装完直接告诉 AI 已配好，不用重启、不用自测（#1313、#1314）。
- **在面板里改插件配置。** 没有自带表单的第三方插件，行内给一个 YAML 编辑框，在 DSH profile 锁里保存或清除覆盖；保留注释和停用状态，识别出的密钥不回传浏览器，请求体上限 1 MiB。改完仍要重启 DSH 才生效（#1329）。
- **QQ 说说一次换掉。** 新接口先发新的、发成功才删旧的。这是有序两步，不是原子修改：发失败旧的原样保留；删失败就如实报「现在有两条」（#1322）。旧说说里有没地址的图，写任何东西之前就拒绝（#1335）。
- **项目选项 `life_page`。** 指向一个文件，它的内容会作为角色的当前状态放在每一轮（消息、定时任务、计时器、转话）前面，上限 2000 字；文件不存在时用简短模板新建。不设就不生效（#1337）。

## 缺陷修复

- **静音群里的定时任务：** 失败提醒改私聊主人，不再发进静音群（#1319）；shell 和自检任务的 `⏰` 进度、结果行只写日志，不进群（#1323）。普通群的单测改成真的非静音群（#1331）。
- **工作区：** 排队的活不再被一件从工作区里交的活卡住，新交活前先清队列（#1315）。`ws-forward` 叫醒工作区自己的项目，不再错投给调用方（#1321）。置顶团队卡上暂停的条目标「暂停」，不再标「没人验收」；写了负责人的条目不再算「待安排」（#1341）。
- **卡片上的工具输出：** 各后端不再先把工具输出截到 500/800 字；卡片细节档留全文，聊天和转发照旧按上限截（#1316）。
- **DSH 频道：** 没选主角色时，单成员频道默认由它接话，多成员频道等明确选择；旧版 `/collab` 页向上滚动会加载更早的历史，失败卡重新有重试按钮（#1332）。中文界面下频道、成员改名失败的错误改说中文（#1324）。
- **看门：** 额度用完的结果不再把失败计数清零，事件流意外断开算一次失败（#1333）。
- **插件：** 两个写入方同时接管过期的 profile 锁时，不会再删掉对方的锁（#1325）。
- **Wiki 星图：** 入口从侧边栏移到面板概览里（#1330）；DSH 停着时不再把面板一层层套进自己（#1339）。
- **测试：** 一个时好时坏的 QQ 引用测试改成等抓到非空内容再判（#1340）。

## 改进

- **托盘：** 今日用量改用 M 显示，每一行点开对应的面板页（#1338）。
- **角色卡片：** 「SERVER MEMBERS INTENT」那段长提示改成平台名旁的灰色小标签，悬停看全文（#1334、#1336）。
- **诊断：** DSH 配置/打开请求带请求号记日志，和管理服务的连接、退出事件对得上，用来查 Windows 上的配置失败（#1320）。
- **文档：** v0.1.59 的安装体积改成实测的 16 MB / 3 秒（#1310）。
