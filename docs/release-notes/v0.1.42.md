## Highlights

- **Pinned task table you can read at a glance.** Each chat channel keeps one pinned table with three groups — 等你看 (waiting for you), 在做 (running), 搁置 (parked) — short task names, what each one is doing, and a link into the task's thread. It is edited in place whenever the task board changes, and kept (not deleted) when empty (#700).
- **Every task has its own thread.** The task thread shows the whole course of a task; the workspace progress card lives there, one card per task, following the card opened in the conversation (#696, #698, #701).
- **Handbacks in plain words.** A workspace handback posts four labelled parts — 【背景】【做了什么】【要你做的】【我加的】 — with a blank line between them and no details in the channel. A reply missing a part, or naming board/PR numbers, workspaces or branches, or holding a table, goes back to be rewritten (#690, #696, #699, #702).
- **Replies about running work reach its workspace.** Replying in a chat channel to a message about work still running in a workspace passes it straight to that workspace and interrupts its turn; the ask-only guard now stops only edits, never dispatching, forwarding, board, timers or sends (#690).

## Fixes

- **The gate judges busy interjections by intent** (unrelated / addition / waiting for a reply / stop) instead of a stop-word list, and aborts a turn that cannot take mid-turn input (#691).
- **An abort or redirect is answered first,** before whatever had queued behind the running turn, for both the gate service and the built-in busy rules (#692, #694).
- **DSH accepts mid-turn messages on a stock install:** `dsh/install.sh` applies the steer patch to dsh-acp (#692).

## Improvements

- **Team rules are sent once per context on every backend,** resent only after a compaction is detected; Grok/ACP uses the context size it reports (#693, #703).
- **One copy of the workspace exit rules** shared by the bridge and DSH (#689); test update (#695).

## 重点

- **置顶任务表一眼看清。** 每个聊天频道只留一张置顶表，分「等你看」「在做」「搁置」三组，每行写短名和正在干什么，点进去就是这件活的子话题。任务板一变就原地改，空了也保留（#700）。
- **每件活一个子话题。** 子话题里能看到这件活从头到尾的经过，工作区进度卡也放在这里，一件一张，跟着会话里开的那张卡走（#696、#698、#701）。
- **交回用人话。** 工作区交回在频道里贴四段：【背景】【做了什么】【要你做的】【我加的】，段间空一行，细节不进频道。缺段、写了任务板/PR 编号、工作区或分支名、或带表格的，打回重写（#690、#696、#699、#702）。
- **回复在跑的活，直接转给它的工作区。** 在聊天频道回复一条在跑的活的消息，会马上转给那个工作区并打断当前这轮；只问不做的守卫只拦自己改东西，不拦派活、转话、任务板、定时和发送（#690）。

## 修复

- **看门按意图判断插话**（无关 / 补充 / 等回复 / 叫停），不再靠叫停词；当前这轮接不了插话时直接打断（#691）。
- **叫停或改派先回答，** 不再排在当前这轮后面积压的消息之后；看门服务和内置规则都一样（#692、#694）。
- **DSH 默认安装也能接中途插话：** `dsh/install.sh` 给 dsh-acp 打上 steer 补丁（#692）。

## 改进

- **团队规矩每个上下文只发一次，** 所有后端都一样，检测到压缩后再发；Grok/ACP 按它报的上下文大小判断（#693、#703）。
- **工作区交回规矩桥和 DSH 共用一份**（#689）；测试更新（#695）。
