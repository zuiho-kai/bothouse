## Highlights

- **Channel settings in one place.** Change the channel name, dispatch mode and primary role from the settings dialog. The sidebar keeps the task board and member list, without duplicate settings controls (#456, thanks @HarunaRyo-051).
- **Rename a channel without losing its history.** Renaming keeps messages, members, bindings and routing, updates related DSH session titles, and survives a restart. Names accept 1–32 characters without whitespace; workspace names stay fixed (#456, thanks @HarunaRyo-051).

### Fixes

- **CLI paths containing spaces start correctly.** Existing executable paths are kept whole, including paths containing apostrophes. Quoted command paths and arguments are supported while ordinary command strings and array configuration keep working (#471, thanks @NethielChou).
- **A saved channel rename stays successful if a session title cannot refresh.** Failed title updates are logged separately, and the remaining sessions still get their updates. The settings dialog receives keyboard focus, keeps Tab navigation inside it, and returns focus to its opener when closed (#456, thanks @HarunaRyo-051).

### Improvements

- **A cleaner message composer.** The rounded composer grows with the message and groups attachments, mentions and the send button in its lower toolbar (#456, thanks @HarunaRyo-051).
- **Clearer AstrBot setup guidance.** The guide identifies the tested AstrBot version and explains where role display and privacy settings live, including which settings to disable in public channels (#433, thanks @NethielChou).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

### Thanks

- @HarunaRyo-051 for channel settings, persistent channel renaming and the refreshed composer (#456).
- @NethielChou for command paths containing spaces and clearer AstrBot configuration guidance (#471, #433).

## 重点

- **频道设置集中到一个面板。** 在设置弹窗里修改频道名、派活方式和主角色；侧栏保留任务板和成员名单，不再重复显示设置控件（#456，感谢 @HarunaRyo-051）。
- **频道改名保留聊天历史。** 改名保留消息、成员、绑定和路由，同步相关 DSH 会话标题，重启后仍保留。名称为 1–32 个字符，不能含空白；工作区名称由系统固定分配（#456，感谢 @HarunaRyo-051）。

### 缺陷修复

- **含空格的 CLI 路径可以正常启动。** 已存在的可执行文件路径会整体保留，路径里含单引号也能识别；支持带引号的命令路径和参数，普通命令字符串和数组配置保持兼容（#471，感谢 @NethielChou）。
- **会话标题刷新失败不再让已保存的频道改名报错。** 失败的标题更新单独记日志，其他会话继续更新。设置弹窗打开时获得键盘焦点，Tab 在弹窗内切换，关闭后焦点返回打开按钮（#456，感谢 @HarunaRyo-051）。

### 改进

- **消息输入区更整洁。** 圆角输入框随内容增高，附件、点名和发送按钮集中在下方工具栏（#456，感谢 @HarunaRyo-051）。
- **AstrBot 配置说明更明确。** 标注实测版本，写清角色显示与隐私设置所在的配置位置，并提醒公开频道应关闭哪些显示项（#433，感谢 @NethielChou）。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
- **校验：** `SHA256SUMS`

从 v0.1.6 起，点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。旧版更新程序若下载超时，请手动下载安装。

macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键 → 打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息 → 仍要运行」。
