## Highlights

- **Tests stay out of your chat.** Work titled as a test (「测试：」「验收探针：」「【自检】」「probe:」) still closes or waits as usual, but its report and question stay in the workspace and the log, and it does not show on your chat's task board (#620).
- **Self-checks are quiet when all is well.** Timer and cron jobs that self-check or look back post no start notice; a command check posts only when it fails, and an agent check stays silent when there is nothing you need to know. Jobs titled as a test post nothing (#620).
- **Test runs cannot reach live channels.** A run in a temporary home that still points at the live data folder, carries a live bot token, or carries the live channel settings stops before it does anything (#620).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **测试不再进你的聊天频道。** 标题标成测试的活（「测试：」「验收探针：」「【自检】」「probe:」）照常收尾或等答复，但交回和提问只留在工作区和日志里，也不出现在你频道的任务板上（#620）。
- **自检一切正常就不出声。** 自检、回看类的定时任务不再发开始提示；命令类的只在失败时才发，让助手做的检查没有你要知道的事就不回话。标题标成测试的定时任务什么都不发（#620）。
- **测试环境碰不到真频道。** 在临时目录里跑的测试，只要还指着线上数据目录、带着线上 bot 令牌或线上频道设置，开跑前就直接停下（#620）。
