## Highlights

- **Quota-out handover works with Claude's new wording.** Claude Code now says "You've hit your 5-hour limit"; every "hit your <window> limit" notice is recognised, so the bot cools down and hands its lead role and tasks to a free teammate. A quota-out turn is no longer forwarded from a workspace as a `[report]` (#592). A `/usage` probe that times out or exits early now logs its screen (#594).
- **One shared workspace pool.** A chat channel outside the pool's category (or in no category) no longer starts its own 「工作区1」: numbering, adoption and the pool listing follow the category that holds the workspaces, and a new workspace is created next to them (#597).
- **The reply footer shows quota by default.** Bots added by the setup wizard no longer turn off the 5-hour and weekly quota in the footer; the local work directory stays hidden (#595).

### Fixes

- **Background turns and session resets.** `session new --after-turn` inside a background-notification turn waits for that turn's reply and `[report]`, and stale queued resets are dropped instead of wiping the next task's session (#589, #600).
- **Forwarded notes land in the right section.** `ws-forward` and `board pause` add to the handoff's 「转交结果」 section, and the wake-up carries the original text (#587).
- **Task action prompts** put the action before its flags (#585).
- **Gate wiki suggestions** rank older lines lower, except settled decisions and user decisions (#588).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **额度用完自动交接认得 Claude 的新提示。** Claude Code 现在提示「You've hit your 5-hour limit」；所有「hit your … limit」这类提示都能认出，机器人进冷却，主角色和手上的活交给空着的队友。额度用完的那一轮不再被工作区当成 `[report]` 转出去（#592）。`/usage` 读额度超时或提前退出时会记下屏幕内容（#594）。
- **工作区只有一个共享池。** 不在工作区所在分类（或没有分类）的聊天频道不再另起一个「工作区1」：编号、认领和列表都按工作区所在的分类，新工作区建在它们旁边（#597）。
- **回复页脚默认显示额度。** 向导新加的机器人不再关掉页脚里的 5 小时和本周额度；本机工作目录仍默认不显示（#595）。

### 缺陷修复

- **后台轮次和清会话。** 后台通知那一轮里的 `session new --after-turn` 等这一轮的回复和 `[report]` 发出后才执行；过期的清会话请求直接丢掉，不再清掉下一件活的会话（#589、#600）。
- **转话写进对的位置。** `ws-forward` 和 `board pause` 写进交接的「转交结果」节，叫醒时带原文（#587）。
- **任务动作提示** 把动作写在参数前面（#585）。
- **gate 推荐 wiki 页** 按行日期降低旧内容的分数，定案和用户定的行不降（#588）。

### 安装

- **macOS（苹果芯片与 Intel 通用）：** `bothouse-mac.dmg`
- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
- **校验：** `SHA256SUMS`

从 v0.1.6 起，点左下角「更新到 vX」即可一键更新；v0.1.5 及更早的版本需要先手动下载安装这一版。旧版更新程序若下载超时，请手动下载安装。

macOS 将 **Bothouse.app** 拖入 Applications，**首次打开请「右键 → 打开」**；Windows 若弹出 SmartScreen 提示，点「更多信息 → 仍要运行」。
