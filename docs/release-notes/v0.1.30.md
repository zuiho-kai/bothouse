## Highlights

- **Delegated review now closes the original task.** When the primary sends a returned task to another member for review, the review assignment stays linked to the original. The assigned reviewer's 【验收】 (accept) or reasoned 【返工】 (rework) now finishes both records, so the original no longer sits at "pending review" forever. Verdict examples inside the dispatch message do not count as a verdict (#538).
- **Owners can accept or request rework from the task board.** The signed-in owner can close a returned task directly from the DSH task board (#538).

### Fixes

- **Workspace reports are not lost on reset.** If a workspace turn finishes or waits without sending its report, the bridge keeps the conversation and asks for the report before resetting context; the recovered report is forwarded to the parent channel, including on the self-hosted web channel (#536).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **派给别人的验收会关掉原任务。** 主角色把已交回的任务派给其他成员验收时，验收任务会挂在原任务下。被指定的验收人回【验收】或写明原因的【返工】后，两条记录一起收口，原任务不再一直停在「待验收」。派活消息里举例的验收写法不算结论（#538）。
- **任务主人可以在任务板上直接验收或返工。** 登录的任务主人可在 DSH 任务板上直接收口已交回的任务（#538）。

### 缺陷修复

- **工作区重置前不丢汇报。** 工作区一轮完成或进入等待却没发汇报时，桥会保留当前对话、先补要汇报再重置上下文；补回的汇报会转到上级频道，自建网页频道同样生效（#536）。

- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
