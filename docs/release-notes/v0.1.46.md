## Highlights

- **The DSH plugin works right after install.** The npm package `bothouse-dsh` 0.1.45 was missing five runtime files (such as `personas.json`), so DSH failed to load it; they are now shipped. On the first start of a plugin-only install, the channel gets one ready role that uses the model DSH already has configured and is set as the channel's primary role, so "hand this to a workspace" works without any setup. It runs once and leaves channels that already have members alone. The README lists three ways to install: ask DSH to install it, add it on the plugins page, or one command (#896, #897).
- **Team desk page.** `/collab/desk` draws the team as an office floor plan: seats, avatars, task cards and a live event feed, with beams for dispatch, hand-back and rejection, and a thin line when one role @-mentions another. It follows the task board live and can replay a time window at 1×/4×/16×; busy/idle comes from the bridge's team status file. Includes a bilingual guide, an end-to-end driver and a latency check (#877, #878, #880, #881, #884, #885, #886, #887, #879).
- **Wiki galaxy page.** `/collab/wiki-galaxy` draws the shared wiki as a rotating galaxy: one star per page, links as orbits, top-level folders as clusters. Read-only; the wiki folder is set by `wikiDir` / `CONEST_WIKI_DIR` (#895).
- **Memory push gets a profile, topic lessons and voting.** Pushed lines carry a short title and an entry id; `GATE_PROFILE` can push the user's profile once per session; lessons are pushed when they share words with the current message; roles can vote on memory entries and low scores sink (#867). Push de-duplication now lives in the push service per entry id and per session, so a new entry on an already-pushed page is no longer blocked (#872), and entries are pushed as whole lines, re-pushed after 20 turns (#875).
- **Mood diary as an easter egg.** New roles from the setup wizard keep a mood diary; an hourly "anything to say?" job is created but off by default (#868, #869).

## Fixes

- **QQ: a busy group is answered in one turn.** Messages that arrive while the agent is busy are folded into the next turn, overflow is carried instead of dropped, and bridge notices are quieter (#863).
- **Calling a teammate by name at the start of any line works,** not only the first line (#871). On Discord, a bot line that opens with a teammate's name is sent as a real mention, including messages with buttons (#873, #874).
- **`ws-up` reports are no longer blocked by the anti-spin guard** when they contain words like "status" (#894).

## Improvements

- **Channel page is responsive:** side panels become drawers on narrow screens, styles move to light/dark design tokens, messages are grouped by sender, and loading/empty/error states are shown (#888).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.46`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **DSH 插件装完就能用。** npm 上的 `bothouse-dsh` 0.1.45 漏打了五个运行时文件（如 `personas.json`），DSH 加载不起来；现在补齐了。纯插件安装第一次启动时，频道里自动有一个角色，用 DSH 已经配好的模型，并当频道主角色，「交给工作区」不用任何设置就能用。只跑一次，已有成员的频道不受影响。README 写了三种装法：对 DSH 说帮我装、在插件页添加、一条命令（#896、#897）。
- **团队工作台页。** `/collab/desk` 把团队画成办公室：工位、头像、任务卡、实况事件流，派活、交回、退回有光路，@ 有细线。实时跟任务板，也能按时间窗 1×/4×/16× 回放；忙闲读桥写的团队状态文件。附中英使用说明、端到端驱动和延迟量测（#877、#878、#880、#881、#884、#885、#886、#887、#879）。
- **Wiki 星河页。** `/collab/wiki-galaxy` 把共用 wiki 画成会转的星系：一页一颗星，链接是星轨，顶层目录是星团。只读；wiki 目录由 `wikiDir` / `CONEST_WIKI_DIR` 配置（#895）。
- **记忆推送加上画像、按话题推经验和投票。** 推送行只给短标题和条目编号；`GATE_PROFILE` 可每会话推一次用户画像；经验和本轮消息有共同词才推；角色可给记忆条目投票，低分沉底（#867）。推送去重改由推送服务按条目编号、按会话管，同页的新条目不再被挡（#872）；条目整行推送，推过的隔 20 轮再推（#875）。
- **心情日记彩蛋。** 向导新建的角色写心情日记；每小时「想不想说」定时会建好，但默认关（#868、#869）。

## 修复

- **QQ 群忙时合成一轮回。** agent 忙时到的群消息并进下一轮，超出上限的带到后面不丢，桥的提示更安静（#863）。
- **任意一行行首写队友名字都算叫她，** 不只第一行（#871）。Discord 上 bot 行首写队友名会发成真 @，带按钮的消息也一样（#873、#874）。
- **`ws-up` 的报告带「状态」这类词时不再被 anti-spin 拦下**（#894）。

## 改进

- **频道页响应式：** 窄屏两侧栏收成抽屉，样式收成亮暗两套设计令牌，消息按发言人分组，补加载、空、失败三态（#888）。
