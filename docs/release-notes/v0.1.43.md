## Highlights

- **A burst sent while the agent is busy runs as one turn.** Plain messages from the same person in the same chat that queued behind a running turn are folded together, oldest first with their send times, answered once, and the reply goes under the last one. Bot, scheduled and resumed messages still run on their own (#733).
- **Truncated handbacks keep the full text.** When a workspace report or delegation result over 2000 characters is cut for the wake prompt, the full text is saved first and the cut point says how long the original was and where to read it (#733).
- **QQ Bot group @ mentions,** within QQ API limits (#730, #732), and **QQ CQ-string attachments and quoted replies** are no longer dropped (#728, #729).
- **Images in the DSH client** can be shown, copied, downloaded and previewed (#697).

## Fixes

- **Tray reads management stats correctly** and marks unknown usage as unknown instead of zero (#715).
- **ws-forward refuses tasks already handed back** (#709); a forward that changes direction must use `--interrupt` (#719).
- **Task-thread progress card** lists recent steps in full (#714).
- **CI on develop back to green** (#707), and tests updated for queued-burst batching.

## Improvements

- **Windows desktop windows** for the bothouse web UI (#717).
- **Subagent delegation policy is off by default;** opt in with `inject_subagent_policy = true` (#718).
- **choice-ask-guard:** a choice question to the user must carry the agent's own answer (#721); decide-or-ask is judged by a small model with a product intent card (#725). (#722 was reverted in #724.)
- **The operator's live helper scripts ship with the package** (#727).

## 重点

- **你忙时连发的几条，合成一轮处理。** 同一个人在同一个聊天里、排在当前这轮后面的普通消息，按时间顺序合在一起，带上发送时间，只回一次，回复挂在最后一条下面。机器人、定时任务和续跑的消息照旧各自单独处理（#733）。
- **截断的交回能找到全文。** 工作区汇报或派工结果超过两千字被截断时，先把全文存下来，截断处写明原文多长、到哪里读全文（#733）。
- **QQ 机器人支持群里 @**（按 QQ 接口的限制，#730、#732）；**QQ CQ 文字串里的附件和引用回复**不再丢（#728、#729）。
- **DSH 客户端里的图片**可以显示、复制、下载和预览（#697）。

## 修复

- **托盘正确读取管理接口统计，**读不到的用量标明未知，不再显示为零（#715）。
- **ws-forward 不再转给已交回的活**（#709）；改方向的转话必须带 `--interrupt`（#719）。
- **任务子话题的进度卡**完整列出最近几步（#714）。
- **develop 上的检查恢复全绿**（#707），并按连发合批更新了测试。

## 改进

- **Windows 桌面窗口**打开 bothouse 网页界面（#717）。
- **子 agent 授权规矩默认关，**要用时设 `inject_subagent_policy = true`（#718）。
- **choice-ask-guard：**问用户做选择时必须带上自己的答案（#721）；该自己定还是问用户，由小模型结合产品意图卡判断（#725）。（#722 已在 #724 撤回。）
- **运营者在用的辅助脚本随包发布**（#727）。
