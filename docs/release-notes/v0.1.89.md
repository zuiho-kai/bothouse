## Fixes

- **Windows: the DSH plugin's first start no longer stops at "members not written to the background service: no output".** While checking which AI CLIs are installed, the setup step waited forever for an npm CLI whose `.cmd` wrapper had timed out, so it never answered and the plugin gave up after two minutes. The checks now stop for real, the message says whether it timed out or which exit code it had, and the log path keeps its backslashes in the chat (#2118).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.89`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 缺陷修复

- **Windows：DSH 插件第一次启用不再卡在「成员没写进后台：没有输出」。** 检查本机装了哪些 AI 命令行工具时，npm 装的工具外层 `.cmd` 超时后，后台还一直等里面的进程，始终不回话，插件两分钟后放弃。现在检查到时真的停下；报错写明是超时还是退出码；聊天里的日志路径不再丢反斜杠（#2118）。
