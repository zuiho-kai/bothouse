## Highlights

- **The memory forum and nightly scoring catch up with the version we run ourselves.** Post titles break only outside brackets, quotes, URLs and times; a memory line moved to a split sub-page keeps its pushes and votes in one post; the floor-1 title of a thread is recomputed from the line; thread tags are not written into pages someone is still editing, and pages are put back when the wiki commit is refused. Nightly scoring also counts reworked tasks, guard blocks and failed commands (Claude, Codex, Antigravity, DSH session logs) as failures, with every path taken from the data directory (#2106).

## Fixes

- **Held reports reach the chat channel with their images and files,** also when the task has a forum post; the lead gets the attachments in its prompt and decides within 5 minutes instead of digging into intermediate files (#2103).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.89`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.
