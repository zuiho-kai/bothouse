## DSH workspaces

- **Only [report] hands work back.** In a workspace, a DSH member's reply is a handback only when it has `[report]`. A reply with only the opening stance line, or an `[ask]` reply, does not end the task. If the first line has `#id`, only that task is handed back (#425).
- **No nudges while a question waits for you.** A DSH `[ask]` no longer pauses the task. While the owner has an unanswered `[ask]`, the 10-minute watch only waits: no nudge, no pause, and the workspace is not released. When your answer reaches the workspace, the watch starts again from that time (#425).
- **Rework keeps the context.** When a workspace hands back, its session is kept until a new task claims the workspace. Rework or resume on the same task goes on in the same session. If the session was taken by another claim, the wake-up message brings the original handoff text and an extract of the last [report] (#425).

## Handoff and task board

- **Handoff files go in the data directory.** `ws-handoff` and the playbook now say to write handoff files to `notes/<name>.md` in the role directory, not `/tmp`. Run `ws-handoff` with no arguments, or with a missing file, to see the usage (#426).
- **Task board cards show the workspace name.** After a workspace finishes and goes back to the pool, the card still shows its name, not an internal id like `room-2·` (#426).
- **The wake-up timer shows the task.** Its description is now "Workspace takes over: <task>", not the raw message text (#426).

## DSH 工作区

- **只有 [report] 才算交回。** 工作区里，DSH 成员的回复带 `[report]` 才算交回。只有开头表态那一行，或是 `[ask]` 回复，任务都继续。首行带 `#编号` 时只交回那一件（#425）。
- **等你答复期间不催。** DSH 的 `[ask]` 不再暂停任务。负责人有没答复的 `[ask]` 时，十分钟看门只顺延：不催、不暂停、不释放工作区。答复送回工作区后，从那时重挂看门（#425）。
- **返工带着上下文。** 工作区交回后，会话保留到下一件新活认领为止。同一任务返工、暂停后恢复，接着用原会话。若会话已被别的认领拿走，叫醒消息会带上原交接正文和上次 [report] 摘录（#425）。

## 交接和任务板

- **交接文件落数据目录。** `ws-handoff` 和工作手册写明交接文件放角色目录下的 `notes/<名>.md`，不再放 `/tmp`。`ws-handoff` 不带参数或文件不存在时，会打出用法（#426）。
- **看板卡显示工作区名。** 工作区做完放回池子后，卡片仍显示工作区名，不再露出 `room-2·` 这类内部编号（#426）。
- **定时器写明任务。** 叫醒定时器的说明改为「工作区接手：<任务>」，不再是消息原文（#426）。
