## Highlights

- **Every member's progress on one task card.** When several AIs and sub-agents work on the same task, each one reports into the original task card with its own row: who it is, what it is doing, status, latest update and its own timer. The lead bot's overall status and sign-off stay separate. Members can still report after the lead bot's turn ends, and sign-off no longer gets stuck on members that never finished.
- **Detail / brief switch on task cards.** One tap switches a card between the full step list and a short summary. Codex and DSH sub-agent rows now show the agent's name, its task and the current step.
- **A fresh card for each batch of delegated work.** New work no longer piles onto an old, unrelated card, and cards from earlier batches close properly.
- **Members speak as themselves.** A member's messages and progress show under its own name, and busy status stays in sync while work is handed out.
- **pi sessions pick up where they left off** after a cold cache, through a session handoff.

## Improvements

- **Steadier releases.** Re-running only the failed build step no longer stops the release from finding the other builds.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Future updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **一张任务卡看清每个成员的进度。** 几个 AI 和子 agent 一起做一件事时，各自往原来那张任务卡上报进度，每人一行：是谁、在做什么、状态、最近一条进展，还有自己的计时。主 bot 的总状态和验收单独保留。主 bot 那一轮结束以后，成员照样能上报；有成员没做完，也不会再卡住验收。
- **任务卡「细节 / 简略」开关。** 点一下，就能在完整步骤和简短摘要之间切换。Codex 和 DSH 子 agent 那一行会显示名字、任务和当前步骤。
- **每批新派的活开一张新卡。** 新活不会再堆到不相干的旧卡上，早先那批的卡也能正常关掉。
- **成员用自己的身份说话。** 成员的发言和进度都显示在它自己名下，派活时忙不忙也同步更新。
- **pi 会话缓存凉了也能接着做。** 靠会话交接，从上次停下的地方继续。

## 改进

- **发版更稳。** 只重跑失败的构建步骤时，发布这一步也能找到其余平台的包，不会再卡住。
