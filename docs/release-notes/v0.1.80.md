## Highlights

- **GitHub events, sorted.** A repository's native GitHub webhook can point at `<webhook path>/github`: the bridge verifies the signature, drops repeats, and sorts each event into immediate (an issue or pull request opens, a comment mentions the bot, CI fails on the default branch), batch (one hourly digest, merged early at 20 events) or ignore (stars, forks, the bot's own events). Immediate events for one issue or pull request inside 30 seconds are one wake, and a busy role gets it after its current turn (#1901).
- **External chat bots as stored channel members.** A bot from another client now has its own credential, can be rotated or removed, comes back after a restart, answers to `@name` or `@id`, and gets an offline notice when someone mentions it while it is disconnected. It is never a channel's default or primary role (#1905).
- **A first setup page that shows the missing CLI.** Setup lists each supported CLI (Claude Code, Codex, Gemini CLI, OpenCode, DSH) as ready, sign-in needed or missing with the command to run, and **Recheck CLIs** runs detection again without losing what was typed. On Windows the check also reads the saved user and machine PATH (#1903).
- **Member token ranking in the admin usage page.** Local members are ranked by tokens and cost, with daily, role and model details and a cost sort. Platform accounts stay separate, and automatic, historical or unrecorded work stays unassigned (#1908).

## Fixes

- **A handback lands on the task it names.** Exiting a workspace with an older draft no longer marks the newest task returned; only the task in the report headline changes state (#1876).
- **A failed step is marked where the answer is.** A failed tool call is failed on the card again, and the newest reply of that run says how many steps failed, which one, and the first line of its output; a click scrolls to the run strip (#1898).
- **A workspace that ends a turn without a handback is woken in 15 seconds**, whoever claimed the task, with a prompt to continue or hand back. A text-only turn no longer counts as progress, and the wake survives a restart (#1900).
- **Mid-turn mentions insert again on dsh-acp 0.2.2.** The steer patch reads the model route the way 0.2.2 exposes it, and an install already patched by an older bridge is rewritten on its next session (#1902).
- **The workspace chain holds together.** A question no longer closes the turn that asked it, a free workspace is offered to any channel, commands wait up to 30 seconds through a bridge restart instead of failing on the first refusal, and files passed to a handback are posted with it (#1907).
- **A resume handoff joins the task still in progress** instead of opening a second item and claiming a second workspace; the same file handed over twice joins the same way (#1914).
- **Housekeeping outside the team chain.** Fired timers expire after 7 days, `cron edit` is validated like a new job, an admin cron PATCH is all-or-nothing, update ordering understands builds made after a tag, Discord card files are swept after 7 days, over-limit and failed attachments are reported instead of dropped, Chinese text is cut by rune, state files are written atomically, and `__pycache__` no longer breaks the build (#1910).
- **Codex wiki turns continue through safe connection failures.** A 429 WebSocket failure is classified from the event, output and usage, and a correction pass keeps its budget instead of bypassing the retry loop (#1916).
- **An interrupted or stopped turn is not a task-post floor**, so a restart no longer fills a post with 「本轮中断」 lines (#1913).

## Improvements

- **The task post reads from the asker's side.** The asker's words come before the goal, a passed report shows its 做了什么 / 要你做的 on the first floor, the title, table row and report headline share one name that can hold 20 runes instead of 10, and a handoff wakes its workspace in 5 seconds instead of a minute (#1911).
- **A workspace question is stored once and shown whole.** The board row keeps only a title; the task post, pinned table, forum facts and the lead's wake all read the stored file. The question goes to the lead first and is tagged 等你拍板 only when the lead passes it on to the user (#1909).
- **Usage ranking date and layout.** A 30-day range highlights correctly across month boundaries, long member identifiers wrap inside their column, and the product notes describe the shipped attribution (#1912).

## 重点

- **GitHub 事件分档处理。** 仓库自带的 GitHub webhook 可以指到 `<webhook 路径>/github`：桥校验签名、丢掉重复投递，再把事件分成立即（issue 或 PR 新开、评论 @ 机器人、默认分支 CI 失败）、批量（每小时一份摘要，满 20 条提前合）和忽略（star、fork、机器人自己的事件）三档。同一 issue/PR 30 秒内的立即事件只叫醒一次，角色正忙就等这一轮结束再看（#1901）。
- **外部聊天机器人成为正式的频道成员。** 别的客户端上的机器人有自己的凭据，可轮换、可移除，重启后还在；被 `@名字` 或 `@id` 叫到会回答，没连上时有人叫它会收到离线提示。它永远不会成为频道的默认或主角色（#1905）。
- **第一次安装的页面会告诉你缺哪个 CLI。** 设置页列出每个支持的 CLI（Claude Code、Codex、Gemini CLI、OpenCode、DSH）是已就绪、需要登录还是没装，并给出要跑的命令；**重新检查** 不用重新填就能再检测一遍。Windows 上还会读保存的用户和系统 PATH（#1903）。
- **管理用量页多了成员 token 排名。** 本机成员按 token 和花销排名，能按天、角色和模型看明细，也能按花销排序。不同平台账号分开统计，自动任务、历史记录和没记到的用量单列为未归属（#1908）。

## 缺陷修复

- **交回落在草稿写的任务上。** 用旧草稿让工作区交回时，不再把最新的任务标成已交回，只有报告标题里的那个任务会改状态（#1876）。
- **失败的步骤标在回答旁边。** 失败的工具调用在卡片上重新标成失败；这一轮最新一条回复下面会写清几步出错、是哪一步和输出的第一行，点一下滚到那一条并高亮（#1898）。
- **一轮结束没交回，15 秒后叫醒工作区**，不管这件活是谁认领的；叫醒时会说继续做或交回。只写了文字、没跑工具的轮不再算进展，桥重启后叫醒也还在（#1900）。
- **dsh-acp 0.2.2 上忙时消息又能插进来。** steer 补丁按 0.2.2 的方式读模型路由；已经被旧桥打过补丁的安装，下次会话启动时自动改写（#1902）。
- **工作区这条链不再断。** 提问不再关掉正在问问题的那一轮；空着的工作区任何频道都能用；命令碰上桥重启会等最多 30 秒，不再第一次连不上就失败；交回时带的文件会跟交回一起发出去（#1907）。
- **续做交接并进正在做的那件活**，不再另开一件、另占一个工作区；同一个交接文件再交一次也走同一条路（#1914）。
- **团队链之外的清理。** 已触发的定时任务 7 天后过期；`cron edit` 和新任务一样做校验；管理页一次改多个字段时要么全成要么全不改；更新判断认得 tag 之后的构建；Discord 卡文件 7 天后清掉；超限和下载失败的附件会被说明而不是丢掉；中文按字截断；状态文件原子写入；`__pycache__` 不再让构建失败（#1910）。
- **Codex 跑 wiki 时遇到可续的连接失败会接着跑。** 429 断连时按事件、输出和用量判断能不能继续，修正轮不再绕过续跑、照常用自己的预算（#1916）。
- **被重启或手动停掉的一轮不再当成任务帖的一层楼**，重启不会把帖子刷满「本轮中断」（#1913）。

## 改进

- **任务帖从提问的人那边写起。** 提问原话排在目标前面；交回过的报告把做了什么、要你做的放在第一层；帖子标题、表格行和报告标题共用一个能放 20 个字的名字（原来 10 个字）；派活后 5 秒叫醒工作区（原来 1 分钟）（#1911）。
- **工作区的提问只存一份、整份显示。** 任务板行只留标题；任务帖、钉住的表格、论坛事实和主角色叫醒都读存下来的那一份。提问先到主角色，主角色转给用户时才标「等你拍板」并 @ 人（#1909）。
- **用量排名的日期和排版。** 30 天范围跨月也能正确高亮，长的成员标识在列内换行，产品说明写清现在这套归属方式（#1912）。
