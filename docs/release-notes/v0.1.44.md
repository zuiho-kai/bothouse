## Highlights

- **Platforms are modules you choose at setup.** One install still ships everything; the wizard now asks where you want to use bothouse first, QQ is a first-class choice with its own page, and the sidebar can add a platform to an existing setup and marks what is already configured (#813, #814, #815, #817). `bothouse module list | add | disable <platform>` does the same from the command line, backing up the config first and preserving unknown keys. A platform marked `disabled = true` is not created, not connected and not probed, and a role whose platforms are all disabled does not start.
- **QQ buttons can be limited to your own number.** The new `command_allow_from` option decides who may send `/`-commands: everyone else in the group still chats normally, and unknown commands are dropped before they reach the engine. It judges by QQ number, not nickname, and leaving it unset keeps the previous behaviour (#827).
- **A workspace task stuck on a request that never returns is rescued once.** The ten-minute watch stops the hung turns, posts a notice in the chat the task came from, and wakes the role to continue in the same session; only the next no-progress check parks it, and parking is announced too (#825). The hourly task-board stale check no longer pauses a workspace that is actually working: it reads the bridge's event stream first and renews the entry when the bound session moved in the last hour (#826).
- **Handbacks wait for acceptance.** A final workspace report now keeps its task open as "waiting for acceptance" and pings whoever dispatched it; only acceptance closes it, and after an hour the board says "nobody accepted · waiting for the dispatcher" and falls back to the lead if that person is away (#800).
- **Cooldowns are scoped to the account, not the role.** A model that ran out no longer blocks a role after it switches to an independent account or quota pool, changing the model releases the full-load cooldown immediately, and one notice is posted per channel instead of one per dropped message (#824, #821). An expired cooldown is re-probed silently in the background, with exponential backoff and no spin polling, without waking the model or spending tokens (#759).
- **Cost numbers come back.** The usage page showed `—` with an un-priced marker for roles whose model was logged with a provider prefix or a variant suffix; pricing is now matched for those names too (#754).
- **New on the web pages:** the roles page tells busy, idle, paused and offline apart with distinct colours (#765); the usage page has a Raw / M / B unit switch and a custom date range (#758); and a project with no usable providers now says why instead of contradicting the "all global providers already linked" message (#799).

## Fixes

- **QQ:** sender names and bot identity survive group messages (#734); oversized attachments are rejected instead of truncated (#736); failed HTTP media downloads and failed file uploads report the real status instead of success (#742, #744); received voice is decoded through `get_record` and replies can be sent as voice (#647).
- **Relay:** a relay that dies after its turn ended wakes the lead (#745); dispatch is refused when a prepaid relay cannot pay one turn and warns on low balance (#746); a task can be dispatched from a chat channel into its own workspace, and the running process knows which workspace it is in (#485); main's dispatch protections are synced into develop (#761); the v0.1.43 release is merged back into develop with the queue-batching test updates (#741).
- **Usage:** cost is priced when the logged model name carries a provider prefix or variant suffix (#754), and Codex usage is imported from every role's `codex_home` instead of only the default one (#796).
- **Gate:** `sync_gate.sh` now ships every local module `gate.py` imports, so a freshly synced remote gate starts instead of silently falling back to local rules, and the switcher answers `/context` locally from the wiki (#16, #591). Wiki pages with a UTF-8 BOM keep their description in search results (#794, thanks @ChillAndHumble for the original fix in #223). The Claude Code trust dialog is answered even when its rendering carries stray characters, so a probe timeout no longer extends a cooldown indefinitely (#810).
- **Hooks:** a hook that exits early reports its exit status instead of a stdin pipe error (#798); `doc-ok` accepts Codex session IDs (#508); local hook hotfixes that only lived on one install are ported into the product (#782); the restart-ok opt-out is dropped from the bridge-kill rule (#783).
- **Windows desktop helper:** the generated icon is true colour with the "b" inside its frame again (#793), on top of the icon and shortcut-location options (#720).
- **Restart:** `safe-restart` refuses to restart when the signed `.app` fails its bundle-seal verification, which used to silently drop the macOS permissions the app was granted (#772).
- **Team:** a delivered handback is not lost if the chat never shows it, and a posted ask wakes the lead even when the timer write failed first (#625); a question the user already answered is not asked again (#773); a reused workspace no longer applies the previous task's paused or closed state to a new task (#818, #823); product names and links are allowed in handoff summaries (#775).
- **Workspaces:** stopped assignments stay stopped across a restart resume (#790); a watch whose title was cut with an ellipsis is matched again (#791); idle-watch resumes stop after two consecutive agent errors (#787); accepts that are still waiting for an answer and handoffs that were not accepted are kept on the board (#763); a stuck workspace handoff is reconciled on startup and a task that stalls after making progress is detected (#768); the ten-minute watch renews while the workspace is still active, resolves the owner correctly, and warns once before pausing (#519); tests no longer write into the live data directory (#792).
- **Other:** a project can turn team-rules injection off with `inject_team_rules = false` (#627); the no-model setup can answer only when named, without the lead butting into other people's conversations (#474); ACP voice sessions stay resident and report segment timings (#607).

## Improvements

- **Lead handoffs carry more context and check more:** prior user decisions ride along and direction is checked on every watch window (#771); a handoff that names a reference must map the copy against it (#769); image handoffs require reference images and their reports a side-by-side image (#770); channel feedback is attributed in the recall (#780); Claude-Code-only scope is rejected (#784). A `[report]` that skips an item in the handoff scope is bounced (#777).
- **Workspace wake-ups get recall context and a code map** (#789), and the same workflow guards and code maps install across every supported CLI (#785, #779), including a long-task subagent type and a 290-second subagent wait cap (#779).
- **Hooks:** the fix-claim guard blocks denying an own feature without looking it up (#776); a time estimate or a timer over fifteen minutes needs a measured basis (#786); delayed prompts re-read what the user changed since scheduling (#778).
- **Task board rows are easier to scan:** pinned rows show name, workspace and age (#766); `bothouse report file-frequency` ranks the most-read files and suggests which belong in `STANDING.md` and which should be split (#584).
- **External task events:** a repeated report of the same change is folded into the existing task, with a durable cursor and a consumption receipt, instead of spawning a new session (#809); task text delivery and uncertain receipts are persisted (#807).
- **Authorization:** optional, default-off proactive policies record decisions and enforce durable source, identity and scope boundaries across admission, queueing, recovery, permissions and output (#808).
- **Collab:** each chat channel can set its own relay cap from 6 to 20 in channel settings, stored per channel and applied immediately (#801).
- **Tools:** optional watchvid site adapters and a configurable news digest, both off by default (#806).
- **Docs:** the README is rebuilt in Chinese and English with an architecture diagram (#764, #767), and Codex bot/desktop session isolation is documented (#279).
- **CI and build:** `bothouse-dsh` is published to npm through trusted publishing (OIDC), the dsh-plugin branch still updates when the npm step fails, and the publish log is verbose enough to show the token exchange (#748, #755, #756). A committed `web/dist/.keep` lets a fresh worktree build without the `no_web` tag (#788). Main is merged back into develop with the drift check and README work (#781).

## 重点

- **平台变成按需选的模块。** 还是一个安装包，向导第一页改成先问「你想在哪儿用」，QQ 排第一并有了自己的页面；侧栏可以给已有配置追加平台，已配好的会标出来（#813、#814、#815、#817）。命令行也能管：`bothouse module list | add | disable <平台>`，改配置前先备份、未知键都留着。标了 `disabled = true` 的平台不创建、不连接、不探活；一个角色的平台全停用它就不启动。
- **QQ 的命令可以只让自己发。** 新增 `command_allow_from`：设了之后，只有名单里的 QQ 号能发 `/` 开头的命令，群里其他人照常聊天，未知命令在进引擎前就被丢掉。判定按 QQ 号，不看昵称；不设就还是老行为（#827）。
- **卡在收不回的请求上的工作区，先救一次。** 十分钟看门发现没进展时，先停掉那个工作区里挂着的这轮、在活所在的聊天频道贴一条提示、把角色叫回同一个会话接着做；下一次检查还没进展才停放，停放也会在频道里说一声（#825）。每小时的任务板停滞检查不再冤枉正在干活的工作区：先读桥的事件流，绑定的会话最近一小时有动作就续期（#826）。
- **交回要等验收。** 工作区的最终报告送达后，任务保留成「等验收」并马上提醒派活人；只有验收才收口。超过一小时没人验收，板上写「没人验收 · 等派活人」，派活人不在线时由主角色接手（#800）。
- **冷却跟着账号走，不再绑在整个角色上。** 某个模型耗尽后换个独立账号或额度池不再被拦住；换模型、恢复后满载冷却立刻解除；「冷却中」每个频道只发一条，不再每扣一条消息刷一遍（#824、#821）。冷却到期由后台静默探活，指数退避、防空转，不唤醒模型也不花 token（#759）。
- **网页上的新东西：** 角色页把「在忙 / 空闲 / 已暂停 / 不在线」用颜色和动效分开（#765）；用量页多了 Raw / M / B 单位和自定义日期范围（#758）；项目没有可用服务商时会说清原因，不再和「所有全局服务商已关联」自相矛盾（#799）。
- **用量页的费用数字回来了。** 模型名带供应商前缀或变体后缀时，用量页一直显示 `—` 和未定价标记；现在这些名字也能正确计价（#754）。

## 缺陷修复

- **QQ：** 群消息里的发送者昵称和机器人身份不再丢（#734）；过大的附件直接拒绝，不再截断（#736）；媒体下载和文件上传失败会报真实状态，不再当成功（#742、#744）；收到的语音走 `get_record` 解码，回复也能发语音（#647）。
- **中转（relay）：** 一轮结束后才死掉的 relay 会唤醒主角色（#745）；预付费中转付不起一轮时拒绝派活并提示余额偏低（#746）；活可以从聊天频道直接派进它自己的工作区，干活的进程知道自己在哪个工作区（#485）；main 上的派活保护同步进 develop（#761）；v0.1.43 的发版分支连同连发合批的测试更新合回 develop（#741）。
- **用量：** 模型名带供应商前缀或变体后缀也能正确计价（#754）；Codex 用量从每个角色的 `codex_home` 导入，不再只算默认那份（#796）。
- **闸门：** `sync_gate.sh` 现在把 `gate.py` 依赖的同目录模块一起打包，新同步的远端闸门不会因导入失败起不来、又悄悄退回本地规则；切换器在本机回答 `/context`（#16、#591）。wiki 页开头带 UTF-8 BOM 时，检索结果不再丢描述（#794，原始修复 #223 感谢 @ChillAndHumble）。Claude Code 的信任对话框渲染带杂字时也能应答，探针超时不再把冷却无限顺延（#810）。
- **钩子：** 钩子提前退出时报它自己的退出码，不再报 stdin 管道错误（#798）；`doc-ok` 认 Codex 会话标识（#508）；只打过一台机器的本地钩子热修搬进产品（#782）；桥杀进程那条规则去掉 restart-ok 例外（#783）。
- **Windows 桌面小工具：** 生成的图标是真彩色，「b」字回到框里（#793），在图标和快捷方式位置选项（#720）之上。
- **重启：** 签名的 `.app` 整包校验不过时，`safe-restart` 直接拒绝重启，不再悄悄丢掉系统给过的授权（#772）。
- **团队：** 交回已发出但频道没显示也不会丢，抬头成功但定时写盘失败时仍会唤醒主角色（#625）；用户已答过的问题不再重复问（#773）；复用工作区时不再把上一个任务的暂停/结束状态套到新任务上（#818、#823）；交回摘要里可以写产品名和链接（#775）。
- **工作区：** 停掉的活重启后不会自己恢复（#790）；标题被省略号截断的看门记录也能对上（#791）；空闲看门连错两次就停（#787）；还在等答复的问题和没验收的交接留在板上（#763）；启动时会对账没结束的工作区交接，也能认出有进展后又卡住的活（#768）；十分钟看门在有动静时会续期、负责人解析正确、暂停前先提醒一次（#519）；测试不再往线上数据目录写（#792）。
- **其他：** 项目可以用 `inject_team_rules = false` 关掉团队规矩注入（#627）；不装模型的点名回复模式补齐，主角色不再因为消息攒多了就插话（#474）；ACP 语音会话常驻并报分段耗时（#607）。

## 改进

- **交接带的上下文更多、检查更全：** 用户以前定过的方向随交接带给下一个人，每个看门窗口都检查一次方向（#771）；用户原话点名了参照物时，交接必须写对照映射表（#769）；图片类交接必须有参考图，汇报要有并排图（#770）；交接召回里标明频道反馈是谁说的（#780）；只适用于 Claude Code 的范围会被打回（#784）。`[report]` 漏掉交接范围里任一项会被退回（#777）。
- **工作区唤醒时带上召回上下文和代码地图**（#789），同一套工作流守卫和代码地图在各 CLI 上都能装（#785、#779），含 long-task 子 agent 类型和 290 秒子 agent 等待上限（#779）。
- **钩子：** 否认自己做过某个功能却不先查，会被 fix-claim-guard 拦住（#776）；说时间估计或挂超过十五分钟的定时要有实测依据（#786）；延迟提示执行前会再看一眼用户这期间改了什么（#778）。
- **任务板更好扫：** 置顶行显示短名、工作区和时长（#766）；`bothouse report file-frequency` 统计最常读的文件，建议哪几个进 `STANDING.md`、哪几个该拆（#584）。
- **外部任务事件：** 同一变化被重复上报时并进已有任务，保留游标和消费回执，不再另起会话（#809）；任务文本投递和不确定回执会持久化（#807）。
- **授权：** 可选、默认关的主动策略会记录判断，并在准入、排队、恢复、权限和输出各环节落实来源/身份/范围边界（#808）。
- **协作：** 每个聊天频道可以在频道设置里单独设 6–20 的接力上限，存进库、即时生效、重启保留（#801）。
- **工具：** 可选的 watchvid 站点适配器和可配置的新闻摘要，默认都关（#806）。
- **文档：** README 中英文重做并加架构图（#764、#767）；补上 Codex 机器人与桌面会话隔离指南（#279）。
- **CI 与构建：** `bothouse-dsh` 改用 npm 受信任发布（OIDC）；npm 那步失败不再挡住 dsh-plugin 分支更新；发布日志详尽到能看见换令牌那一步（#748、#755、#756）。提交了 `web/dist/.keep` 占位，新 worktree 不带 `no_web` 标签也能编译（#788）。
