## Highlights

- **Workspace results come back through the chat lead, with the task behind them.** A workspace `[report]` or `[ask]` now wakes the chat channel's lead instead of being pasted verbatim; the lead gets the task board item and the requester's original request from the handoff, and replies with a short summary of which task, how far it got and what you need to do. The verbatim copy is kept only as a fallback when no lead can take it (#577).
- **Task progress is kept on every platform, and tasks link their artifacts.** Platforms without progress cards now record accepted progress in the task journal, so it survives a restart (#560, thanks @Zssan12). Tasks can link the artifacts they produced (branches, commits, PRs, files) and record a specified rework request against them (#563, thanks @Zssan12).
- **Settled decisions come back at the start of work.** When a handoff, a dispatch or a "start work" message arrives, the gate adds the settled decisions and pitfalls from the related wiki pages, so earlier choices are reused instead of rediscovered. A short standing-practices block (`STANDING.md` in the wiki) travels with every session; the agent maintains it and is asked to fix it if it breaks. The decisions block is capped per message and per session so long chats do not grow (#574, #575).
- **One event stream and change-only pollers.** Engine messages, tool calls and replies go to `events.jsonl`, with a socket route to append and read events. `bothouse cron add --poll --exec <check>` runs a check on schedule without waking the agent and only starts a turn when the check prints something (#581).

### Fixes

- **A paused task really stops.** Pausing a handed-off task now stops the turn still running in its workspace, and a late `[ask]`/`[report]` from a paused task is no longer forwarded (#571).
- **DSH roles set up by the wizard can answer.** The wizard asks a DSH role for its model route (official DeepSeek or a custom relay) and key, writes them into the role's patch, and refuses a keyless setup instead of producing a role that fails every turn (#567). Every wizard DSH model now declares image input, so pictures reach the model instead of a file path (#572, #576).
- **The team status bar keeps its task-card index.** The links to tasks in work and tasks waiting on you are back on the quieter board (#570, thanks @Zssan12).
- **`safe-restart` works on a bothouse install, and closing a board item ends it.** Without a custom launchd label it restarts through `bothouse daemon restart` and reads the bridge's own log; a board update that starts with a closing word ends the item (#573).

### Improvements

- **Multi-device setup guide.** How to join one channel from several machines (hub on one device, members on others), with the member config, a same-machine simulation and troubleshooting (#561, thanks @NethielChou).
- **AstrBot member identity notes.** Verified L2 member behavior, configuration points, and deduplication and replay protection learned on real devices (#525, thanks @NethielChou).

### Install

- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **工作区的结果由聊天频道的主角色带着任务背景转述。** 工作区的 `[report]`、`[ask]` 不再原文贴进聊天频道，而是叫醒聊天频道的主角色；主角色拿到任务板条目和交接里提需求的人的原话，用几句话说清是哪件活、做到哪、要你做什么。没有主角色能接时才退回原文转贴（#577）。
- **每个平台都留得住任务进度，任务能挂上产物。** 没有进度卡的平台也把进度写进任务日志，重启后还在（#560，感谢 @Zssan12）。任务可以挂上自己产出的分支、提交、PR、文件，并针对它们记下指定的返工要求（#563，感谢 @Zssan12）。
- **开工时自动带上以前定好的方向和做法。** 交活、派活或开工的那一轮，gate 会从相关 wiki 页附上已定的方向、流程和踩过的坑，直接照着做，不用重新探索。wiki 里的 `STANDING.md` 作为常驻短块跟着每个会话，由 agent 自己维护，写坏了会提示当场修。定案块每次和每个会话都有字数上限，长聊不会越聊越胖（#574、#575）。
- **统一事件流和「有变化才叫醒」的轮询。** 引擎的消息、工具调用和回复写进 `events.jsonl`，也能通过 socket 追加和读取事件。`bothouse cron add --poll --exec <检查命令>` 按时跑检查但不叫醒 agent，检查有输出时才开一轮（#581）。

### 缺陷修复

- **暂停的活真的停下来。** 暂停一件交出去的活时，会停掉它所在工作区里还在跑的那一轮；已暂停的活晚到的 `[ask]`/`[report]` 不再转出去（#571）。
- **向导配的 DSH 角色能正常回话。** 向导会问 DSH 角色走官方 DeepSeek 还是自建中转、填哪个 key，并写进角色配置；没填 key 直接拒绝，不再生成一个每轮都报错的角色（#567）。向导写的每个 DSH 模型都声明支持图片，图片能直接给到模型，不再只是一个文件路径（#572、#576）。
- **团队状态栏的任务卡索引回来了。** 安静版任务板上重新有「进行中」「等你拍板」的任务链接（#570，感谢 @Zssan12）。
- **`safe-restart` 在 bothouse 安装上可用，收尾词能直接结束任务板条目。** 没设自定义 launchd 服务名时走 `bothouse daemon restart`，读桥自己的日志；任务板更新以收尾词开头就直接结束这一条（#573）。

### 改进
