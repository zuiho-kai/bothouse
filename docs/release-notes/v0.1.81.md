## Highlights

- **Add a JiuwenSwarm / ACP teammate from the web panel.** The setup page and the panel's **Add role / model** entry have a new **JiuwenSwarm / ACP** card: pick it, paste the launch script path (for JiuwenSwarm, `scripts/run_gateway_acp.sh` in its repository), and the role joins the team like any other, with no config file to edit. The **New project** dialog asks for the launch command when ACP is chosen (#1924, #1925).

## Fixes

- **An ACP role with no launch command is refused.** A new ACP role or project whose command is empty, missing or not executable is refused before anything is written, with a message that says what to fill in. Before, it was saved without a command and the bridge failed to start on its next restart (#1924).
- **Claude Fable 5.2 turns count toward the spend cap.** The built-in price table had no row for `claude-fable-5-2`, so scheduled and workspace turns on it were never warned or stopped by the cap (#1922).

## Improvements

- **A turn is told to hand in before it is stopped.** A cron, timer or workspace turn gets one message at 80% of its per-turn spend cap, and a scheduled turn at 80% of its time limit, asking it to write out what it has and what is left undone. The stop itself is unchanged; an agent that takes no mid-turn input is stopped as before (#1921).

### Install

- **macOS 13 or later (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`
- **DSH plugin:** `npm i bothouse-dsh@0.1.81`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **在网页上点几下就能加 JiuwenSwarm / ACP 队员。** 设置页和面板里的 **添加角色 / 模型** 多了一张 **JiuwenSwarm / ACP** 卡片：选它，填启动脚本路径（JiuwenSwarm 是它仓库里的 `scripts/run_gateway_acp.sh`），这个角色就和别的队员一样进队，不用改配置文件。**新建项目** 对话框选 ACP 时也会让你填启动命令（#1924、#1925）。

## 缺陷修复

- **没填启动命令的 ACP 角色会被拦下。** 新建 ACP 角色或项目时，启动命令没填、找不到或不能执行，会在写入之前被拒绝，并说明该填什么。以前会照样存下来，桥下次重启就起不来（#1924）。
- **Claude Fable 5.2 的轮计入花费上限。** 内置价格表缺 `claude-fable-5-2` 这一行，用它跑的定时和工作区轮一直不会被上限提醒或停掉（#1922）。

## 改进

- **被停之前先提醒交结果。** cron、定时和工作区的轮花到每轮上限的 80% 时会收到一条消息，定时类的轮在时限用到 80% 时也会收到，让它把已有的结果和没做完的部分写出来。停的规则不变；不能中途收消息的 agent 照旧直接停（#1921）。
