## Highlights

- **The panel works on a DSH-only install.** Overview, Roles and Sessions show DSH members, channels and recent messages even with no bridged project; member `model` fields in object, string or null form are all read; a read failure shows as an error instead of "not running", and the panel no longer drops into the first-run wizard just because there are zero bridged projects. Thanks @sgepk203619-a11y (#1132).
- **Add, edit and remove DSH members straight from the Roles page.** Adding a role on an installed DSH opens a member form instead of re-running install/import, and lets you pick DSH's own providers and models. Config-file and external members are read-only; busy members cannot be deleted or switch type. Thanks @sgepk203619-a11y (#1132).
- **Codex members get their own model and reasoning effort.** The choices come from what Codex actually reports, and are applied after a session is created or resumed, before the next prompt. Thanks @sgepk203619-a11y (#1132).
- **Overview and Roles refresh by themselves.** They refresh on focus and every 30 s while visible, and an older response no longer overwrites a newer one. Trusted embedded pages no longer hit a proxy 403. Thanks @sgepk203619-a11y (#1132).
- **New panel pages:** an Image page with an image-generation API (writes a local file, never posts anywhere by itself) (#1032); a Plugins page to install and enable/disable plugins in DSH's web profile, with a source/publisher confirmation before install (#1027); QQ posts and avatar changes from the panel, off by default (#1033). Thanks @Zssan12.
- **The DSH chat page got 12 interaction fixes:** a permanent Direct messages section, unread counts, channel progress moved out of the message area (and collapsible per channel), clearer DM input and commands, and more (#1114, #1102 thanks @Zssan12).

## Fixes

- **DSH install and launch:** on a Mac with only the desktop app, the `dsh` CLI inside the app bundle is found (#1125), and that fallback stays macOS-only (#1133); on Windows with only the desktop app, `module add dsh` no longer reports "not installed" after a successful install (#1131), and a profile that lists a missing bundle is repaired instead of reported as installed (#1138); after an upgrade, `module add dsh` refreshes `~/.bothouse/dsh` before running `install.sh` (#1106); the desktop window also gets the channel plugins (#1088); restarting dsh web writes `dsh-web.json` back, so "Open DSH" no longer returns 503 (#1020); only one DSH starts the channel plugin on the same channel data (#1031). Thanks @Zssan12.
- **Channels:** channel names must be unique and cannot take a workspace name (#1117), and a `#` prefix no longer bypasses that check on rename (#1130); removing a member clears it as a channel's lead (#1137); DMs can be closed and DMs with removed members disappear (#1103); a CLI member's session key is per room, so memory votes land in the right room (#1091); narrow-screen dialogs no longer overflow by 4 px (#1122); the empty lead option in English reads "Not selected (use the default)" (#1135). Thanks @Zssan12.
- **Panel:** Overview and Roles count DSH `bot` members (#1095), and the tray's role line no longer lists them (#1108); the Cron page can actually create jobs — session key can be typed and errors stay in the dialog (#1041). Thanks @Zssan12.
- **QQ:** file messages download over WS when `http_url` is not set (#1113); "↪ inserted" receipts and job start notices stay out of QQ groups (#1098) and private chats (#1107); after a script already sent a message, the final reply is not repeated and self-notes are not sent (#1120). Thanks @Zssan12.
- **Quota:** a probe that cannot read usage is no longer treated as exhausted and no longer extends the provider cooldown (#1099). Thanks @Zssan12.
- **Task board:** changing an item's owner keeps its workspace binding and the hourly wrap-up no longer kills a running session (#1112); a failed workspace lookup keeps the binding and reports the error (#1119); writing forward results into a handoff file is atomic (#1034). Thanks @Zssan12.
- **macOS package and updates:** the whole `.app` is signed, not only the inner binary, so a browser download is no longer "damaged" (#1118); in-app update replaces the whole `.app` instead of only the binary, so one update no longer breaks the signature and blocks later updates (#1126). Thanks @Zssan12.
- `bothouse send --dm` is no longer silently dropped after a muted cron turn (#1115).
- Stop words cancel a busy bot's turn even when the gate has no model; idle watch stops after two can't-do replies (#1139).
- Sessions near the CLI's own compaction point start fresh with a handoff instead of being compacted in place (#1142).
- The footer's ctx% uses the last call's prompt size, not the whole turn's sum; a silent turn's progress card no longer promises a next message (#1147).
- Roles can no longer read other roles' private chats through `sessions`, chanlog (#1093) or `/channel/history` (#1101).

## 重点

- **只装 DSH 时面板也能用。** 没有桥接项目时，概览、角色、会话页也显示 DSH 成员、频道和最近消息；成员 `model` 字段是对象、字符串或空都能读；读取失败显示为出错，不再误报「未运行」；桥接项目为零时不再误进首次部署向导。感谢 @sgepk203619-a11y（#1132）。

- **面板新页面：** 生图页和生图 API（写成本机文件，不会自己发到任何频道）（#1032）；插件页，装、启停 DSH web profile 里的插件，装之前先确认来源和发布者（#1027）；QQ 说说与换头像，默认关闭（#1033）。感谢 @Zssan12。
