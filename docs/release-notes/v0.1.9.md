## Highlights

- **Workspace questions and reports go back to the right chat.** When several chat channels share one workspace, each handoff now gets its own task id, and the workspace is told that id when it takes the task. A role's `[ask]` or `[report]` is routed to the chat that handed off that task — by the id quoted in the reply, or to the only chat with an open task. Tasks that are finished stop counting, so an old handoff never steals a new report.
- **Install the DSH plugin straight from GitHub.** Every release now publishes the DSH plugin to a `dsh-plugin` branch, so one command installs it: `dsh plugin --profile web add 'github:zuiho-kai/bothouse#dsh-plugin&path:dsh/plugin-pkg'`.
- **Voice desk.** In a voice turn the lead can hear everyone's progress, and after you confirm, pass a message on to the right teammate in the right channel. Turn it on with `voice_desk` in the config; it is off by default.
- **A new README.** Both READMEs are rewritten in plain language, with a section on the chat channel and workspaces and a real-footage demo GIF at the top.

## Improvements

- **Pausing a role only stops the current turn.** The conversation is kept and queued messages stay queued, then get answered next. Works for Claude, Codex and Antigravity sessions.
- **Tidier task threads.** Each update in a task thread is one message in the member's own words, without a repeated header or an extra "see the thread" post.
- **Task cards show each member once, by the bot's channel name**, and the pinned board lists task-card members too.
- **Steadier bridge.** Scheduled messages wait for Discord to connect before sending, model and reasoning changes survive a restart, and Discord sends return an error instead of crashing when the session is not ready.

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM) (`chmod +x`, then run)
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Updates are one click: use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once.

The packages are unsigned. macOS: drag **Bothouse.app** into Applications, then **right-click → Open the first time**. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **工作区的提问和汇报回到交活的那个聊天频道。** 几个聊天频道共用一个工作区时，每次交活都有自己的任务编号，工作区接活时会收到这个编号。角色的 `[ask]`、`[report]` 按回复里带的编号送回交这件活的聊天频道；没带编号时，只有一个频道有未完成的活就送给它。做完的活不再算数，旧的交接抢不走新的汇报。
- **DSH 插件直接从 GitHub 装。** 每次发版都会把 DSH 插件发布到 `dsh-plugin` 分支，一条命令就能装：`dsh plugin --profile web add 'github:zuiho-kai/bothouse#dsh-plugin&path:dsh/plugin-pkg'`。
- **语音总台。** 语音对话里，主角色能听到全员进度；你确认之后，它把话转给对应频道里的对应队友。在配置里打开 `voice_desk` 即可，默认关闭。
- **新的 README。** 中英两份 README 都用大白话重写，加了聊天频道和工作区的介绍，开头换成实拍演示动图。

## 改进

- **暂停一个角色只停当前这一轮。** 会话保留，排队的消息继续排着，接下来照常回答。Claude、Codex、Antigravity 都支持。
- **任务线程更干净。** 线程里每条进展只发一条，用成员本人的话，不再带重复的标题，也不再多发一条「详见任务线程」。
- **任务卡上每个成员只出现一次，显示 bot 在频道里的名字**；置顶任务板也列出任务卡成员。
- **桥更稳。** 定时消息等 Discord 连上再发，切换的模型和推理强度重启后还在，Discord 会话没就绪时发消息返回错误而不是崩溃。
