## Highlights

- **A teammate out of quota no longer leaves you waiting.** When the teammate you @ or assign is in quota cooldown, the bridge hands the job to a free teammate in the same channel and says so ("X is cooling down until …, Y takes this"). If everyone is cooling down, it says when the first one is back (#1720).
- **Cheap-lane workspaces no longer stall on a full context.** A workspace on the local Qwen that outgrows its context window is moved to the stronger model instead of retrying the same error for an hour; the Qwen window is split by its parallel slots, and the route is re-checked when the handoff changes (#1722).

## Fixes

- **Stopping the management API no longer waits out open connections**: open SSE connections are closed on stop, so shutdown and restart finish right away (#1740, thanks @jsk11231).
- **QQ disconnects release their receipts**: pending receipts are released when the connection drops, and a stopped bot no longer keeps reconnecting (#1731, thanks @jsk11231).
- **No zombie processes after a restart**: after an in-place restart, the children of the previous image are reaped (#1742).
- **`daemon restart` recovers after a slow shutdown**: it waits for launchd to finish tearing down before reloading, and brings the service back if the reload fails (#1738, thanks @jsk11231).
- **Setup mode keeps things current**: upgrading in setup mode also refreshes the installed guard scripts (#1735, thanks @jsk11231), and a DSH web host that exited is started again (#1737, thanks @jsk11231).
- **Tests no longer hit the live gate**: collab tests clear an inherited `GATE_PORT`, in the source and in the embedded copy (#1736, #1739, thanks @jsk11231).
- **DSH members while busy**: a teammate's @ now reaches a DSH member mid-turn instead of only queueing; a lost steer patch in `dsh-acp` is restored at session start; a withdrawn acceptance stops the acceptance turn that is still running (#1741).
- **Reply checks**: the check-first guard blocks "not sure what X is" replies when no web search ran in this turn (#1723); the check for answering without searching now asks a small model to judge the reply and this turn's handoff, cron and timer text, also in team chat (#1724); `ws-forward` also applies forbidden-phrase rules to the forwarded summary (#1733).

## Improvements

- **Source tags in the wiki**: wiki facts can be tagged as seen first-hand, relayed, or quoted from the user (#1732, thanks @jsk11231).
- **README** now leads with putting someone else's agent to work for you (#1721).

## 重点

- **队友没额度了不再干等。** 你 @ 或派活的队友在额度冷却时，桥把活转给同频道空着的队友，并在频道里说明（「X 额度冷却到几点，这件改给 Y」）；全员都在冷却时，告诉你最早几点恢复（#1720）。
- **便宜通道的工作区不再因上下文满了卡住。** 跑在本机千问上的工作区超出上下文窗口时，改交给更强的模型，不再对同一个报错重试一小时；千问窗口按并行槽位拆分，交接变了会重新选路（#1722）。

## 缺陷修复

- **管理接口关停不再等满**：关停时关掉打开的 SSE 连接，关停和重启马上完成（#1740，感谢 @jsk11231）。
- **QQ 断线释放回执**：连接断开时释放待发回执，已停的机器人不再一直重连（#1731，感谢 @jsk11231）。
- **重启不留僵尸进程**：原地重启后回收上一个进程留下的子进程（#1742）。
- **`daemon restart` 慢关停后能装回**：等 launchd 卸载完再重新加载，加载失败时把服务装回（#1738，感谢 @jsk11231）。
- **设置模式保持最新**：设置模式下升级也刷新已安装的守卫脚本（#1735，感谢 @jsk11231）；退出的 DSH 网页宿主会被重新拉起（#1737，感谢 @jsk11231）。
- **测试不打正式 gate**：协作插件测试清掉继承的 `GATE_PORT`，源码和内嵌副本都改了（#1736、#1739，感谢 @jsk11231）。
- **DSH 成员忙时**：队友 @ 能插进 DSH 成员正在跑的一轮，不再只排队；`dsh-acp` 丢了的 steer 补丁在起会话时自动补回；撤销验收后正在跑的验收轮会停下（#1741）。
- **回复检查**：本轮没搜过网时，「不确定 X 是什么」这类回复会被拦下（#1723）；「没搜就答」检查改由小模型判断回复和本轮交接、定时任务文本，团队聊天里也生效（#1724）；`ws-forward` 的禁写规则也查转话摘要（#1733）。

## 改进

- **wiki 信源标注**：wiki 里的事实可以标明来源：亲自验证、转述，或引用用户的话（#1732，感谢 @jsk11231）。
- **README** 开头改为主打「用别人的 agent 给你干活」（#1721）。
