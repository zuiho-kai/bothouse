## Highlights

- **One task per workspace.** A workspace works on one task at a time and only free workspaces take new ones; with four workspaces busy, a new task waits on the board as 「排队」 and starts as soon as one frees up (#615).
- **Workspaces clean up after themselves.** A workspace's final `[report]` marks its board item done, clears the session and returns the workspace to the pool. An `[ask]` parks the task as waiting for you and frees the workspace; your answer resumes it in a free workspace with its handoff file. Once an hour, a workspace with no live task on the board is freed (#615).
- **Shorter handoffs for fresh sessions.** A new session's handoff keeps your words and where work stopped; timer and watch posts, model footers, team rules and backfilled channel tails are left out. On a real session the dialogue went from about 7,900 to 1,450 characters (#617).
- **Task board, four states.** The board shows in progress, stuck, waiting for you and done; a workspace lists only its own items (#610, #612).
- **Workspace reports post their first line verbatim** in the chat channel, under the board item's number.

### Fixes

- A `[report]` bounced for a missing headline no longer frees the workspace.
- A `plan_gate` hook blocks dispatch, code, commit and restart while a plan you asked for is not approved yet (#608).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **一个工作区一次只做一件活。** 新活只交给空着的工作区；四个工作区都在忙时，新活在任务板上记「排队」，有工作区空出来就自动接上（#615）。
- **工作区做完自己收拾。** 工作区交回最终 `[report]` 后，任务板自动标完成、清空会话、工作区放回池子。发 `[ask]` 后这件活在板上显示等你，工作区当场让出；你回复后，系统找空工作区，带着交接文件和你的答复接着做。每小时核一次，板上没有在做的活的工作区自动放回（#615）。
- **新会话的交接块变短了。** 只留你说的话和做到哪一步；定时和看门的输出、模型页脚、团队规矩、频道补录的长尾都不再带。真实会话上对话段从约 7900 字降到约 1450 字（#617）。
- **任务板四种状态。** 在做、卡住、等你、完成；工作区只看自己的活（#610、#612）。
- **工作区交回的第一句原样贴到聊天频道**，前面带任务板编号。

### 缺陷修复

- 因缺第一行被退回的 `[report]` 不再放回工作区。
- 新增 `plan_gate`：你要了方案还没批时，拦下派活、改代码、提交和重启（#608）。

- **校验：** `SHA256SUMS`
