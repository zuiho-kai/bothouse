## Highlights

- **One task per workspace.** A workspace takes one task at a time; a new task goes to a free workspace, and once four are busy it queues on the task board and starts as soon as one frees up (#615).
- **Workspaces clean up after themselves.** A workspace's final `[report]` marks its task done, clears the session and returns the workspace to the pool. An `[ask]` puts the task on the board as waiting for you and frees the workspace; your answer resumes it in a free workspace with its handoff file. Once an hour, a workspace whose task is no longer live on the board is freed (#615).
- **Lean handoff after a fresh session.** The handoff a new session gets keeps your messages and where the work stopped; timer and watch posts, model footers, team rules and long teammate reports are left out (#617).
- **Task board in four states.** The board shows four states, and a workspace lists only its own items (#610, #612).
- **Workspace reports post their headline as written** in the chat channel.

### Fixes

- A `[report]` bounced for a missing headline no longer frees the workspace.
- The workspace board's 「其他频道」 shows one short row per channel and skips done or waiting items (#603).
- `plan_gate` hook: dispatch, code changes, commits and restarts wait while a requested plan is not approved (#608).

### Install

- **macOS (Apple Silicon + Intel):** `bothouse-mac.dmg`
- **Windows:** `bothouse-windows.exe`
- **Linux:** `bothouse-linux-x64` (Intel/AMD) / `bothouse-linux-arm64` (ARM); `chmod +x`, then run.
- **Checksums:** `SHA256SUMS`

Already on v0.1.6 or later? Use the **Update to vX** button in the bottom-left corner. From v0.1.5 or earlier, download and install this release once. If an older updater times out, download and install this release manually.

macOS: drag **Bothouse.app** into Applications and **right-click → Open** the first time. Windows: if SmartScreen warns, click **More info → Run anyway**.

## 重点

- **一个工作区一次只做一件活。** 新活交给空着的工作区；四个都在忙时，新活在任务板上排队，有工作区空出来就自动接上（#615）。
- **工作区做完自己收拾。** 工作区交回最终 `[report]` 后，这件活自动标完成、清空会话、放回池子。发 `[ask]` 时，活在板上显示「等你」，工作区当场让出；你回复后，系统找空工作区，带着交接文件接着做。每小时把板上已没有在做的活的工作区放回（#615）。
- **新会话的交接更短。** 新会话拿到的交接只留你说的话和做到哪一步；定时和看门消息、模型页脚、团队规矩、队友长汇报都不再塞进去（#617）。
- **任务板四种状态。** 任务板显示四种状态，工作区只列自己的条目（#610、#612）。
- **工作区交回的第一句** 原样贴到聊天频道。

### 缺陷修复

- 因缺第一行被退回的 `[report]` 不再放回工作区。
- 工作区任务板的「其他频道」每个频道只占一行，不列已完成和等你的条目（#603）。
- `plan_gate` 钩子：你要了方案还没批时，派活、改代码、提交、重启都先等着（#608）。

- **Windows：** `bothouse-windows.exe`
- **Linux：** `bothouse-linux-x64`（Intel/AMD）/ `bothouse-linux-arm64`（ARM）；`chmod +x` 后运行。
- **校验：** `SHA256SUMS`
