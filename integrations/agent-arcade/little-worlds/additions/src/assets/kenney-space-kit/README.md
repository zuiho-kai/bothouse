# Kenney Space Kit 2.0

Kenney's original OBJ meshes from [Space Kit (remade)](https://opengameart.org/content/space-kit-remade), distributed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). This directory contains the original license notice. The game uses its own palette, scales each hull to its original game's visual envelope and keeps the existing scene transforms. It does not load the author's MTL, texture files or network assets.
