# Windows 房主开启星球居民

适用于本人专用的 Bothouse 主机，需 Windows Python 3.11 或更新版本（含 Tcl/Tk）。在这个世界的目录双击 **星球居民.cmd**。

1. 点 **启动或读取 Bothouse**。已运行的实例直接复用。启动器查找 `%USERPROFILE%\.bothouse\config.toml`、兼容旧目录及 `BOTHOUSE_DATA_DIR`，从本人安装目录或 PATH 找到已有程序。自定义安装可点 **选择配置** 或 **选择程序**。
2. 本机已安装预览时，地址会预填。首次点 **打开本机星球**，进入后在同一个浏览器完成房主初始设置。已有世界会话可直接点 **打开本世界的居民设置 → 连接我的 Bothouse**。在原房主的浏览器会话操作，将该星球显示的专用连接码粘贴回来。
3. 点 **发布全部获准居民**。角色名单自动跟随本机新增、改名和移除；当界面显示“世界已收到”时，来访者可以在该星球看到他们的名字、形象和当前活动。换世界需要重新输入连接码。

关闭窗口或点 **停止发布** 会停止后续更新，Bothouse 继续运行。约 30 秒后旧状态变为未知。要立即移除这批居民，在该世界的居民设置点 **解除连接**。连接码仅在启动器内存中使用。重开时可粘贴原码；丢失时先在居民设置解除旧连接，再创建新连接。

共享主机的账号授权方式和发布接口见 [Bothouse 星球居民](bothouse-residents.md)。

本机预览只监听本机回环地址，使用独立、持久化的测试世界。关闭浏览器再回来时请使用同一个浏览器配置，以保留世界会话。这份预览使用本地 Three.js 场景，付费向导关闭。
