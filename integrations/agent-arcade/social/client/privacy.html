Agent Arcade 好友

返回好友

隐私说明

这份说明适用于 Agent Arcade 好友服务和 Windows 应用。下文先介绍好友账号和在线功能，再说明 Windows 应用「更多」里的个人功能。网页版只提供好友服务。

运营方与隐私联系

此服务尚未公布支持联系方式。选择上方「返回好友」，登录或创建账号后在「我 → 意见反馈」联系运营方。

可复制已公布的联系方式。在 Windows 点「打开支持网页」会交给系统默认浏览器。

账号和登录

注册时，服务接收你填写的用户号、昵称和密码。服务保存带随机盐的密码哈希。登录会在你的设备上写入保持会话用的 Cookie，服务端保存会话凭证的摘要。知道你完整用户号的已登录用户可以查到你的用户号和昵称。登录和注册时，服务也用来源 IP 限制过于频繁的请求。

真人私聊和群聊

好友关系、申请、群名称和成员、消息正文、发送者及时间保存在好友服务的数据库中，用于送达消息和重开后查看历史。好友私聊双方可查看本会话；群成员只能查看自己本次入群后有权看到的消息。真人私聊与普通群消息无需配置模型。群消息只有在发送人符合下方群内 AI 授权及触发条件时，才可能发送给所选云服务。

点「发送文件」后，文件名和原始内容随消息保存在好友服务及其备份中。有权查看该消息的会话成员可保存原件。截图选区和发送前预览在设备上完成，点「发送截图」后才作为聊天图片上传。

发送 PNG 或 JPEG 时，服务原样保存图片，数据库备份也包含原图。能查看该消息的会话成员可打开和另存原图，文件可能保留拍摄时间或位置，发送和保存前请留意。发给真人的图片不会因此发送给云模型。

通过「我 → 更换头像」保存的照片会在当前设备裁成方形并移除拍摄信息。服务只保存处理后的头像，好友和同群成员可以看到，数据库备份也会保留备份时使用的头像。输入框的表情包使用随版素材，按普通图片消息的权限显示。

录音和发送前试听在当前设备上进行，点「发送语音」才会上传。录音随消息保存在数据库及备份中。群里有 AI 时，真人仍可收发照片和录音；当前有权查看消息的成员可打开原图或直接在气泡内播放，群成员只能查看本次入群后的附件。录音不会自动转写，普通附件及原件地址不会触发 AI 接话、看图或公开图搜索。在 AI 私聊发图时填写问题，或在已发照片上明确选择「问 AI」，好友服务才会将所选照片的画面和本次问题发给界面列出的角色服务。发给模型的副本会移除拍摄信息，JPEG 只保留显示方向。群友使用别人的图，需要作者对这张图及该角色的允许。会话下载的原图可能仍含拍摄信息。

未发送的聊天文字暂存在当前页面的会话存储中。登录过期后，用同一用户号重新登录，可在仍有访问权限的原会话继续编辑符合条件的草稿。恢复只填回文字，不会自动发送，也不会恢复附件或已提交的发送请求。主动退出会清除聊天草稿；换用另一账号登录时不会带入原账号的草稿。

正式部署要求 HTTPS，传输由 HTTPS 保护。服务端数据库包含可读消息正文，当前未提供端到端加密。数据库及备份由运行该服务的一方管理。

好友动态

发布动态时，好友服务保存作者、发布时间以及你发出的文字和原图。你和当前互加为好友的人可查看原图，图片可能保留拍摄时间或位置。后来成为好友的人也能查看仍保留的动态。删除或审核移除后，在线正文和原图会清除，发布编号仍保留以防重试恢复。旧备份或好友自己保存的副本可能仍含原图。动态文字和图片均不会发送给聊天模型。

发表评论时，服务保存你的用户号、文字和时间。读者须能查看原动态；你和你的好友能看到你的评论。删除动态或审核移除时会一并清除在线评论，旧备份可能保留。评论不会发送给 AI。

关注角色动态

你可分别关注鲸鱼娘、橘娘和龙娘。只有当前关注者能查看该角色仍保留的动态，取消关注后这位角色的动态会从你的列表隐藏。好友服务保存关注设置。角色可以发一条短动态，也可以保持安静。生成时会把公开角色设定、固定发动态指令和当天 UTC 日期发给该角色使用的服务，依次为 DeepSeek、Claude（Anthropic）和 OpenAI。关注者的账号、私聊、群聊和私有角色设定不会发送。关注不会添加好友、打开云私聊或开启主动联系。

举报和意见反馈

你从消息旁的「⋯」（消息操作）菜单选择「举报消息」并提交时，服务记录举报人、消息编号、原因和处理状态。运营者可查看所选消息的正文或附件类型。你勾选「一并提供」后，运营者可在本机审核工具打开该条图片或语音原件，原图可能含拍摄信息。原件不会发给外部服务。举报不附上整段聊天。运营者移除消息后，聊天同步时会显示「已移除」。服务仍保留原记录，已经另存的副本无法远程清除。

举报一条好友动态时，服务仅保存这条动态提交举报时的正文、对应作者、举报人、原因和处理状态。之后即使作者删除，运营者仍可核对该举报副本。动态举报回执不会复制原图。审核移除后，作者和好友刷新动态即无法再读取正文或原图。

你主动提交意见反馈时，服务保存填写的文字、账号、提交时间、回执、网页构建号及可用的桌面包版本。运营者可在处理工具中查看并记录处理结果。你可在「我的反馈」查看本账号的近期记录及对应处理结果。反馈不会自动附带聊天、通讯录或密码。重试用的待提交内容保存在当前客户端，收到回执或主动退出账号后清除。

你点「回顾我的聊天问题」后，好友服务用本身已保存、当前仍可查看的本人文字消息计算问题统计。回顾只把类别和数字显示给本账号，不另存原文，也不调用模型。只有你把汇总加入草稿并提交后，运营才会在这条意见中看到你提交的内容。

与 Bothouse 角色聊天

通讯录只列出本账号可联系的 Bothouse 角色。打开角色私聊后发送文字，或在群中从成员列表 @ 一位角色后发送，好友服务会把当条文字、你的社交账号标识和对应会话标识交给该角色所在的 Bothouse 实例。角色使用实例配置的服务处理消息，回复保存在原会话。普通好友聊天由好友服务送达。

明确交办的任务会在任务板留下发起人、目标角色、原消息位置和任务内容，进度和交付结果可由原会话的成员查看。电脑上的「更多 → Bothouse 管理」打开本机实例的管理页面。

此前版本的云 AI 私聊

只有好友服务已启用相应角色，并且你在当前账号明确同意后，新发给该 AI 的私聊才会触发模型请求。鲸鱼娘使用 DeepSeek（api.deepseek.com），龙娘使用 OpenAI GPT（api.openai.com），橘娘使用 Claude（Anthropic，api.anthropic.com）。好友服务把这段私聊中最近最多十条可用消息的正文和回复角色标记，连同角色回复说明，发送给所选角色的服务。其他会话、通讯录、举报、意见反馈及本地角色资料不会随这项请求发送。你的消息和回复会保存在当前私聊中。

在 AI 私聊顶部打开「会话设置」，选择「关闭云聊天」并确认，即可撤回本账号对这段私聊的云授权。已保存的历史仍可查看，关闭期间不能发送新消息。服务会尝试中止在途请求，并丢弃此后到达的回复。已经发给 DeepSeek 的内容无法撤回。已经发给 OpenAI 或 Claude 的内容同样无法撤回。

你明确请鲸鱼娘记一次约定时，好友服务会在当前私聊保存事项、你选的时区和时间。约定及提醒由好友服务处理，不发给模型。可在聊天顶部的「约定提醒」改时间或取消。好友服务运行时，即使客户端已关闭也会把到期提醒留在原私聊。

「通讯录 → 新的朋友」可分别选择是否接收鲸鱼娘、橘娘和龙娘的好友申请。在已有群内云聊天授权且你点名和这位角色交谈后，该角色可以决定发来一次申请。好友服务只在当轮的群回复模型请求中附上你愿意接收该角色申请的说明，不会单独再请求模型或传送通讯录。关闭某一位会撤下她尚未处理的申请。你可以接受或拒绝，接受后仍由你单独决定是否开启该角色的云私聊。你主动添加这三位内置 AI 时，好友申请会自动通过，云私聊仍由你决定。以前的接收设置只适用于鲸鱼娘。

已同意的 AI 私聊或群内接话可以回一张角色贴图或带署名的公开表情图。找公开图时，好友服务向 OpenMoji 请求固定目录或素材，或向 Wikimedia Commons 发送筛选后的公开主题词并取得原图。图源不会收到账号、会话、聊天原文或附件。收件人可在原图详情查看来源和许可。个人 AI 在私聊收到明确的表情请求时，可按语境从 OpenMoji 取一张带署名的通用表情，仅请求固定目录及选中的图片文件。「发个表情」不会触发云生图。

你可在 AI 私聊的「会话设置」开启公开网页搜索。角色已入群时，群内公开搜索默认可用，群主可关闭。明确请角色查公开资料时，好友服务只把本次消息中的公开主题词发给 Mwmbl（api.mwmbl.org），不会附带聊天历史、账号或附件。来源作为聊天消息保存在原会话。可在同一设置关闭搜索。

因含私密内容在本地被拒的找图消息仍保留在会话内。该消息、关联回复和可识别的复述会从后续模型上下文中过滤。旧库升级或从快照恢复后也会在好友服务本地处理。

如需重新启用，请在这段私聊点「恢复云聊天」，再点「同意并恢复」。恢复后的模型上下文从新发的消息开始，之前的历史、停用期间的文字和草稿不会自动发送。

好友角色的私聊绘图

好友服务配置云生图后，在已同意云聊天的内置角色私聊中明确要求画一张图，服务会将本次画面描述发给 Cloudflare Workers AI。要求画当前角色本人或明确参考它的公开头像时，服务也会发送该角色的公开外观和随包头像。旧聊天与会话里的照片、附件不作为绘图参考。生成的图片保存在这段私聊中。打开图片可重发原图，无需重新生成。

原有个人 AI 私聊中已收到的绘图仍按原会话权限保存。

角色私聊主动联系

只有你在与鲸鱼娘、龙娘或橘娘的私聊中单独开启「主动联系」后，好友服务才会按你保存的时段尝试生成一次问候。关闭页面后服务仍可把问候写入这段私聊。对应角色的 DeepSeek、OpenAI 或 Claude 服务只会收到公开角色设定和固定的问候提示，账号、联系时段、旧消息和群聊资料留在好友服务。你可以随时关闭主动联系。关闭云聊天会同时停用主动联系，恢复云聊天后需另行开启。

可选群内 AI

好友服务配置好云生图后，已经入群的角色默认可用，群主可关闭。已同意和该角色聊天的群友可以点名要求画图。好友服务向 Cloudflare Workers AI 发送画面描述。要求画内置角色本人或参考它的头像时，服务也会发送该角色的公开外观和项目自带头像。群主单独批准本群导入角色的卡面后，画这个角色或明确指定参考该卡面时会附上这张 PNG。切换角色卡时需重新批准卡面，也可单独撤销。群聊天里的照片仍按消息权限保存。新图可能计入运营方用量，重发沿用已保存的原图。

群主可添加已配置的鲸鱼娘（DeepSeek，api.deepseek.com）、龙娘（OpenAI GPT，api.openai.com）和橘娘（Claude，api.anthropic.com）。加入角色后，每位群成员仍须在「群成员 → 群内 AI」为自己的账号、这一个群、选定的角色和标明的服务分别同意。群主的选择不会为其他群成员授权。

同意后，你从成员列表按用户号点名该 AI，或发出符合接话条件的邀请、提问或续问时，服务默认把当条文字和角色公开设定发给相应服务商。经群主批准后，请求还会带上角色卡的名称、公开设定和示例台词，以及随卡或从本机世界书另行选中、适用于当条消息的内容。仅保存本群此角色已批准的条目，群主可单独撤销另选的世界书。

你在「群内 AI」另行允许带上上一问一答后，符合条件的续聊才会附上你与同一 AI 的前一问一答。其他成员的消息、更早的群历史、私聊、通讯录、附件和其他本机资料不会随请求发送。各服务分别授权，服务不可用时不会转交另一家。回复会出现在群聊中。

在同一页选择对应 AI 的「停止发给 DeepSeek」「停止发给 OpenAI（GPT）」或「停止发给 Claude（Anthropic）」可撤回你对这一角色和服务的授权。你也可以单独关闭携带上一问一答。退群、由群主移除该 AI 或从备份准备恢复时，相关授权会清除。服务会尝试中止相关的在途请求，丢弃此后到达的回复。发给提供商的内容无法撤回，已保存的群消息仍依成员权限可见。

别人通过 Bothouse 分享角色时，可在「通讯录 → AI 联系人」使用为你当前好友号生成的一次性配对码。好友服务保存这次配对的角色访问范围。在同一处解除配对后，原聊天记录仍可按原会话权限查看。

原有个人 AI 的资料与授权

旧版中由你输入好友服务的聊天密钥只存于服务进程内存，正常重启后即失效。现在可从桌面 App 的「更多 → Bothouse」管理角色。有原有个人 AI 的账号，可在「通讯录 → AI 联系人 → 原有 AI 的授权与资料」查看设定和撤回授权。

原个人 AI 的私聊可在消息列表继续查看。原先批准的私聊和群聊角色卡、世界书仍可分别查看和撤回。在「原有 AI 的授权与资料 → 好友权限」可收回旧的好友或云聊天许可。在「群内 AI → 原有群 AI 的授权」可收回自己曾给予这位 AI 的发送授权。主人或群主可撤下旧邀请或移除角色。

好友服务正常重启后，原 AI 编号、群邀请和已保存的群授权仍在。若运营方从备份恢复，成员须重新登录，按群权限查看备份中的历史。

你可单独从某个群移除 AI，或在「原有 AI 的授权与资料」点「从所有群撤回并断开」。全部撤回会从各群移除 AI、撤下邀请，并清除本服务内存中的密钥。AI 编号和已经发布的群消息仍保留；此前已经发送给云服务的内容无法在这里收回。

好友角色的可选语音回复

内置好友角色可按会话授权使用选定的音色。首次明确要语音时，可在原消息上选择仅本群允许、记住本账号的 Azure 选择，或只收文字。记住的选择只用于该账号可访问、且已授权相应角色接话的群中的明确语音请求。单群暂停或停用本人选择优先。等待你选择时，好友服务不会为这条请求调用聊天或语音服务。

需要朗读时，好友服务使用运营方配置的 Azure 凭据，把当轮要朗读的台词和选定音色发给微软，Azure 不接收主人的聊天 API 密钥。台词可能含有对话内容；试听只发送固定示例及选定音色。未配置云语音、未授权语音、明确要求文字或合成失败时，已允许的聊天可以用文字回复。你可撤回会话语音许可。已存语音仍按会话权限可见，已提交给云服务的台词无法收回。

好友服务保存生成的音频和台词。会话成员按消息权限重播音频。AI 语音的试听、合成和播放均无需麦克风。

真人录音最长 30 秒，AI 语音最长 120 秒。被拒的私密找图、可识别的复述和会话附件原件地址不会交给合成服务。关闭当前会话的模型授权会同时清除该角色的语音授权；从备份恢复后须重新选择并允许音色。

Windows 应用的个人功能

「更多」里的个人功能使用本机档案。个人对话、角色卡、世界书、记忆和设置保存在当前 Windows 用户的应用资料中，保存的 API 密钥使用系统加密。登录好友账号不会同步这些档案或密钥，退出好友账号也不会清除它们。「陪伴」使用在本机为该搭档配置的密钥。把本机角色卡或世界书用于某个好友群，也须在对应群明确批准。

在「陪伴」发消息时，App 使用你为该搭档选定的 AI 服务。使用 API 时，消息、适用的近期对话、角色设定和记忆会随请求发给该服务，密钥用于向该服务认证。选择本机 Claude Code 时，内容交给该程序，由它使用自己的登录和服务。可在「应用设置 → AI 服务与模型」查看或更换服务，并在所选搭档的连接设置中清除已保存的凭据。

在「创作与图库」请求云生图时，画面描述及该次使用的卡面参考图会发给你配置的绘图服务。图库作品保存在本机。在「陪伴」开启麦克风语音后，使用 Windows 语音或已配置的本机神经语音识别和朗读。原始麦克风音频在本机处理，通常可先检查识别出的文字再发送；使用受支持的耳机免按键模式时，识别结果会直接发送。发出的文字按当前陪伴对话交给所选 AI。可在语音面板结束语音或关闭麦克风。上文的好友录音与好友 AI 语音使用各自的授权。

「工作」中的 Claude Code 观察器由你安装，记录本机任务状态。可在「应用设置 → 观察器与隐私」移除观察器，或关闭默认未开启的「保存最终回复文本」。开启后保存的最终回复留在本机，关闭会清除该项保存的回复。在「工作 → 任务」派出任务后，App 会为选定的 Git 仓库创建工作树并启动另行安装的本机 Claude Code，使用该程序的登录和额度。任务说明、返工内容和工具读取的文件可能由该程序及其服务处理。工作树内的预授权只影响编辑确认，无法隔离程序对其他文件或网络的访问。

「渠道与账号」里主动连接的 QQ 或微信会通过所选渠道收发消息。开启 AI 回复或派活后，符合所设范围的消息及回复所需上下文可能发给该搭档的 AI 服务。在「应用设置 → 渠道与派活」可选择渠道执行方式，包括本机 Codex。选择它后，任务指令及工具按权限读取的内容或执行结果可能交给 Codex 及其服务，使用该程序自己的登录。可在同处检查工作范围，也可断开渠道或在对应设置中收回群和功能许可。你添加的数据源可以在本机读取日历或文件夹，或向配置的网站请求内容；可在「数据源」停用或移除。设备入口用于本机桌宠和选定设备，不会把个人聊天同步到好友服务。

好友服务的记录与控制

如果运营方从备份恢复，好友账号须重新登录。恢复副本保留有权查看的历史，云私聊和群内分享授权需重新确认，角色动态也需重新关注。即使群里仍能看到恢复前的问答，重新打开分享也只会在符合条件的续聊中携带授权后新产生的问答。

你可查看自己有权访问的会话与反馈，决定是否接受好友请求、发送消息、举报、提交反馈或启用 AI 私聊。退出登录会终止这次登录。普通成员退出群聊后会失去访问该群的权限。退出登录或退群后，服务仍保留已保存的记录。当前没有供用户删除账号、导出全部数据或设定自动删除期限的功能。
