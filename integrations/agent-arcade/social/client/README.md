# Agent Arcade 好友客户端

在真人私聊或群的输入框旁点「文件」，选择最多 16 MiB 的本地文件并点「发送文件」。对方会看到名称、字节数和「保存文件」。Windows 桌面点「截图」后用系统截图工具选区，回到会话按 Ctrl+V 查看预览，再点「发送截图」。也可按 Win+Shift+S 选区，或选择已经保存的 PNG/JPEG。关闭预览即可取消。也可把单个本地文件拖到当前聊天区，核对会话名和文件后再发送。PNG/JPEG 会先显示图片预览。多个附件请逐个拖入。

Windows 桌面和移动浏览器共用好友客户端，登录后进入「消息」。在「我」复制自己的用户号。在「通讯录 → 添加朋友」粘贴对方的用户号，点「查找」，核对号码后点「发送好友请求」。对方在「通讯录 → 新的朋友」接受后，双方可从「消息」或「通讯录」打开私聊，也可从「通讯录」发起群聊。

账号会话由服务端 HttpOnly Cookie 管理，历史和好友关系从真实服务读取。已登录时前台定期刷新会话、好友请求和当前聊天，回到前台或重新联网会刷新。重试同一条待发送消息沿用同一标识。消息、昵称和群名按纯文本渲染。

好友私聊和群聊默认按 Enter 发送，Shift+Enter 换行。在统一桌面 App 中，好友聊天沿用「设置 → 聊天」的发送键。使用 Ctrl+Enter 发送时，单按 Enter 换行。中文输入法确认候选后，再按发送键即可发出。

从「通讯录 → AI 联系人」找 Bothouse 已分享给你的角色，点「打开私聊」开始聊天。拿到分享人给这个账号的一次性配对码时，在同一入口点「使用角色配对码」。如果已直接获准，刷新目录即可。聊过的角色可从「消息」回到原会话，角色和模型由分享方在 Bothouse 管理。

给支持派活的 Bothouse 角色交办任务时，在原私聊的输入框旁点「＋ → 交办任务」，写明要做什么再发送。群里先输入 @，从出现的成员列表选中已入群的角色，再用同一个「交办任务」入口。受理状态和结果回到发起任务的会话。

在「好友动态」可读到自己的动态以及当前互加好友的文字动态。点「发动态」发布，或在「我的动态」里删除自己的动态。动态下面点「评论」可写最多 500 字。朋友点「刷新」就能在原帖下看到最近两条可见评论，点「评论」可读更早的内容。评论仅对仍能看该帖的本人和好友可见。

在已接入小星球的桌面版里，打开真人好友的私聊，点「会话设置 → 拜访好友星球」。好友在自己的星球开启「允许好友来访」后即可前往。结束拜访时点「返回消息」，可继续原聊天。

在真人私聊或群聊里，点输入框旁的「图片」，选择一张静态 PNG 或 JPEG，在预览中确认后点「发送图片」。点开收到的图片，再点「保存图片」，Windows 应用会打开另存为。单张上限 4 MiB，保存的原图可能保留拍摄时间或位置。发给真人的图片不会自动送给 AI。

打开真人或 AI 发送的图片旁的「消息操作」，点「收藏为表情」。在另一段支持发图片的会话打开「表情包 → 我的收藏」，点击图片即可发送。
收藏较多时可翻页，也可在同一面板取消收藏。收藏跟随登录账号，重发保留原图及已有出处。打开重发的角色绘图可查看作画角色和原标题。
原图失去访问权限后，收藏不会继续提供预览或发送。
在支持发图的 AI 私聊，发送收藏的图片和只发普通图片一样。如果要让角色看图并回答，发送后需另行选择「问 AI」。

已有 Playwright 和 Edge 时，可运行 `npm --prefix integrations/agent-arcade/social run test:images`，复验图片收发、群范围撤销和 SQLite 恢复。可传入输出目录保留窄屏原图截图。

如果账号保留旧版个人 AI 资料，可在「AI 联系人 → 原有 AI 的授权与资料」查看该角色的授权，有原私聊时也可打开历史。在群的「群内 AI → 原有群 AI 的授权」可撤回自己原来给出的发送授权。

## 本机启动

从 Bothouse 仓库根目录运行。普通用户只打开应用入口，服务地址和数据库由部署控制。服务部署和配套地址见[好友服务部署说明](../deploy/README.md)。

```powershell
$env:SOCIAL_DB = Join-Path $env:TEMP 'agent-arcade-social-dev.sqlite'
node integrations/agent-arcade/social/server/main.cjs
```

浏览器打开服务在控制台输出的本机地址。手机浏览器支持窄屏布局，安装清单采用独立窗口显示。手机实体设备安装和商店壳尚待现场验收。

## 隔离复验

在仓库根运行 `npm --prefix integrations/agent-arcade/social run test:client`。需要 Microsoft Edge 与当前检出或 Node 模块查找路径中的 Playwright。已安装桌面项目依赖时可直接复用。在独立检出中可用 `npm install --no-save --package-lock=false --prefix social playwright` 安装测试依赖。脚本用三个合成账号、随机回环端口及临时 SQLite 走真实 HTTP 服务，保留 .qa 下的截图和机读回执，清理服务和临时库。布局参考 Signal 的精确用户名查找，以及 Element 的桌面并排导航；窄屏将会话独立展开。


未读与换服回归可在仓库根目录单独运行：

```sh
node integrations/agent-arcade/social/client/.qa/verify-unread.cjs unread-evidence
```

使用上文的 Edge 和 Playwright。输出目录必须尚未存在。脚本在本机回环中创建合成账号，并在同一服务地址让已有账号用旧版无角标首页加载现行脚本，从聊天界面发送，核对对端只收到一条。回执和截图保存在输出目录中。若另有不带已读游标的公开源码版本，可在该版本用同一脚本和第三参数 `baseline` 生成旧库，再在新版把该夹具目录作为第三参数，额外验证数据库迁移。

同一好友服务和账号重开应用后，可在原会话继续编辑本机未发送的文字。草稿不会自动发送；主动退出登录会清除该账号在此设备上的草稿。旧版草稿可在原页面仍保留草稿时迁移。

要删除真人好友，从通讯录打开该好友的私聊，再点「会话设置 → 删除好友」，确认显示的用户号。删除后双方仍可查看原私聊历史，共同群也能继续聊天；要恢复私聊发消息、好友动态与从私聊拜访星球，可在原私聊点「重新添加好友」，待对方接受。

真人好友的私聊中可点「会话设置 → 好友备注」。备注仅自己可见，可在通讯录按备注、原昵称或用户号查找。清空备注并保存即可恢复原昵称。
