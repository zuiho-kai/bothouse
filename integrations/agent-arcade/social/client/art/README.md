# Built-in chat artwork

The ribbon is a resized export of [the original Agent Arcade ribbon](../../../src/assets/brand/ribbon-simple-v1.png). The Ju, Dragon and Whale avatars are 160 × 160 exports of the corresponding [built-in project portraits](../../../src/ui/portraits/). Only dimensions and PNG encoding changed. The original artwork and its attribution remain in the same repository. The chat assets follow the project's AGPL-3.0 distribution terms.
