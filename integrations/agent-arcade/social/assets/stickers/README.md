# 好友聊天贴图

鲸鱼娘与龙娘的动物主题小贴图为 Agent Arcade 原创图形。`render.py` 是手工绘制几何形状的可编辑源，导出六张 256 × 256 透明 PNG，分别对应开心、赞同、惊讶。未取用外部图库、个人资料或聊天附件。

橘娘使用同一套本项目角色美术。「开心」直接沿用 [既有橘娘贴图](../../../src/assets/qq-group-replies/ju-sticker.png)，「赞同」和「有点不满」用 [桌面搭档原画](../../../src/pet/portrait/art/) 裁出 256 × 256 透明 PNG，由 `export_ju.py` 导出。

源文件和导出 PNG 随项目按 [AGPL-3.0](../../../LICENSE) 分发。App 的原图弹窗提供角色、反应和素材来源。好友私聊和群聊的「表情包」按钮与 AI 表情共用这套随版 PNG。
